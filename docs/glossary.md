# 📖 คำศัพท์และถ้อยคำใน PIRIvoice (Glossary)

> **ทำไมต้องมีไฟล์นี้** — ผลตรวจ UX/UI (`~/plans/PIRIvoice_UX_UI_Audit.md` §6) พบว่าปัญหา
> "แอปเยอะเกินไป" ส่วนหนึ่งไม่ใช่ *จำนวนของ* แต่เป็น **ของอย่างเดียวกันถูกเรียกหลายชื่อ**
> ⇒ ผู้ใช้ต้องตีความใหม่ทุกครั้งที่เจอ ("นี่อันเดียวกับเมื่อกี้ไหม")
>
> 🔴 **ไฟล์นี้ไม่ใช่เอกสารประกอบ — เป็นข้อตกลงที่บังคับใช้** เมื่อจะเขียนป้าย/หัวข้อ/ข้อความ
> ในหน้าจอ ให้เปิดไฟล์นี้ก่อน แล้วใช้คำในคอลัมน์ "ใช้" เท่านั้น

## 1. ชื่อสิ่งของ (ของสิ่งเดียวต้องมีชื่อเดียว)

| ความหมาย | ✅ ใช้ | ❌ ห้ามใช้ | หมายเหตุ |
|---|---|---|---|
| กระดานพูดคุย/โหวตสาธารณะ | **บอร์ด** | PIRI Boards · Boards | `PIRIvoice` เป็นชื่อ *ผลิตภัณฑ์* ไม่ใช่ชื่อ *หน้า* — อยู่ที่ตรา/หน้าเปิดเท่านั้น |
| คู่มือสภานักเรียน (E-book 6 เล่ม) | **คู่มือการทำงาน** | P.R. Playbooks · Playbooks | |
| เรื่องที่ผู้ใช้เป็นผู้รับผิดชอบ | **เรื่องที่รับผิดชอบ** | เรื่องที่รับ · ระดับฉัน · ผู้รับผิดชอบ | ป้ายในแถบ segment ใช้คำสั้น **"ที่รับผิดชอบ"** |
| เรื่องที่ผู้ใช้แจ้งเอง | **เรื่องของฉัน** | ของฉัน (ในบริบทที่ต้องชัด) | ป้ายในแถบ segment ใช้คำสั้น **"ของฉัน"** |
| หน้ารวมงานของสภา | **จัดการรายงาน** | ตรวจรายงาน | เดิมแถวเมนูกับหัวหน้าใช้คนละคำ |
| ผู้ใช้ระดับสูงสุด | **ผู้ดูแลระบบ** | แอดมิน · admin | |
| ปีที่สมาชิกผูกอยู่ (ม.1–ม.6) | **ปีการศึกษา** | ปีการศึกษาใหม่ · เทอม | ดู §1.1 — **คนละอันกับภาคเรียน** |
| ช่วงวันที่ของสถิติในปีหนึ่ง | **ภาคเรียน** | เทอม · ภาคการศึกษา | 1 ปีมี 2 ภาค |

📌 **"PIRIvoice"** ปรากฏได้เฉพาะเป็น *ชื่อระบบ* (หน้าเปิด, `<title>`, ข้อความต้อนรับระดับแอป)
— ห้ามใช้เป็นคำนำหน้าชื่อหน้า/ป้ายเมนู

### 1.1 🔴 "ปีการศึกษา" กับ "ภาคเรียน" **คนละอย่าง — อย่าใช้แทนกัน**

สองคำนี้ออกเสียงคล้ายกันและอยู่ในหน้าเดียวกัน (กลุ่มเมนู "โรงเรียน") แต่ตอบคนละคำถาม
⇒ สลับแล้วความหมายเพี้ยนทันทีโดยที่ข้อความยังอ่านดูปกติ

| | **ปีการศึกษา** | **ภาคเรียน** |
|---|---|---|
| ตอบคำถาม | "ปีนี้**ใคร**อยู่ห้องไหน ตำแหน่งอะไร" | "ช่วงนี้**เป็นยังไง**" |
| เก็บที่ตาราง | `academic_years` | `academic_terms` |
| ผูกกับ | **สมาชิก** (`students.academic_year_id`) | **สถิติ/ช่วงวันที่** (ใช้กรอง) |
| 1 ปีมีกี่อัน | 1 | **2** |
| หน้าที่ | หน้าปีการศึกษา · ปุ่ม "ใช้เป็นปีปัจจุบัน" | หน้าภาคเรียน · ปุ่ม "ใช้เป็นภาคปัจจุบัน" |

- ✅ **"ปีการศึกษา 2569"** (พ.ศ.) · ✅ **"ภาคเรียนที่ 1/2569"**
- ❌ ห้ามเรียกภาคเรียนว่า "ปีการศึกษา …" และห้ามเรียกปีการศึกษาว่า "เทอม"
- ❌ ห้ามเขียน "ปี 2569/1" — เลขหลัง `/` เป็นของ**ห้อง** (`ม.4/1`) ไม่ใช่ของภาค

⭐ **ทำไมสมาชิกผูกกับ "ปี" ไม่ใช่ "ภาค":** ถ้าผูกกับภาค คำถาม "คนนี้ย้ายห้องตอนภาค 2
ใช่ไหม" จะตอบไม่ได้ตั้งแต่ต้น เพราะ 1 ปีมี 2 ภาค ⇒ แถวสมาชิกจะชี้ภาคไหนก็ไม่ครบ
(ดู `backend/services/year_service.py` หัวไฟล์)

## 2. สถานะของ "เรื่อง" (issue)

ใช้ชุดคำนี้ตรงกันทั้งแอป — ที่มาคือ **2 ไฟล์**: `src/types/issue.ts` (`STATUS_LABELS` = ป้ายยาว)
และ `src/constants/status.ts` (`STATUS_SHORT` = ป้ายสั้น)

| รหัส (backend) | ป้ายยาว | ป้ายสั้น (ชิป/แถว) |
|---|---|---|
| `pending` | รอรับเรื่อง | รอรับ |
| `in_progress` | กำลังดำเนินการ | กำลังทำ |
| `escalated` | ส่งต่อให้ระดับสูงขึ้น | ส่งต่อ |
| `resolved` | แก้ไขเสร็จ | เสร็จแล้ว |
| `cancelled` | ถูกยกเลิก | ยกเลิก |
| `rejected` | ถูกปฏิเสธ | ปฏิเสธ |

### 🔴 "ปฏิเสธ" (เรื่อง) กับ "ไม่ดำเนินการ" (รายงาน) **คนละความหมาย — ห้ามใช้คำเดียวกัน**

| การกระทำ | ใช้คำ | แปลว่า |
|---|---|---|
| สภาตรวจเรื่องแล้วไม่รับเรื่องนั้น | **ปฏิเสธเรื่อง** | เรื่องจบ สถานะเป็น `rejected` |
| สภาตรวจ *รายงาน* เนื้อหาแล้วเห็นว่าไม่มีมูล | **ไม่ดำเนินการ** | รายงานถูกปิด **โดยที่คอมเมนต์ยังแสดงอยู่** |

⚠️ เดิมทั้งสองอย่างใช้คำว่า **"ปัดตก"** ร่วมกัน ซึ่งเป็นศัพท์ภายในที่ผู้ใช้อ่านไม่ออก
และทำให้สองความหมายที่ต่างกันสุดขั้วดูเหมือนอันเดียวกัน — **ห้ามใช้คำนี้ใน UI อีก**
(ตัวอักษร "ปัดตก" ยังเหลือได้เฉพาะใน *คอมเมนต์อธิบายประวัติการแก้* เท่านั้น)

| `vice_discipline` | รองวินัย |

## 5. ถ้อยคำบนปุ่ม/หัวข้อ

| กฎ | ตัวอย่าง |
|---|---|
| ปุ่ม = **คำกริยาสั้น** ไม่มี "+" และไม่ผสมสองการกระทำ | "แจ้งเรื่อง" ไม่ใช่ "+ แจ้งเรื่อง / ความคิดเห็น" |
| งานรอง (ตั้งเวลา/มอบหมาย) อยู่ใน `⋯` ไม่ต่อท้ายชื่อปุ่มหลัก | "รับเรื่อง" (แล้วตั้งเวลาใน sheet) |
| ห้าม `uppercase` + `tracking-*` กับ **ข้อความไทย** | ภาษาไทยไม่มีตัวพิมพ์ใหญ่ — ตัวอักษรจะลอยห่างกันอ่านยาก |
| ไม่มี eyebrow ภาษาอังกฤษนำหน้าชื่อหน้า | ~~MY REPORTS~~ · ~~STUDENT VOICE~~ · ~~INBOX~~ |
| ข้อความ empty บอก **สถานะเดียว** | "ไม่มีรายงานค้าง" ไม่ใช่ "ไม่มีรายงานค้าง — นักเรียนยังไม่แจ้ง หรือสภาจัดการหมดแล้ว" |

## 6. วันที่และเวลา

ใช้ `src/datetime.ts` เท่านั้น — ปีเป็น **พ.ศ.** และเวลาเป็น `Asia/Bangkok` เสมอ

🔴 **ห้าม `toISOString()` เพื่อ *แสดงผล* เด็ดขาด** — มันคืน UTC (ไม่ใช่ `Asia/Bangkok`) และ ค.ศ. (ไม่ใช่ พ.ศ.)
⇒ ผู้ใช้จะเห็นเวลาผิด 7 ชั่วโมงและปีผิดศักราช

✅ **ข้อยกเว้นเดียวที่อนุญาต:** ใช้เป็น *ค่าที่ไม่ถูกนำไปแสดง* — ปัจจุบันมี 2 จุดในเรพ
(`Dashboard.vue` เก็บ ISO ไว้แล้วโชว์ผ่าน `fmtDateTime` · `NotificationCenter.vue` ใช้เป็น
ธง "อ่านแล้ว") ⇒ **ถ้าจะเพิ่มจุดใหม่ ต้องมีคอมเมนต์กำกับว่าทำไมไม่ผ่าน `datetime.ts`**
(ของเดิมเขียนกฎสั้น ๆ ว่า "ห้าม `toISOString()`" ซึ่งกว้างเกินความจริงที่มีอยู่แล้ว)

- ปีนี้ → ตัดปี · ต่างปี → ใส่ปี · ไม่มีเลข 0 นำหน้าวัน
- "น." ใช้หรือไม่ใช้ ให้ตรงกันทั้งแอป
