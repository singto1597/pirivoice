# ข้อมูลนักเรียนและประวัติ

หานักเรียน ตั้งตำแหน่งในห้อง ใส่หน้าที่ให้กรรมการ และย้อนดูประวัติข้ามปี
ทั้งหมดอยู่ที่หน้าเดียว คือ **สมาชิก**

- ค้นด้วยชื่อ นามสกุล หรือรหัสนักเรียน
- เปลี่ยนตำแหน่งได้ทันที สิทธิ์เปลี่ยนตามทันที
- ดูข้ามปีได้ แต่ต้องพิมพ์คำค้นก่อน

**ทางเข้า:** แท็บ **เพิ่มเติม** ➔ กลุ่ม **ผู้ดูแล** ➔ **สมาชิก** ➔ แท็บ **นักเรียน**

## ใครใช้บทนี้

คนที่มีสิทธิ์ `MANAGE_STUDENTS` ได้แก่ ผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา ครูทั่วไป ประธานระดับ และผู้ช่วยหัวหน้าระดับ
แต่ละคนเห็นไม่เท่ากัน ดูหัวข้อ **ขอบเขตที่แก้ไขได้** ด้านล่าง

ก่อนเริ่ม ต้องมีชื่อในรายชื่อสมาชิกของปีนี้
และตั้งตำแหน่งได้ไม่สูงกว่าตำแหน่งของตัวเอง ยกเว้นผู้ดูแลระบบ

## หานักเรียนในปีปัจจุบัน

1. **เลือกห้อง** จากช่อง **ทุกห้อง** ถ้ารู้ว่าอยู่ห้องไหน
2. **พิมพ์ชื่อ นามสกุล หรือรหัสนักเรียน** ลงช่องค้นหา
3. **กด ค้นหา**

รายการเรียงตามรหัสห้องแล้วตามเลขที่ในห้อง
บนมือถือแสดงเป็นการ์ด บนจอคอมแสดงเป็นตาราง **เลขที่** **รหัสนักเรียน** **ชื่อ-นามสกุล** **ห้อง** **ตำแหน่ง**

ช่องค้นหาอ่านชื่อ นามสกุล และรหัสนักเรียน แต่ไม่ค้นชื่อเล่น
หน้ารายชื่อไม่มีปุ่มแบ่งหน้า เพราะแสดงทั้งชุดในขอบเขตของเราอยู่แล้ว

## หาคนที่จบไปแล้ว

**ทางเข้า:** **สมาชิก** ➔ แท็บ **นักเรียน** ➔ เปลี่ยนช่องปีเป็น **ทุกปี (ค้นข้ามปี)** ➔ พิมพ์ชื่อหรือรหัส ➔ **ค้นหา**

ระบบไม่ยอมค้นข้ามปีถ้าไม่พิมพ์คำค้น และจะตอบว่า **ต้องพิมพ์คำค้นก่อน**
เพราะดึงรายชื่อทุกปีทั้งโรงเรียนพร้อมกันจะช้า และไม่ใช่สิ่งที่เราต้องการจริง ๆ

ถ้าอยากดูรุ่นใดรุ่นหนึ่ง เลือกปีการศึกษาจากช่องเดียวกัน
รายการจะเหลือแค่แถวของปีนั้น รวมถึงคนที่จบหรือถูกเปลี่ยนสถานะไปแล้ว

## เปลี่ยนตำแหน่งในห้อง

ใช้ตอนตั้งหัวหน้าห้อง รองฝ่าย ประธานระดับ หรือสภานักเรียน

1. **เปิด ตำแหน่งปัจจุบัน** ของนักเรียน
2. **เลือกตำแหน่งใหม่**
3. **กด บันทึก**

ตำแหน่งที่เลือกได้มี 10 แบบ คือ **นักเรียน** **หัวหน้าห้อง** **รองวิชาการ** **รองวินัย** **รองกิจกรรม** **รองปฏิคม** **ประธานระดับ** **ผู้ช่วยหัวหน้าระดับ** **สภานักเรียน** และ **ประธานสภา**

บันทึกแล้วระบบคำนวณสิทธิ์ใหม่ทันที
แต่ถ้าได้ตำแหน่งระดับสภา ต้องกดออกจากระบบแล้วเข้าใหม่ เมนูของสภาจึงจะขึ้น

*กดป้ายตำแหน่งของนักเรียนเพื่อเปิดรายการตำแหน่งที่ตั้งได้*

## ตั้งหน้าที่ให้กรรมการ

หน้าที่คือหมวดงานที่กรรมการคนนั้นรับผิดชอบ และใช้กำหนดว่าเรื่องประเภทไหนจะวิ่งมาถึงเขา
ตั้งได้เฉพาะตำแหน่ง **สภานักเรียน** และ **ผู้ช่วยหัวหน้าระดับ**

**ทางเข้า:** **สมาชิก** ➔ แท็บ **เจ้าหน้าที่** ➔ **แก้ไข** ที่แถวของคนนั้น ➔ เลือก **ตำแหน่ง** ➔ ติ๊กหมวด **หน้าที่** ➔ **บันทึก**

หมวดหน้าที่มี 9 หมวด คือ **วิชาการ** **ปฏิคม** **กิจกรรม** **วินัย** **ประชาธิปไตย** **สุขภาวะทางกาย** **สุขภาวะทางใจ** **ร้องทุกข์** และ **ร้องเรียน**

เปลี่ยนตำแหน่งเป็นแบบที่ไม่มีหน้าที่ ระบบจะล้างหน้าที่เดิมให้เอง
ส่วนตำแหน่ง **ครู** และ **ผู้ดูแลระบบ** ตั้งจากหน้าจอนี้ไม่ได้

## เพิ่มบัญชีนักเรียนเอง

ใช้เมื่อนำเข้าจาก Excel ไม่ครบ หรือมีคนย้ายเข้ามากลางปี

1. **กด เพิ่มผู้ใช้งาน**
2. **กรอก รหัสนักเรียน / Username** (จำเป็น)
3. **กรอก รหัสผ่าน** หรือปล่อยว่าง
4. **กรอก คำนำหน้า ชื่อ นามสกุล ชื่อเล่น**
5. **เลือก ห้อง และ ตำแหน่ง**
6. **ติ๊ก หน้าที่** ถ้าตำแหน่งนั้นรองรับ
7. **กด เพิ่มผู้ใช้งาน**

::: tip ใส่รหัสนักเรียนลงช่องรหัสผ่านเองจะปลอดภัยกว่า
ถ้าปล่อยว่าง ระบบจะสุ่มรหัสให้ และไม่มีใครเห็นรหัสนั้นเลยจนกว่าผู้ดูแลจะรีเซ็ต
นักเรียนจะเข้าไม่ได้ในวันแรก พิมพ์รหัสนักเรียนลงไปเลยจะง่ายกว่า
:::

ห้องที่เลือกได้จำกัดตามระดับชั้นของเรา คนที่ดูแลระดับหนึ่งจะไม่เห็นห้องของระดับอื่น

## ขอบเขตที่แก้ไขได้

| ผู้ใช้ | เห็นใคร | ตั้งตำแหน่งได้ |
|---|---|---|
| ผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา | ทั้งโรงเรียน | ทุกตำแหน่ง |
| ครูทั่วไป | เฉพาะระดับชั้นที่ดูแล | ทุกตำแหน่งในระดับชั้นนั้น |
| ประธานระดับ ผู้ช่วยหัวหน้าระดับ | เฉพาะระดับชั้นของตัวเอง | ตำแหน่งระดับ 2 ลงมา ไม่รวมสภานักเรียนและประธานสภา |

ทำเกินขอบเขต ระบบจะตอบแบบนี้

- **คุณไม่มีขอบเขตสิทธิ์ในการจัดการนักเรียน** — บัญชีมีสิทธิ์ แต่หาขอบเขตไม่เจอ
- **คุณจัดการได้เฉพาะระดับ ม.4** — เป้าหมายอยู่นอกระดับชั้นของเรา
- **คุณไม่สามารถตั้งตำแหน่งที่สูงกว่าตัวเองได้** — ตั้งตำแหน่งสูงกว่าตำแหน่งปัจจุบัน
- **คุณไม่สามารถจัดการตำแหน่งที่สูงกว่าได้** — แก้ไขคนที่ตำแหน่งสูงกว่าเรา

## ดูประวัติข้ามปี

**ทางเข้า:** แท็บ **เพิ่มเติม** ➔ **ย้ายห้องนักเรียน** ➔ ค้นหานักเรียน ➔ **ประวัติ** ที่แถวของคนนั้น

ประวัติแสดงทุกปีที่มีชื่อในระบบ รวมปีที่จบไปแล้ว
พร้อมห้อง เลขที่ ตำแหน่ง สถานะ และรายการย้ายห้องทั้งหมด

## ระบบทำอะไรเบื้องหลัง

- เปลี่ยนตำแหน่งแล้วคำนวณ `permissions` และ `is_admin` ใหม่จาก `config/roles.json` ทุกครั้ง ไม่ได้คัดลอกจากแถวเดิม
- เปลี่ยนเป็นตำแหน่งที่ไม่มีหน้าที่ ระบบล้าง `responsibilities` ให้ว่าง
- เปลี่ยนเป็น **ครู** โดยไม่ระบุระดับชั้น ระบบใช้ระดับชั้นของห้องนั้นเป็น `staff_level`
- รหัสนักเรียนต้องไม่ซ้ำในห้องและปีเดียวกัน ระบบตอบ **รหัสนักเรียน ... มีอยู่ในห้องนี้แล้ว (ปีเดียวกัน)**
- แก้รหัสนักเรียนผ่าน API แล้วไม่เปลี่ยนชื่อผู้ใช้ที่ใช้ล็อกอิน เพื่อไม่ให้เข้าไม่ได้
- เพิ่มบัญชีใหม่บันทึกเป็น `CREATE_STUDENT` ส่วนการแก้ไขบันทึกเป็น `UPDATE_STUDENT`
- ค้นชื่อแบบไม่สนตัวพิมพ์เล็กใหญ่ และเรียงตามรหัสห้องก่อนเลขที่
- ประวัติข้ามปีผูกด้วยบัญชีผู้ใช้ ไม่ใช่รหัสนักเรียน

## ข้อจำกัดและข้อควรระวัง

- หน้าจอแก้ชื่อ นามสกุล คำนำหน้า เลขที่ และรหัสนักเรียนไม่ได้ ต้องใช้ `PATCH /api/students/{student_id}`
- หน้าจอเปลี่ยนสถานะเป็น **รออนุมัติ** หรือ **พักการเรียน** ไม่ได้
- ไม่มีปุ่มลบนักเรียนจากหน้าจอ
- ส่งออกรายชื่อเป็น Excel หรือ PDF ไม่ได้
- ค้นข้ามปีต้องพิมพ์คำค้นก่อนเสมอ
- ครูและประธานระดับเห็นเฉพาะระดับชั้นของตัวเอง แม้เลือกปีเก่าก็ยังติดขอบเขตเดิม
- ชื่อเล่นค้นได้เฉพาะหน้า **เจ้าหน้าที่** ซึ่งกรองในเบราว์เซอร์

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: ค้นชื่อแล้วไม่เจอ แต่รู้ว่ามีคนนี้ในระบบ?**

👉 **วิธีแก้:** ดูช่องปีว่ายังเป็น **ปีปัจจุบัน** อยู่ไหม คนที่จบหรืออยู่ปีเก่าจะไม่ขึ้น จนกว่าเลือก **ทุกปี (ค้นข้ามปี)** พร้อมพิมพ์คำค้น

**Q: เปลี่ยนตำแหน่งแล้วเมนูไม่ขึ้น?**

👉 **วิธีแก้:** ให้คนนั้นออกจากระบบแล้วเข้าใหม่ เพราะสิทธิ์คำนวณตอนโหลดโปรไฟล์ และเช็กด้วยว่าตำแหน่งนั้นมีสิทธิ์ที่ต้องการจริงตาม [คู่มือเจ้าหน้าที่](index.md)

**Q: ตั้งตำแหน่งสภานักเรียนให้นักเรียนในระดับตัวเองไม่ได้?**

👉 **วิธีแก้:** ประธานระดับและผู้ช่วยหัวหน้าระดับตั้งได้ไม่เกินตำแหน่งระดับ 2 ต้องให้ครูสภานักเรียน ผู้ดูแลระบบ หรือประธานสภาตั้งให้

**Q: เพิ่มผู้ใช้แล้วนักเรียนรู้รหัสผ่านไม่ได้?**

👉 **วิธีแก้:** กรณีเว้นช่องรหัสผ่าน ระบบสุ่มรหัสและไม่แสดงให้ใครเห็น ให้ผู้ดูแลระบบตั้งรหัสใหม่ หรือลบแล้วเพิ่มใหม่โดยพิมพ์รหัสนักเรียนเป็นรหัสผ่าน

**Q: แก้ชื่อนักเรียนผิด ต้องทำยังไง?**

👉 **วิธีแก้:** หน้าจอยังไม่มีฟอร์มแก้ชื่อ ให้แจ้งผู้ดูแลระบบใช้ `PATCH /api/students/{student_id}` หรือแก้ผ่านการนำเข้า Excel ตาม [นำเข้านักเรียนจาก Excel](student-import.md)

**Q: ทำไมเห็นรายชื่อน้อยกว่าที่คิด?**

👉 **วิธีแก้:** ระบบตัดตามขอบเขตระดับชั้นและตำแหน่งก่อนแสดงผล คนที่ตำแหน่งสูงกว่าจะไม่ขึ้นในรายการของประธานระดับ
