# ย้ายห้องและถอดนักเรียนออกจากห้อง

ใช้ตอนสลับห้องกลางปี มีนักเรียนย้ายเข้า หรือต้องเคลียร์ห้องก่อนอัปโหลดรายชื่อชุดใหม่
ย้ายได้ทีละคน หลายคน หรือยกทั้งห้อง

- ย้ายได้เฉพาะนักเรียนของปีปัจจุบัน
- ไม่มีปุ่มย้อนกลับ ถ้าย้ายผิดต้องย้ายกลับเอง
- ถอดจากห้องแล้วบัญชียังใช้ได้ แค่ไม่มีห้อง

**ทางเข้า:** แท็บ **เพิ่มเติม** ➔ กลุ่ม **ผู้ดูแล** ➔ **ย้ายห้องนักเรียน**

## ใครใช้บทนี้

คนที่ย้ายนักเรียนได้ คือผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา ครูทั่วไป ประธานระดับ และผู้ช่วยหัวหน้าระดับ
ครูและประธานระดับย้ายได้เฉพาะห้องในระดับชั้นของตัวเอง

ก่อนเริ่ม ต้องมีปีการศึกษาปัจจุบัน และรู้ว่าห้องต้นทางกับห้องปลายทางคือห้องไหน
ห้องปลายทางต้องยังใช้งานอยู่และไม่ถูกลบ

## ย้ายรายคนหรือหลายคน

1. **กรองด้วยช่องห้อง หรือค้นหารหัส/ชื่อ**
2. **ติ๊กช่องหน้าชื่อ** คนที่ต้องการ
3. **เลือก ห้องปลายทาง** ที่แถบติดขอบล่าง
4. **กด + เหตุผล** ถ้าอยากบันทึกไว้ (สูงสุด 200 ตัวอักษร)
5. **กด ย้าย** แล้วยืนยัน **ย้ายเลย**

ผลลัพธ์จะขึ้นว่า **ย้ายสำเร็จ N คนไป «ห้อง»** พร้อมจำนวนที่ถูกข้ามและจำนวนแถวซ้ำที่ถูกแทนที่

คนที่อยู่ในห้องปลายทางอยู่แล้วจะถูกข้าม ไม่นับเป็นความผิดพลาด
กด **เลือกทั้งหมด** เพื่อเลือกทุกคนตามตัวกรองที่ตั้งไว้ และ **ล้างที่เลือก** เพื่อเริ่มใหม่
พอเปลี่ยนตัวกรอง รายการที่เลือกจะถูกล้างให้เอง เพราะคนที่หลุดจากรายการไม่ควรค้างอยู่ในชุดที่เลือก

หน้านี้รวมการ์ดย้ายทั้งห้องไว้ด้านบน และรายการนักเรียนพร้อมช่องติ๊กด้านล่าง

![ภาพที่ 1 — หน้าย้ายห้องนักเรียน](../assets/screenshots/staff/student-moves.webp)
*หมายเลข 1 กับ 2 คือห้องต้นทางและปลายทาง หมายเลข 3 คือปุ่ม ย้ายทั้งห้อง และหมายเลข 4 คือ เลือกทั้งหมด*

## ย้ายทั้งห้องพร้อมกัน

ใช้ตอนสลับห้องทั้งระดับ หรือรวมสองห้องเข้าด้วยกัน

1. **ที่การ์ด ย้ายทั้งห้อง เลือก ห้องต้นทาง**
2. **รอข้อความ** **ห้อง «ม.4/1» มี N คน**
3. **เลือก ห้องปลายทาง**
4. **กด ย้ายทั้งห้อง** แล้วตรวจจำนวนก่อนยืนยัน

เลือกห้องปลายทางเป็นห้องเดียวกับต้นทางไม่ได้
ระบบบันทึกประวัติให้ทุกคนเหมือนย้ายทีละคน

## ถอดนักเรียนออกจากห้อง

ใช้ตอนเคลียร์ห้องก่อนอัปโหลดรายชื่อชุดใหม่ หรือมีคนลาออกกลางปี

**ทางเข้า:** ติ๊กนักเรียน ➔ **ถอดห้อง** ที่แถบด้านล่าง ➔ อ่านคำเตือน ➔ **ถอดออกจากห้อง**

ผลจะขึ้นว่า **ถอดออกจากห้องแล้ว N คน** พร้อมจำนวนที่ถูกข้ามเพราะไม่มีห้องอยู่แล้ว
คนที่ถูกถอดจะติดป้าย **ไม่มีห้อง** ในรายการ

การถอดไม่ลบบัญชี คนนั้นยังเข้าสู่ระบบได้ แต่ไม่มีห้องและไม่มีตำแหน่งในห้อง

## ดูประวัติการย้ายของนักเรียน

**ทางเข้า:** **ประวัติ** ที่แถวของนักเรียน

ประวัติแบ่งเป็นสองส่วน

- **รายปี** — ปี ห้อง เลขที่ และสถานะของแต่ละปี
- **การย้ายห้อง** — ห้องต้นทาง ห้องปลายทาง เวลา คนสั่ง และเหตุผล

ประวัตินี้รวมปีที่จบไปแล้วด้วย และเห็นการย้ายทุกครั้งที่ทำจากหน้านี้

## ระบบทำอะไรเบื้องหลัง

- ทุกครั้งที่ย้าย ระบบเก็บประวัติไว้ พร้อมห้องต้นทาง ห้องปลายทาง ปี คนสั่ง และเหตุผล
- ระบบล็อกแถวนักเรียนด้วย `FOR UPDATE` ระหว่างย้าย กันย้ายชนกัน
- ถ้าคนเดียวกันมีแถว active ในห้องอื่นของปีเดียวกัน ระบบปิดแถวเดิมเป็น `superseded`
- ย้ายกลับห้องเดิม ระบบปลุกแถวเดิมในห้องปลายทางกลับมาเป็น `active` และปิดแถวต้นทาง
- ถ้าห้องปลายทางมีแถวของคนนี้ที่ไม่ได้ใช้งานอยู่ ระบบข้ามแถวนั้นและแจ้งเหตุผล
- ถอดห้องแล้วระบบล้างห้องให้ว่าง รีเซ็ตตำแหน่งในห้องเป็น **นักเรียน** และล้างหน้าที่
- บทบาทระดับโรงเรียน ได้แก่ ผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา และสภานักเรียน คงตำแหน่งเดิมเมื่อไม่มีห้อง
- ครูคงตำแหน่งเดิมเมื่อไม่มีห้อง เพราะขอบเขตมาจากระดับชั้นที่ดูแล ไม่ใช่ห้อง
- ทุกการย้ายและการถอดบันทึกการใช้งานเป็น `MOVE_STUDENTS` และ `UNASSIGN_STUDENTS`

## ข้อจำกัดและข้อควรระวัง

::: warning ย้ายผิดแล้วไม่มีปุ่มย้อนกลับ
ต้องเลือกคนเดิมแล้วย้ายกลับเข้าห้องที่ถูกด้วยมือ
ระบบจะบันทึกประวัติทั้งสองครั้งไว้ให้ตรวจย้อนหลัง
:::

- ย้ายได้เฉพาะนักเรียนของปีปัจจุบัน ย้ายข้ามปีต้องใช้ **เลื่อนชั้นนักเรียน**
- ครูและประธานระดับต้องมีสิทธิ์ทั้งห้องต้นทางและห้องปลายทางในระดับเดียวกัน
- ย้ายไปห้องที่ยังไม่มีในระบบไม่ได้ ต้องสร้างห้องก่อน
- ถอดได้เฉพาะคนที่มีห้องอยู่แล้ว คนที่ไม่มีห้องจะถูกข้าม
- การถอดทำให้ตำแหน่งในห้องหายไปด้วย ไม่ได้เก็บไว้รอใส่คืน
- ระบบไม่แจ้งเตือนนักเรียนเมื่อถูกย้ายหรือถูกถอดจากห้อง
- ส่งออกประวัติการย้ายเป็นไฟล์ไม่ได้

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: กดย้ายแล้วขึ้นว่าย้ายได้เฉพาะสมาชิกของปีปัจจุบัน?**

👉 **วิธีแก้:** ในรายการที่เลือกมีแถวของปีอื่นปนอยู่ ให้กลับไปที่รายการซึ่งแสดงเฉพาะปีปัจจุบันแล้วเลือกใหม่ การย้ายข้ามปีเป็นงานของ **เลื่อนชั้นนักเรียน**

**Q: ขึ้นว่าย้ายได้เฉพาะห้องในระดับ ม.4?**

👉 **วิธีแก้:** ห้องปลายทางหรือนักเรียนบางคนอยู่นอกระดับชั้นที่เราดูแล ให้เลือกห้องในระดับเดิม หรือให้ผู้ดูแลระบบเป็นคนย้าย

**Q: ย้ายแล้วนักเรียนหายจากรายการ?**

👉 **วิธีแก้:** ดูตัวกรองห้องว่ายังกรองห้องเดิมอยู่ไหม เปลี่ยนเป็น **ทุกห้อง** แล้วจะเห็นนักเรียนครบ คนนั้นย้ายไปห้องใหม่เรียบร้อยแล้ว

**Q: ย้ายทั้งห้องแล้วจำนวนไม่ตรงกับที่เห็น?**

👉 **วิธีแก้:** ตัวเลขบนการ์ดนับเฉพาะแถวปัจจุบัน ไม่นับแถวประวัติที่ถูกแทนที่ ถ้ามีคนย้ายเข้า–ออกระหว่างนั้น ให้เลือกห้องต้นทางใหม่เพื่อนับอีกครั้ง

**Q: ถอดออกจากห้องแล้วจะย้ายกลับได้ไหม?**

👉 **วิธีแก้:** ได้ เลือกคนนั้นในรายการซึ่งติดป้าย **ไม่มีห้อง** แล้วย้ายเข้าห้องที่ต้องการ ประวัติการถอดยังอยู่ในส่วน **การย้ายห้อง**

**Q: ทำไมถอดสภานักเรียนออกจากห้องไม่ได้?**

👉 **วิธีแก้:** บทบาทระดับโรงเรียนไม่ผูกกับห้อง ระบบจึงคงตำแหน่งเดิมไว้ ถ้าจะเปลี่ยนตำแหน่งให้แก้ที่หน้า **สมาชิก**

**Q: ย้ายผิดห้องแล้วต้องทำยังไง?**

👉 **วิธีแก้:** เลือกคนเดิมแล้วย้ายกลับเข้าห้องที่ถูก ระบบจะปลุกแถวเดิมกลับมาและบันทึกประวัติทั้งสองครั้ง
