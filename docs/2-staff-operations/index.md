# คู่มือเจ้าหน้าที่และสภานักเรียน

เล่มนี้สำหรับคนที่รับเรื่อง ดูแลกิจกรรม ประกาศ และข้อมูลนักเรียน
ทุกบทเขียนจากงานที่เจอจริง เช่น รับเรื่องมาแล้วต้องทำอะไรต่อ หรือจะเลื่อนชั้นทั้งโรงเรียนต้องเตรียมอะไร

- 📥 **รับเรื่องและปิดงาน** — ตั้งกำหนด ส่งต่อ ปิดเรื่อง
- 🎫 **กิจกรรมและเช็คอิน** — สร้างกิจกรรม เปิดรับสมัคร และสแกนคิวอาร์หน้างาน
- 📢 **ประกาศและรายงานเนื้อหา** — ยิงข่าวถึงทั้งโรงเรียน และตรวจคอมเมนต์ที่มีคนรายงาน
- 🗂️ **ข้อมูลนักเรียน** — นำเข้าจาก Excel ย้ายห้อง เลื่อนชั้น และกระทบยอดรายชื่อ

## ใครได้เล่มนี้ไปใช้

| กลุ่ม | ตำแหน่ง | งานหลัก |
|---|---|---|
| คณะกรรมการห้อง | หัวหน้าห้อง รองวิชาการ รองวินัย รองกิจกรรม รองปฏิคม | รับเรื่องระดับห้อง ส่งต่อ ปิดเรื่อง |
| ระดับชั้น | ประธานระดับ ผู้ช่วยหัวหน้าระดับ | รับเรื่องระดับชั้น ดูแลนักเรียนในระดับ |
| สภานักเรียน | สภานักเรียน ประธานสภา ครูสภานักเรียน | อนุมัติบอร์ด ดูแลประกาศ กิจกรรม และรายงาน |
| ครู | ครูทั่วไป | ดูเรื่องและแดชบอร์ดตามระดับชั้น |
| ผู้ดูแลระบบ | ผู้ดูแลระบบ | ทุกงานในเล่มนี้ และงานในเล่ม 3 |

สิทธิ์มาจากตำแหน่งในปีการศึกษาปัจจุบัน ไม่ได้มาจากบัญชีผู้ใช้อย่างเดียว
ถ้าเพิ่งได้ตำแหน่งมาใหม่ ให้เช็กก่อนว่ามีชื่ออยู่ในรายชื่อสมาชิกของปีนี้แล้วหรือยัง

## วันแรกเริ่มยังไง

1. **เข้าสู่ระบบ** ด้วยรหัสนักเรียนหรือชื่อผู้ใช้ที่ได้รับ
2. **กดแท็บ เพิ่มเติม** แล้วดูว่ามีเมนูของงานที่เราต้องทำหรือยัง
3. **เปิด แท็บ เรื่อง ➔ ที่รับผิดชอบ** เพื่อดูคิวงานที่ยังรออยู่
4. **กลับไปหน้าแรก** ดูบล็อก **รอฉันตอบ** ว่ามีอะไรค้าง
5. **เปิดบทที่ตรงกับงาน** แล้วทำตามขั้นตอนได้เลย

## เมนูที่ใช้บ่อยอยู่ไหน

ทั้งหมดอยู่ในแท็บ **เพิ่มเติม**

**กลุ่ม ผู้ดูแล**

- **แดชบอร์ด**
- **จัดการรายงาน**
- **สมาชิก**
- **ย้ายห้องนักเรียน**

**กลุ่ม โรงเรียน**

- **จัดการประกาศ**
- **ปีการศึกษา**
- **เลื่อนชั้นนักเรียน**
- **กระทบยอดรายชื่อ**
- **ภาคเรียน**
- **เรื่องที่ผู้รับหมดวาระ**
- **บันทึกการใช้งาน**

อีกสองที่ไม่ได้อยู่ในเมนู เพราะซ่อนอยู่ในหน้างานที่เกี่ยวข้อง

- **เจ้าหน้าที่** กับ **นำเข้านักเรียน** อยู่ในหน้า **สมาชิก**
- **จัดการกิจกรรม** คือแท็บ **จัดการ** ในหน้า **กิจกรรม**

เมนูที่ไม่มีสิทธิ์จะถูกซ่อนไปเลย ไม่ใช่โชว์แล้วกดไม่ได้ ถ้าไม่เห็นแปลว่ายังไม่มีสิทธิ์ข้อนั้น

## สิทธิ์ที่เล่มนี้พูดถึง

- `RECEIVE_ISSUES` — รับเรื่องในระดับของเรา
- `MANAGE_ISSUE_STEPS` — เพิ่มและปิดขั้นตอนในเรื่อง
- `SET_COUNTDOWN` — ตั้งและยืดกำหนดแก้ไข
- `ESCALATE_ISSUE` — ส่งต่อเรื่องขึ้นระดับบน
- `VIEW_LEVEL_PYRAMID` — เห็นเรื่องในระดับที่ดูแลอยู่
- `MANAGE_ANNOUNCEMENTS` — สร้าง แก้ และปลดระวางประกาศ
- `MANAGE_EVENTS` — สร้างกิจกรรมและสแกนเช็คอิน
- `MANAGE_STUDENTS` — ดูและแก้ข้อมูลนักเรียนในขอบเขต
- `VIEW_DASHBOARD` — เปิดแดชบอร์ด
- `MANAGE_SETTINGS` — ตั้งค่าปี ภาค และระบบ
- `VIEW_AUDIT_LOG` — เปิดบันทึกการใช้งาน

คนที่มี `is_admin` ในบทบาทจะข้ามการตรวจสิทธิ์รายข้อไปเลย
บทบาทที่มีสถานะนี้คือ **ประธานสภา** **ครูสภานักเรียน** และ **ผู้ดูแลระบบ**

## กติกาที่ทุกคนถือเหมือนกัน

- ทุกการเปลี่ยนแปลงสำคัญถูกบันทึกใน **บันทึกการใช้งาน** พร้อมชื่อคนทำและเวลา
- งานที่ปิดแล้วกู้คืนจากหน้าจอไม่ได้ ต้องให้ผู้ดูแลระบบแก้ที่ฐานข้อมูล
- ข้อมูลนักเรียนจริงห้ามคัดลอกออกนอกระบบ
- เรื่องที่แจ้งแบบไม่ระบุตัวตน ซ่อนชื่อจากคนทั่วไป แต่คนที่ต้องลงมือแก้ยังเห็นข้อมูลเท่าที่จำเป็น
- ไม่แน่ใจ ให้ส่งต่อหรือถามผู้ดูแลระบบก่อนกดปิดเรื่อง

::: warning ปิดเรื่องแล้วย้อนกลับไม่ได้
กดปิดหรือกดปฏิเสธเรื่องแล้ว ต้องให้ผู้ดูแลระบบแก้ที่ฐานข้อมูลเท่านั้น
ถ้ายังลังเล ให้คุยกับคนในทีมก่อนกด
:::

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: เข้าเมนูจัดการกิจกรรมไม่ได้?**

👉 **วิธีแก้:** บัญชีอาจยังไม่มีสิทธิ์ `MANAGE_EVENTS` หรือยังไม่มีชื่อในรายชื่อสมาชิกของปีนี้ ให้ผู้ดูแลระบบเช็กตำแหน่งและปีการศึกษาที่ผูกกับบัญชี

**Q: เห็นเรื่องน้อยกว่าที่คิด?**

👉 **วิธีแก้:** คิว **ที่รับผิดชอบ** แสดงเฉพาะเรื่องในระดับและขอบเขตของเรา เรื่องของห้องอื่นจะไม่ขึ้น ถ้าเห็นน้อยกว่าที่ควรให้ถามผู้ดูแลระบบว่าสิทธิ์ถูกต้องไหม

**Q: ต้องรอผู้ดูแลระบบทุกครั้งไหม?**

👉 **วิธีแก้:** ไม่ต้อง งานประจำอย่างรับเรื่อง ปิดเรื่อง ประกาศกิจกรรม และสแกนเช็คอิน ทำเองได้เลย จะใช้ผู้ดูแลระบบเฉพาะงานที่กระทบทั้งโรงเรียนหรือต้องกู้คืนข้อมูล

**Q: ทำผิดแล้วย้อนกลับได้ไหม?**

👉 **วิธีแก้:** แล้วแต่ชนิดงาน การปิดเรื่องและการเลื่อนชั้นย้อนจากหน้าจอไม่ได้ ส่วนงานที่ยังไม่ปิดแก้ไขหรือส่งต่อได้ ตรวจให้ดีก่อนกดยืนยันทุกครั้ง

**Q: ทำงานพวกนี้จากมือถือได้ไหม?**

👉 **วิธีแก้:** ได้เกือบทั้งหมด รวมถึงสแกนเช็คอินและย้ายห้อง แต่การนำเข้า Excel กับการเลื่อนชั้นทำบนจอคอมพิวเตอร์จะถนัดกว่า

**Q: ข้อมูลในคู่มือไม่ตรงกับหน้าจอ?**

👉 **วิธีแก้:** ระบบอาจอัปเดตหลังคู่มือเขียน ให้ยึดหน้าจอจริงเป็นหลัก แล้วแจ้งผู้ดูแลระบบพร้อมชื่อหน้าและข้อความที่เห็น
