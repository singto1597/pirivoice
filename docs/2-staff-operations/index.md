# คู่มือเจ้าหน้าที่และสภานักเรียน

เล่มนี้สำหรับผู้ที่รับเรื่อง ดูแลกิจกรรม ประกาศ เนื้อหาบนบอร์ด และข้อมูลนักเรียน
ทุกบทเขียนจากสถานการณ์ทำงานจริง เช่น รับเรื่องแล้วต้องทำอะไรต่อ หรือจะเลื่อนชั้นทั้งโรงเรียนต้องเตรียมอะไร

## ใครใช้เล่มนี้

| กลุ่ม | ตำแหน่ง | งานหลัก |
|---|---|---|
| คณะกรรมการห้อง | หัวหน้าห้อง รองวิชาการ รองวินัย รองกิจกรรม รองปฏิคม | รับเรื่องระดับห้อง ส่งต่อ ปิดเรื่อง |
| ระดับชั้น | ประธานระดับ ผู้ช่วยหัวหน้าระดับ | รับเรื่องระดับชั้น ดูแลนักเรียนในระดับ |
| สภานักเรียน | สภานักเรียน ประธานสภา ครูสภานักเรียน | อนุมัติบอร์ด ดูแลประกาศ กิจกรรม และรายงาน |
| ครู | ครูทั่วไป | ดูเรื่องและแดชบอร์ดตามระดับชั้น |
| ผู้ดูแลระบบ | ผู้ดูแลระบบ | ทุกงานในเล่มนี้ และงานในเล่ม 3 |

ระบบกำหนดสิทธิ์จากตำแหน่งในปีการศึกษาปัจจุบัน ไม่ใช่จากบัญชีผู้ใช้อย่างเดียว
หากเพิ่งได้รับตำแหน่ง ให้ตรวจว่ามีแถวสมาชิกในปีปัจจุบันแล้วหรือยัง

## เริ่มงานวันแรก

1. เข้าสู่ระบบด้วยรหัสนักเรียนหรือชื่อผู้ใช้ที่ได้รับ
2. เปิด **เพิ่มเติม** แล้วตรวจว่าเห็นเมนูที่งานของคุณต้องใช้
3. เปิด **เรื่อง** แล้วเลือก **ที่รับผิดชอบ** เพื่อดูคิวงาน
4. เปิด **หน้าแรก** เพื่อดูบล็อก **รอฉันตอบ**
5. อ่านบทที่ตรงกับงาน แล้วทำตามขั้นตอน

## เมนูที่เจ้าหน้าที่ใช้บ่อย

เมนูทั้งหมดอยู่ในแท็บ **เพิ่มเติม**

กลุ่ม **ผู้ดูแล**

- **แดชบอร์ด**
- **จัดการรายงาน**
- **สมาชิก**
- **ย้ายห้องนักเรียน**

อีกสามหน้าอยู่ในหน้างานที่เกี่ยวข้อง ไม่ได้อยู่ในเมนู ได้แก่ **เจ้าหน้าที่** และ **นำเข้านักเรียน** ซึ่งเป็นแท็บและปุ่มในหน้า **สมาชิก** และ **จัดการกิจกรรม** ซึ่งเป็นแท็บ **จัดการ** ในหน้า **กิจกรรม**

กลุ่ม **โรงเรียน**

- **จัดการประกาศ**
- **ปีการศึกษา**
- **เลื่อนชั้นนักเรียน**
- **กระทบยอดรายชื่อ**
- **ภาคเรียน**
- **เรื่องที่ผู้รับหมดวาระ**
- **บันทึกการใช้งาน**

เมนูที่ไม่เกี่ยวข้องกับสิทธิ์ของคุณจะถูกซ่อน ไม่ใช่แสดงแล้วกดไม่ได้

## สิทธิ์ที่ใช้ในเล่มนี้

| สิทธิ์ | ใช้ทำอะไร |
|---|---|
| `RECEIVE_ISSUES` | รับเรื่องในระดับของตน |
| `MANAGE_ISSUE_STEPS` | เพิ่มและปิดขั้นตอนในเรื่อง |
| `SET_COUNTDOWN` | ตั้งและยืดกำหนดแก้ไข |
| `ESCALATE_ISSUE` | ส่งต่อเรื่องขึ้นระดับบน |
| `VIEW_LEVEL_PYRAMID` | เห็นเรื่องในระดับที่ตนดูแล |
| `MANAGE_ANNOUNCEMENTS` | สร้าง แก้ ปลดระวางประกาศ |
| `MANAGE_EVENTS` | สร้างกิจกรรมและสแกนเช็คอิน |
| `MANAGE_STUDENTS` | ดูและแก้ข้อมูลนักเรียนในขอบเขต |
| `VIEW_DASHBOARD` | เปิดแดชบอร์ด |
| `MANAGE_SETTINGS` | ตั้งค่าปี ภาค และระบบ |
| `VIEW_AUDIT_LOG` | เปิดบันทึกการใช้งาน |

ผู้ที่มี `is_admin` ในบทบาทจะข้ามการตรวจสิทธิ์รายข้อ
บทบาทที่มี `is_admin` คือ **ประธานสภา** **ครูสภานักเรียน** และ **ผู้ดูแลระบบ**

## หลักปฏิบัติร่วม

- ทุกการเปลี่ยนแปลงสำคัญถูกบันทึกใน **บันทึกการใช้งาน** พร้อมผู้ทำและเวลา
- งานที่ปิดแล้วกู้คืนจากหน้าจอไม่ได้ ต้องให้ผู้ดูแลระบบแก้ที่ฐานข้อมูล
- ข้อมูลนักเรียนจริงห้ามคัดลอกออกนอกระบบ
- การแจ้งแบบไม่ระบุตัวตนซ่อนชื่อจากผู้เปิดเรื่อง แต่ไม่ได้ซ่อนจากผู้ที่ต้องแก้ปัญหา
- หากไม่แน่ใจ ให้ส่งต่อหรือถามผู้ดูแลระบบก่อนกดปิดเรื่อง

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: เข้าเมนูจัดการกิจกรรมไม่ได้**
ตอบ: บัญชีไม่มีสิทธิ์ `MANAGE_EVENTS` หรือยังไม่มีแถวสมาชิกในปีปัจจุบัน
ให้ผู้ดูแลระบบตรวจตำแหน่งและปีการศึกษาที่ผูกกับบัญชี

**ถาม: เห็นเรื่องน้อยกว่าที่คาด**
ตอบ: คิว **ที่รับผิดชอบ** แสดงเฉพาะเรื่องในระดับและขอบเขตของคุณ
เรื่องของห้องอื่นจะไม่แสดง เว้นแต่คุณมีสิทธิ์ระดับสูงกว่า

**ถาม: ต้องรอผู้ดูแลระบบทุกครั้งหรือไม่**
ตอบ: ไม่ต้อง งานประจำ เช่น รับเรื่อง ปิดเรื่อง ประกาศกิจกรรม และสแกนเช็คอิน ทำได้เอง
ต้องใช้ผู้ดูแลระบบเฉพาะงานที่มีผลทั้งโรงเรียนหรือกู้คืนข้อมูล

**ถาม: ทำผิดแล้วย้อนกลับได้ไหม**
ตอบ: ขึ้นกับงาน การปิดเรื่องและการเลื่อนชั้นย้อนจากหน้าจอไม่ได้
งานที่ยังไม่ปิดสามารถแก้ไขหรือส่งต่อได้ ให้ตรวจก่อนกดยืนยันทุกครั้ง

**ถาม: ใช้มือถือทำงานเหล่านี้ได้ไหม**
ตอบ: ได้เกือบทั้งหมด รวมถึงสแกนเช็คอินและย้ายห้อง
งานนำเข้า Excel และการเลื่อนชั้นทำบนจอคอมพิวเตอร์ได้สะดวกกว่า

**ถาม: ข้อมูลในคู่มือไม่ตรงกับหน้าจอ**
ตอบ: ระบบอาจถูกอัปเดตหลังคู่มือเขียน ให้ยึดหน้าจอจริงและแจ้งผู้ดูแลระบบ
พร้อมระบุชื่อหน้าและข้อความที่เห็น
