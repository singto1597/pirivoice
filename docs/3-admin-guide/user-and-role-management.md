# จัดการผู้ใช้และตำแหน่ง

แต่งตั้งตำแหน่งให้สมาชิก เพิ่มคนที่ตกหล่นจากการนำเข้า และมอบหน้าที่เฉพาะทาง
รวมถึงขอบเขตว่าใครแก้ไขใครได้บ้าง

- ตั้งตำแหน่งแล้วมีผลทันที ไม่ต้องรอรอบไหน
- หน้าต่างเลือกตำแหน่งแสดงแค่ตำแหน่งที่เราตั้งได้
- ประวัติปีเก่าไม่เปลี่ยนตาม

## ใครใช้บทนี้

คนที่มีสิทธิ์ `MANAGE_STUDENTS` ได้แก่ ผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา ครูทั่วไป ประธานระดับ และผู้ช่วยหัวหน้าระดับ

ขอบเขตการจัดการแบ่งเป็นสามแบบ

| ผู้จัดการ | จัดการได้ | ข้อจำกัด |
|---|---|---|
| ผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา | ทุกคน ทุกห้อง ทุกตำแหน่ง | ไม่มี |
| ครูทั่วไป | ทุกตำแหน่งในระดับชั้นที่ดูแล (`staff_level`) | ตั้งตำแหน่งผู้บริหารหรือครูด้วยกันไม่ได้ |
| ประธานระดับ ผู้ช่วยหัวหน้าระดับ | เฉพาะตำแหน่งที่ลำดับไม่สูงกว่าตัวเอง ในระดับชั้นของตัวเอง | ตั้งสภานักเรียนหรือประธานสภาไม่ได้ |

ระบบใช้ลำดับตำแหน่งตัดสินสิทธิ์ มีห้าระดับ คือ นักเรียน (0) คณะกรรมการห้อง (1) ประธานระดับและผู้ช่วยหัวหน้าระดับ (2) สภานักเรียน (3) ประธานสภา (4)

ก่อนเริ่ม ต้องมีปีการศึกษาปัจจุบัน เพราะตำแหน่งผูกกับแถวสมาชิกของปี
และต้องรู้ชื่อหรือรหัสนักเรียนของคนที่จะแต่งตั้ง พร้อมเช็กว่าห้องของคนนั้นมีอยู่ในปีนี้

## ตำแหน่งทั้ง 13 แบบ

| รหัส | ชื่อที่แสดง | `is_admin` | ความสามารถหลัก |
|---|---|---|---|
| `student` | นักเรียน | ไม่ | แจ้งเรื่อง ดูเรื่องของตัวเอง |
| `class_president` | หัวหน้าห้อง | ไม่ | รับเรื่องระดับห้อง ตั้งกำหนด ส่งต่อ |
| `vice_academic` | รองวิชาการ | ไม่ | เหมือนหัวหน้าห้อง |
| `vice_discipline` | รองวินัย | ไม่ | เหมือนหัวหน้าห้อง |
| `vice_activity` | รองกิจกรรม | ไม่ | เหมือนหัวหน้าห้อง |
| `vice_reception` | รองปฏิคม | ไม่ | เหมือนหัวหน้าห้อง |
| `level_president` | ประธานระดับ | ไม่ | รับเรื่องระดับชั้น จัดการสมาชิกในระดับ |
| `level_vice_president` | ผู้ช่วยหัวหน้าระดับ | ไม่ | เหมือนประธานระดับ และรับหน้าที่เฉพาะทางได้ |
| `council_member` | สภานักเรียน | ไม่ | รับเรื่องทั้งโรงเรียน ดูแลประกาศ เปิดแดชบอร์ด |
| `council_president` | ประธานสภา | ใช่ | ทุกอย่าง รวมถึงตั้งค่าและดูบันทึกการใช้งาน |
| `teacher_council` | ครูสภานักเรียน | ใช่ | เทียบเท่าประธานสภา |
| `teacher` | ครู | ไม่ | ดูแลสมาชิกและเรื่องในระดับชั้นที่ระบุ |
| `admin` | ผู้ดูแลระบบ | ใช่ | ทุกอย่าง |

ชื่อไทยของตำแหน่งมาจาก `frontend/src/constants/roles.ts` ซึ่งเป็นไฟล์เดียวกับที่หน้าจอใช้แสดง
ส่วนสิทธิ์และ `is_admin` มาจาก `backend/config/roles.json`

## แต่งตั้งตำแหน่งให้คนเดียว

ใช้ตอนตำแหน่งในห้องเปลี่ยนกลางปี หรือหลังเลือกตั้งเสร็จ

**ทางเข้า:** แท็บ **เพิ่มเติม** ➔ กลุ่ม **ผู้ดูแล** ➔ **สมาชิก** ➔ แท็บ **นักเรียน** ➔ ค้นหาชื่อหรือรหัส ➔ กดป้ายตำแหน่งท้ายชื่อ ➔ เลือกตำแหน่งใหม่ ➔ **บันทึก**

ถ้าเลือกปีเป็น **ปีปัจจุบัน** ไว้ ก็แก้ได้แค่ปีนี้ ถ้าจะแก้ปีอื่นให้เลือกปีนั้นจากรายการ

หน้าต่างเลือกตำแหน่งจะแสดงเฉพาะตำแหน่งที่บัญชีเราตั้งได้ ถ้าตำแหน่งที่ต้องการไม่อยู่ในรายการ แปลว่าเกินขอบเขต

บันทึกแล้วจะขึ้น **บันทึกแล้ว** และป้ายตำแหน่งเปลี่ยนทันที
แต่คนที่ถูกเปลี่ยนตำแหน่งต้องรีเฟรชหน้าหรือเข้าสู่ระบบใหม่ เมนูใหม่จึงจะขึ้น

![ภาพที่ 1 — หน้าสมาชิก แท็บนักเรียน](../assets/screenshots/admin/member-roles.webp)
*กดป้ายตำแหน่งท้ายชื่อเพื่อเปิดหน้าต่างเลือกตำแหน่ง*

## ตั้งคณะกรรมการห้องทั้งชุด

หน้าจอไม่มีปุ่มตั้งหลายคนพร้อมกัน มีสองวิธีที่ใช้ได้

- **ตั้งทีละคน** ตามขั้นตอนข้างบน เหมาะกับห้องที่เปลี่ยนแค่ไม่กี่ตำแหน่ง
- **ใส่ตำแหน่งในไฟล์ Excel แล้วนำเข้าซ้ำ** ที่หน้า **นำเข้านักเรียน** เหมาะกับต้นปีที่ต้องตั้งทุกห้อง

นำเข้าซ้ำแล้วไม่เกิดนักเรียนใหม่ เพราะระบบจับคู่ด้วยรหัสนักเรียน ห้อง และปีการศึกษา แล้วอัปเดตตำแหน่งให้ตรงไฟล์
รายละเอียดอยู่ใน [นำเข้านักเรียนจาก Excel](../2-staff-operations/student-import.md)

## เพิ่มผู้ใช้ทีละคน

ใช้เมื่อมีนักเรียนตกหล่นจากไฟล์ Excel หรือมีคนย้ายเข้ามากลางปี

หน้า **เจ้าหน้าที่** รวมทุกตำแหน่งไว้ให้กรองด้วยชิป และมีปุ่ม **เพิ่มผู้ใช้งาน** อยู่มุมขวาบน

![ภาพที่ 2 — หน้าสมาชิก แท็บเจ้าหน้าที่](../assets/screenshots/admin/users-list.webp)
*วงแดงชี้แท็บ เจ้าหน้าที่ ปุ่ม เพิ่มผู้ใช้งาน ชิปกรองบทบาท และปุ่มดินสอท้ายแถวที่เป็นทางเข้าแก้ไข*

1. **เปิด สมาชิก ➔ แท็บ เจ้าหน้าที่ ➔ เพิ่มผู้ใช้งาน**
2. **กรอก รหัสนักเรียน / Username \*** เป็นรหัสนักเรียน
3. **เว้น รหัสผ่านเริ่มต้น ว่างไว้** ได้ ระบบจะสุ่มรหัสให้
4. **กรอก คำนำหน้า ชื่อ\* และ นามสกุล\*** ให้ครบ
5. **กรอก ชื่อเล่น** ถ้าอยากใส่
6. **เลือก ห้อง\*** จากรายการ ห้องต้องมีอยู่ก่อน
7. **เลือก ตำแหน่ง** ค่าเริ่มต้นคือตำแหน่งเดียวกับคนที่ล็อกอินอยู่
8. **กด เพิ่มผู้ใช้งาน** อีกครั้งที่ท้ายหน้าต่าง

กด **เพิ่มผู้ใช้งาน** แล้วหน้าต่างฟอร์มจะเปิดขึ้น — ช่องที่มีดอกจันคือช่องบังคับ

![ภาพที่ 3 — ฟอร์มเพิ่มผู้ใช้งาน](../assets/screenshots/admin/user-add.webp)
*วงแดงไล่ตั้งแต่รหัสผู้ใช้ รหัสผ่านเริ่มต้น คำนำหน้า ห้อง ตำแหน่ง ไปจนถึงปุ่ม เพิ่มผู้ใช้งาน*

::: tip ตั้งรหัสผ่านเองจะง่ายกว่า
รหัสที่ระบบสุ่มให้ไม่แสดงบนหน้าจอ ใครก็ไม่รู้
ถ้าอยากให้เข้าได้ทันที พิมพ์รหัสนักเรียนลงช่อง **รหัสผ่านเริ่มต้น** แล้วบอกนักเรียนทางส่วนตัว ไม่ใช่ในกลุ่มแชท
:::

## ให้หน้าที่เฉพาะทาง

หน้าที่คือหมวดเรื่องที่คนนั้นรับผิดชอบเพิ่มจากตำแหน่งปกติ
ใช้ได้เฉพาะ **สภานักเรียน** และ **ผู้ช่วยหัวหน้าระดับ**

**ทางเข้า:** **สมาชิก** ➔ แท็บ **เจ้าหน้าที่** ➔ เลือกกลุ่ม **สภานักเรียน** หรือ **หัวหน้าระดับ** ➔ **แก้ไข** ที่แถวของคนนั้น ➔ เลือกหมวดใน **หน้าที่ที่รับผิดชอบ** ➔ **บันทึก**

เลือกได้หลายหมวด ตรงกับหมวดย่อยของเรื่องทั้ง 9 หมวด คือ **วิชาการ** **ปฏิคม** **กิจกรรม** **วินัย** **ประชาธิปไตย** **สุขภาวะทางกาย** **สุขภาวะทางใจ** **ร้องทุกข์** และ **ร้องเรียน**

ถ้าเลือกตำแหน่งอื่นที่ไม่มีหน้าที่ หน้าต่างจะขึ้นว่า **ตำแหน่งนี้ไม่มีหมวดหน้าที่ (เฉพาะ สภานักเรียน / ผู้ช่วยหัวหน้าระดับ เท่านั้น)**
และบันทึกแล้วระบบจะล้างหน้าที่เดิมออกให้

## ค้นหาคนที่จบไปแล้ว

**ทางเข้า:** **สมาชิก** ➔ แท็บ **นักเรียน** ➔ เลือกปีเป็น **ทุกปี (ค้นข้ามปี)** ➔ พิมพ์ชื่อ นามสกุล หรือรหัส ➔ **ค้นหา**

ระบบบังคับให้พิมพ์คำค้นก่อน เพราะดึงสมาชิกทุกปีทั้งหมดจะหนักโดยไม่จำเป็น
ถ้ายังไม่พิมพ์ จะขึ้น **ต้องพิมพ์คำค้นก่อน** พร้อมคำอธิบาย **การค้นข้ามทุกปีต้องระบุชื่อ นามสกุล หรือรหัสนักเรียน**

ผลลัพธ์แสดงทุกปีที่คนนั้นเคยมีแถว รวมปีที่จบแล้ว
ใช้เช็กว่าคนที่ล็อกอินไม่ได้มีแถวปีใหม่ไหม หรือหาเลขที่เดิมก่อนย้ายห้อง

## กำหนดระดับชั้นของครู

ระดับชั้นของครู (`staff_level`) ไม่มีช่องให้เลือกแยกในหน้าจอ
ระบบตั้งให้จากระดับชั้นของห้องที่ผูกตอนสร้างบัญชีหรือตอนนำเข้า เช่นครูที่อยู่ห้อง ม.4/1 จะได้ระดับ ม.4

ถ้าต้องย้ายครูไปอีกระดับ มีสองทาง

- **แก้ห้องของครูผ่านการนำเข้า Excel** โดยระบุห้องใหม่ในระดับที่ต้องการ
- **ให้ผู้พัฒนาอัปเดต `staff_level` ที่ฐานข้อมูล**

ย้ายห้องด้วยหน้า **ย้ายห้องนักเรียน** แล้ว `staff_level` ไม่เปลี่ยน เพราะระดับชั้นที่ดูแลเป็นคนละค่ากับห้องปัจจุบัน
ถ้าย้ายห้องแล้วแดชบอร์ดยังแสดงระดับเดิม ให้เช็กค่านี้ที่ฐานข้อมูล

## ระบบทำอะไรเบื้องหลัง

- เปลี่ยนตำแหน่งแล้วคำนวณ `permissions` และ `is_admin` ใหม่จาก `config/roles.json` ทุกครั้ง ไม่ใช่เพิ่มต่อจากของเดิม
- การเปลี่ยนมีผลกับแถวของปีที่แก้เท่านั้น แถวปีเก่ายังเก็บตำแหน่งเดิมไว้เป็นประวัติ
- เปลี่ยนเป็นตำแหน่งที่ไม่มีหน้าที่ ระบบล้าง `responsibilities` ให้ว่าง
- ครูที่ถูกตั้งตำแหน่งแต่ยังไม่มี `staff_level` ระบบดึงระดับชั้นจากห้องที่ผูกอยู่ให้
- การเพิ่มผู้ใช้สร้างสองระเบียนพร้อมกัน คือบัญชีในตาราง `users` และแถวสมาชิกในตาราง `students`
- ถ้าไม่กรอก **รหัสผ่านเริ่มต้น** ระบบสุ่มรหัสยาวและตั้ง `must_change_password` เป็นจริง
- ชื่อผู้ใช้ไม่เปลี่ยนตามรหัสนักเรียน แม้จะแก้รหัสนักเรียนทีหลัง
- ระบบกันรหัสนักเรียนซ้ำในห้องและปีเดียวกัน และกันชื่อผู้ใช้ซ้ำทั้งระบบ
- ทุกการเพิ่มและแก้ไขเขียนบันทึกเป็น `CREATE_STUDENT` และ `UPDATE_STUDENT` พร้อมค่าเดิมและค่าใหม่
- ระบบไม่แจ้งเตือนคนที่ถูกเปลี่ยนตำแหน่ง

## ข้อความที่อาจเจอ

| ข้อความ | เกิดเมื่อ | ทางแก้ |
|---|---|---|
| **คุณไม่มีขอบเขตสิทธิ์ในการจัดการนักเรียน** | บัญชีไม่มีขอบเขตที่ระบบหาเจอ | ให้ผู้ดูแลระบบตรวจตำแหน่งและปีปัจจุบัน |
| **คุณจัดการได้เฉพาะระดับ …** | เลือกคนต่างระดับชั้นจากที่ดูแล | เลือกคนในระดับเดียวกันหรือให้ผู้ดูแลระบบทำ |
| **คุณไม่สามารถจัดการตำแหน่งนี้ได้** | ครูพยายามแก้ตำแหน่งครูหรือผู้บริหาร | ให้ผู้ดูแลระบบทำ |
| **คุณไม่สามารถจัดการตำแหน่งที่สูงกว่าได้** | ประธานระดับแก้คนที่ตำแหน่งสูงกว่า | ให้ผู้ดูแลระบบทำ |
| **คุณไม่สามารถตั้งตำแหน่งที่สูงกว่าตัวเองได้** | ประธานระดับพยายามตั้งสภานักเรียน | ให้ผู้ดูแลระบบทำ |
| **username '…' มีผู้ใช้อยู่แล้วในระบบ** | เพิ่มผู้ใช้ที่ชื่อซ้ำ | ใช้บัญชีเดิมหรือเปลี่ยนชื่อผู้ใช้ |
| **ไม่พบห้องเรียน …** | ห้องที่เลือกถูกลบหรือไม่มีในปีนี้ | สร้างห้องก่อนหรือเลือกห้องอื่น |
| **รหัสนักเรียน … มีอยู่ในห้องนี้แล้ว (ปีเดียวกัน)** | มีคนรหัสเดียวกันในห้องเดียวกัน | ตรวจรหัสผิดหรือย้ายคนเดิมออกก่อน |

## ข้อจำกัดและข้อควรระวัง

- ลบบัญชีผู้ใช้จากหน้าจอไม่ได้ ถ้าจะปิดการใช้งานต้องแก้ `status` ที่ฐานข้อมูล
- ไม่มีฟังก์ชันรีเซ็ตรหัสผ่านให้ผู้ใช้จากหน้าจอผู้ดูแล
- ไม่มีหน้าจอแก้ `staff_level` หรือ `is_admin` แยกจากตำแหน่ง
- ตั้งตำแหน่งได้ทีละคน ไม่มีตัวเลือกหลายคนในครั้งเดียว
- เปลี่ยนตำแหน่งแล้วไม่มีปุ่มย้อนกลับ ต้องตั้งตำแหน่งเดิมคืนเอง
- แก้ชื่อหรือรหัสนักเรียนแล้วไม่เปลี่ยนชื่อผู้ใช้ที่ใช้ล็อกอิน
- ครูทั่วไปตั้งตำแหน่งครูด้วยกันหรือตำแหน่งผู้บริหารไม่ได้ แม้อยู่นอกระดับชั้นที่ดูแล

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: ตั้งตำแหน่งแล้วผู้ใช้ยังเห็นเมนูเดิม?**

👉 **วิธีแก้:** สิทธิ์ถูกอ่านใหม่ทุกครั้งที่เรียก API แต่เมนูในเบราว์เซอร์คำนวณตอนโหลดหน้า ให้ผู้ใช้รีเฟรชหน้าหรือออกแล้วเข้าสู่ระบบใหม่

**Q: ตั้งหัวหน้าห้องให้คนที่ยังไม่มีห้องได้ไหม?**

👉 **วิธีแก้:** ได้ แต่ตำแหน่งในห้องจะไม่มีผลกับเรื่องของห้อง เพราะระบบใช้ห้องกำหนดขอบเขต ควรใส่ห้องให้ก่อนแล้วค่อยตั้งตำแหน่ง

**Q: ทำไมตำแหน่งที่ต้องการไม่ขึ้นในรายการ?**

👉 **วิธีแก้:** รายการถูกกรองตามตำแหน่งของผู้จัดการ ผู้ดูแลระบบเห็นทุกตำแหน่ง ครูเห็นเฉพาะตำแหน่งที่ไม่ใช่ผู้บริหารและครู ประธานระดับเห็นเฉพาะตำแหน่งที่ไม่สูงกว่าตัวเอง

**Q: เปลี่ยนตำแหน่งแล้วประวัติปีเก่าเปลี่ยนด้วยไหม?**

👉 **วิธีแก้:** ไม่เปลี่ยน ระบบแก้เฉพาะแถวของปีที่เลือก ประวัติปีก่อนยังแสดงตำแหน่งเดิม ซึ่งถูกต้องสำหรับการตรวจย้อนหลัง

**Q: เพิ่มผู้ใช้แล้วเขาล็อกอินไม่ได้?**

👉 **วิธีแก้:** เช็กชื่อผู้ใช้ว่าตรงกับ **รหัสนักเรียน / Username** ที่กรอกไหม ถ้าเว้นรหัสผ่านไว้ เขาต้องใช้รหัสที่ระบบสุ่ม ซึ่งไม่แสดงที่ไหน ให้สร้างบัญชีใหม่ด้วยรหัสที่กำหนดเอง หรือให้ผู้พัฒนาตั้งรหัสใหม่ที่ฐานข้อมูล

**Q: แก้รหัสนักเรียนแล้วทำไมยังต้องล็อกอินด้วยรหัสเดิม?**

👉 **วิธีแก้:** ชื่อผู้ใช้กับรหัสนักเรียนเป็นคนละค่า และการแก้รหัสนักเรียนไม่แตะชื่อผู้ใช้ เพราะเปลี่ยนชื่อผู้ใช้แล้วเจ้าของบัญชีจะเข้าไม่ได้ทันที

**Q: ครูย้ายระดับชั้นแล้วแดชบอร์ดยังแสดงระดับเดิม?**

👉 **วิธีแก้:** ค่า `staff_level` ตั้งไว้ตั้งแต่ตอนสร้างหรือนำเข้า และไม่เปลี่ยนตามการย้ายห้อง ให้แก้ค่าที่ฐานข้อมูล หรือนำเข้าครูคนนั้นใหม่พร้อมห้องในระดับที่ต้องการ

**Q: ครูประจำชั้นควรมีตำแหน่งอะไร?**

👉 **วิธีแก้:** ครูใช้ตำแหน่ง `teacher` และระบบใช้ระดับชั้นของห้องเป็นขอบเขตการดูแล ไม่ต้องตั้งเป็นหัวหน้าห้องหรือรองฝ่าย เพราะนั่นสำหรับนักเรียนในห้อง
