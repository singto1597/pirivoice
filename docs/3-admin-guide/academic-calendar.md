# ตั้งค่าปีการศึกษาและภาคเรียน

สองค่านี้ตัดสินว่าอะไรคือ "ปัจจุบัน" ของทั้งระบบ
ตั้งผิดที่เดียว ตัวเลขสถิติและรายชื่อนักเรียนจะเพี้ยนทั้งโรงเรียน

- **ปีการศึกษา** ตอบว่าใครอยู่ห้องไหน ตำแหน่งอะไร
- **ภาคเรียน** ตอบว่าสถิติครอบคลุมช่วงไหน
- ตั้งปีปัจจุบันไม่ย้ายแถวสมาชิกเดิมให้ ต้องใช้เลื่อนชั้นหรือนำเข้า

## ใครใช้บทนี้

คนที่มีสิทธิ์ `MANAGE_SETTINGS` ได้แก่ผู้ดูแลระบบ ครูสภานักเรียน และประธานสภา
ทั้งสามตำแหน่งมี `is_admin` จึงไม่ติดด่านขอบเขตระดับชั้น

## ปีการศึกษากับภาคเรียนต่างกันตรงไหน

| | ปีการศึกษา | ภาคเรียน |
|---|---|---|
| ตอบคำถามว่า | ปีนี้ใครอยู่ห้องไหน ตำแหน่งอะไร | ช่วงนี้สถิติครอบคลุมวันใด |
| ผูกกับ | แถวสมาชิกและสิทธิ์ | การกรองสถิติในหน้าแรกและหน้าสถิติ |
| มีได้กี่ค่าที่เป็นปัจจุบัน | หนึ่งค่า | หนึ่งค่า หรือไม่มีเลย |
| เปลี่ยนแล้วกระทบ | ค่าเริ่มต้นปีของสมาชิกใหม่ และรายชื่อที่แสดง | ตัวเลขสถิติและช่วงเวลาที่นับ |
| ใช้ในงาน | เลื่อนชั้น นำเข้า มอบหมายเรื่อง | รายงานสถิติตามภาค |

หนึ่งปีมีได้หลายภาค แต่ละภาคควรผูกกับปีที่มันอยู่
ระบบไม่บังคับให้ผูก และไม่ตรวจว่าช่วงวันที่ของภาคอยู่ในช่วงของปีหรือไม่

## เตรียมปีใหม่ก่อนเปิดเทอม

ทำตามลำดับนี้ ข้ามขั้นแล้วต้องไล่แก้ทีหลัง

1. **เปิด ปีการศึกษา** (แท็บ **เพิ่มเติม** ➔ **ปีการศึกษา**)
2. **ที่การ์ด ขั้นต่อไปของการขึ้นปีใหม่ กด สร้างปีการศึกษาใหม่**
3. **กรอก ปีการศึกษา (พ.ศ.)** เป็นเลขสี่หลัก เช่น 2569 (รับค่าตั้งแต่ 2400 ถึง 2700)
4. **กรอก ชื่อปีการศึกษา** ถ้าเว้นว่าง ระบบตั้งเป็น **ปีการศึกษา 2569** ให้
5. **เลือก วันเริ่มต้น และ วันสิ้นสุด** ถ้ายังไม่รู้วันเปิดเทอม เว้นว่างได้
6. **กดบันทึก**
7. **กลับมาเช็กในแท็บ ทั้งหมด** ว่าปีใหม่ขึ้นแล้ว และยังไม่มีป้าย **ปีปัจจุบัน**
8. **ทำขั้นที่เหลือตามการ์ด** คือ เลื่อนชั้น ➔ นำเข้ารายชื่อ ➔ ตรวจกระทบยอด ➔ ตั้งภาคเรียน ➔ มอบหมายเรื่องที่ผู้รับหมดวาระ

ขั้นเลื่อนชั้นและนำเข้ารายชื่อมีรายละเอียดใน [คู่มือเจ้าหน้าที่](../2-staff-operations/index.md)
การตั้งภาคเรียนของปีใหม่อยู่ในหัวข้อถัดไป

![ภาพที่ 1 — หน้าปีการศึกษา](../assets/screenshots/admin/academic-years.webp)
*ป้าย **ปีปัจจุบัน** จะมีแค่ใบเดียวในทั้งระบบ*

## ตั้งปีปัจจุบัน

ใช้ตอนโรงเรียนเริ่มใช้ปีใหม่จริง และรายชื่อของปีใหม่ครบแล้ว

**ทางเข้า:** แท็บ **เพิ่มเติม** ➔ กลุ่ม **โรงเรียน** ➔ **ปีการศึกษา** ➔ แท็บ **ทั้งหมด** ➔ **ใช้เป็นปีปัจจุบัน** ➔ อ่านข้อความยืนยัน ➔ **ใช้ปีนี้**

ข้อความยืนยันจะบอกจำนวนสมาชิกของปีนั้น และบอกว่าสมาชิกที่สร้างใหม่จะไปอยู่ปีนี้

สำเร็จแล้วจะขึ้น **ตั้งเป็นปีปัจจุบันแล้ว** และป้าย **ปีปัจจุบัน** ย้ายมาที่ปีใหม่ทันที

ระบบเปลี่ยนค่าเริ่มต้นของปีการศึกษาในตารางสมาชิกให้ชี้ปีใหม่ด้วย
สมาชิกที่สร้างหลังจากนี้ เช่นเพิ่มผู้ใช้รายคนหรือนำเข้าโดยไม่ระบุปี จะไปอยู่ปีใหม่เอง

::: warning ตั้งปีว่างเป็นปัจจุบันไม่ได้ ถ้าปียังมีคนอยู่
ระบบจะตอบ **ตั้งปีที่ยังไม่มีสมาชิกเป็นปีปัจจุบันไม่ได้ (ขณะนี้มีสมาชิกที่ใช้งานอยู่ N คนในปีอื่น)**
ทางออกคือกดเลื่อนชั้นหรือนำเข้ารายชื่อของปีใหม่ก่อน

ด่านนี้กันโรงเรียนล็อกตัวเอง เพราะถ้าตั้งปีว่างเป็นปัจจุบัน ระบบจะมองไม่เห็นนักเรียนที่ใช้งานอยู่เลย
:::

## ตั้งภาคเรียนของปี

1. **เปิด ภาคเรียน ➔ เพิ่มภาคเรียน**
2. **กรอก ชื่อภาคเรียน \*** เช่น **ภาคเรียนที่ 1/2569**
3. **เลือก ปีการศึกษา** ที่ภาคนี้สังกัด หรือคง **ไม่ผูกปี**
4. **เลือก วันเริ่มต้น\* และ วันสิ้นสุด\***
5. **ติ๊ก ใช้เป็นภาคปัจจุบัน** ถ้าภาคนี้เริ่มใช้แล้ว
6. **กดบันทึก**

::: tip วันสิ้นสุดนับรวมวันนั้นด้วย
ถ้าภาคจบวันที่ 10 ตุลาคม ให้เลือก 10 ตุลาคม ไม่ใช่ 9 ตุลาคม
ระบบแสดงจำนวนวันของภาคบนการ์ดให้ตรวจได้
:::

มีภาคปัจจุบันได้ครั้งละหนึ่ง ระบบปลดภาคเดิมให้อัตโนมัติเมื่อตั้งภาคใหม่
แก้ภาคที่กำลังใช้อยู่แล้วมีผลกับการกรองสถิติทันที

## เปลี่ยนภาคปัจจุบันกลางปี

**ทางเข้า:** แท็บ **เพิ่มเติม** ➔ กลุ่ม **โรงเรียน** ➔ **ภาคเรียน** ➔ แท็บ **ทั้งหมด** ➔ **ใช้เป็นภาคปัจจุบัน** ที่การ์ดภาคใหม่ ➔ อ่านช่วงวันที่ที่จะถูกนับ ➔ **ใช้ภาคนี้**

สำเร็จแล้วจะขึ้น **ตั้งเป็นภาคปัจจุบันแล้ว**
ป้าย **กำลังใช้อยู่** ย้ายไปที่ภาคใหม่ และหน้าแรกกับหน้าสถิติเปลี่ยนช่วงนับทันที

ถ้ายังไม่เคยตั้งภาคปัจจุบัน ระบบนับสถิติทั้งหมดตั้งแต่เริ่มใช้ระบบ ซึ่งถูกต้อง ไม่ใช่ข้อผิดพลาด

## แก้ปีหรือภาคที่สร้างผิด

### แก้ข้อมูลที่พิมพ์ผิด

**ทางเข้า:** เปิดหน้าปีหรือภาค ➔ **แก้ไข** ➔ แก้ชื่อหรือวันที่ ➔ บันทึก

ปีการศึกษาส่ง **วันเริ่มต้น** หรือ **วันสิ้นสุด** เป็นค่าว่างได้ เท่ากับล้างวันที่นั้น
แต่ภาคเรียนต้องมีทั้งวันเริ่มต้นและวันสิ้นสุด

### ลบรายการที่ยังไม่เคยใช้

**ทางเข้า:** **ลบ** ที่การ์ด ➔ อ่านคำเตือนว่าเป็นการซ่อนและกู้คืนได้ ➔ ยืนยัน

ลบปีไม่ได้ถ้าเป็นปีปัจจุบัน หรือยังมีสมาชิกอยู่ในปีนั้น
ปุ่มจะกดไม่ได้ และมีข้อความบอกเหตุผลใต้การ์ดตั้งแต่ก่อนกด

ลบภาคเรียนได้เสมอ แม้เป็นภาคปัจจุบัน ระบบจะกลับไปนับสถิติทั้งหมดจนกว่าจะตั้งภาคใหม่

### กู้คืนรายการที่ลบไปแล้ว

**ทางเข้า:** แท็บ **ถูกลบ** ➔ **กู้คืน** ➔ ยืนยัน

ปีและภาคที่กู้คืนกลับมาเป็นรายการธรรมดา ไม่ได้กลับเป็นปัจจุบันให้
ต้องกด **ใช้เป็นปีปัจจุบัน** หรือ **ใช้เป็นภาคปัจจุบัน** เองอีกครั้ง

การกู้คืนปีจะล้มเหลวถ้ามีปี พ.ศ. เดียวกันถูกสร้างขึ้นระหว่างนั้น
ข้อความคือ **กู้คืนไม่ได้ — มีปีการศึกษา … อยู่แล้ว** ให้ลบปีที่ซ้ำหรือแก้ พ.ศ. ของปีนั้นก่อน

## ระบบทำอะไรเบื้องหลัง

- ปีปัจจุบันบังคับด้วย unique index ที่ฐานข้อมูล มีได้หนึ่งแถวเสมอ
- ระบบล้างปีปัจจุบันเดิมก่อนตั้งปีใหม่ในทรานแซกชันเดียว ถ้าลำดับสลับจะชนข้อจำกัดและทั้งงานล้มเหลว
- ตั้งปีปัจจุบันแล้วสั่งเปลี่ยนค่าเริ่มต้น `academic_year_id` ของตารางสมาชิก เป็นการแก้โครงสร้างตารางแต่ไม่เขียนแถวใหม่
- การลบปีและภาคคือการซ่อน (`deleted_at`) ไม่ลบข้อมูลจริง สมาชิกและประวัติยังครบ
- ลบภาคปัจจุบันจะล้างค่าปัจจุบันด้วย เพื่อให้กู้คืนทีหลังได้โดยไม่ชนข้อจำกัด
- ระบบบันทึกการกระทำเป็น `CREATE_ACADEMIC_YEAR` `SET_CURRENT_YEAR` `DELETE_ACADEMIC_YEAR` และชุดเดียวกันของภาคเรียน
- แก้ปีหรือภาคแล้วมีผลกับหน้าจอที่อ่านค่าปัจจุบันทันที แต่หน้าจอที่โหลดค้างอยู่ต้องรีเฟรช
- ระบบไม่แจ้งเตือนผู้ใช้เมื่อเปลี่ยนปีหรือภาค

## ข้อจำกัดและข้อควรระวัง

- ไม่มีหน้าจอตั้งวันหยุดหรือปฏิทินรายวัน ระบบรู้จักเฉพาะช่วงของปีและภาค
- ระบบไม่ตรวจว่าภาคที่ผูกกับปีมีช่วงวันที่อยู่ในปีนั้น ต้องตรวจเอง
- ลบแบบถาวรจากหน้าจอไม่ได้
- ปีที่ยังไม่มีสมาชิกกดตั้งเป็นปัจจุบันไม่ได้ ถ้ามีสมาชิกอยู่ปีอื่น
- เปลี่ยนปีปัจจุบันไม่ย้ายแถวสมาชิกเดิมให้อัตโนมัติ ต้องใช้การเลื่อนชั้นหรือนำเข้า
- ปีที่ลบแล้วยังถูกนับในรายงานย้อนหลังถ้ามีการอ้างถึงรหัสปีนั้น
- สถิติที่กรองตามภาคใช้ช่วงวันที่ ไม่ได้ใช้ปีการศึกษาของสมาชิก

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: ตั้งปีใหม่เป็นปีปัจจุบันไม่ได้ ขึ้นว่ายังไม่มีสมาชิก?**

👉 **วิธีแก้:** ระบบกันการล็อกโรงเรียนเมื่อยังมีนักเรียนใช้งานอยู่ในปีอื่น ให้เลื่อนชั้นทั้งโรงเรียนหรือนำเข้ารายชื่อของปีใหม่ให้เสร็จก่อน แล้วค่อยตั้งปีปัจจุบัน

**Q: ลบปีไม่ได้ ทั้งที่เพิ่งสร้าง?**

👉 **วิธีแก้:** เช็กสองข้อ — ปีนั้นเป็นปีปัจจุบันหรือไม่ และยังมีสมาชิกอยู่ในปีนั้นหรือไม่ ถ้าเป็นปีปัจจุบันให้ตั้งปีอื่นก่อน ถ้ามีสมาชิกให้ย้ายหรือเลื่อนชั้นออกก่อน

**Q: เปลี่ยนปีปัจจุบันแล้วนักเรียนเดิมหายจากรายการ?**

👉 **วิธีแก้:** ไม่หาย แต่หน้า **สมาชิก** แสดงเฉพาะปีปัจจุบันเป็นค่าเริ่มต้น ให้เลือกปีเดิม หรือ **ทุกปี (ค้นข้ามปี)** พร้อมคำค้นเพื่อดูรายชื่อเดิม

**Q: ภาคเรียนกับปีการศึกษาต้องตั้งอันไหนก่อน?**

👉 **วิธีแก้:** ตั้งปีก่อน เพราะภาคที่ผูกกับปีต้องอ้างปีที่มีอยู่ ภาคที่ไม่ผูกปีสร้างได้ตลอด แต่จะตรวจย้อนหลังได้ยากว่าอยู่ปีไหน

**Q: วันสิ้นสุดของภาคใส่วันสุดท้ายที่มีเรียนหรือวันปิดเทอม?**

👉 **วิธีแก้:** ใส่วันสุดท้ายที่นับเป็นส่วนหนึ่งของภาค ระบบรวมวันนั้นด้วย ถ้าภาคจบ 10 ตุลาคม ก็เลือก 10 ตุลาคม

**Q: ไม่มีภาคปัจจุบันได้ไหม?**

👉 **วิธีแก้:** ได้ ระบบจะนับสถิติทั้งหมดแทน และหน้าแรกจะไม่จำกัดช่วงเวลา นี่คือสถานะตั้งต้นก่อนโรงเรียนตั้งภาคแรก

**Q: เปลี่ยนชื่อปีแล้วกระทบอะไร?**

👉 **วิธีแก้:** กระทบแค่ชื่อที่แสดง ส่วนการอ้างอิงภายในใช้รหัสปี แต่ระวังการแก้ พ.ศ. ให้ไม่ซ้ำกับปีอื่น เพราะระบบไม่ให้มี พ.ศ. ซ้ำกันในปีที่ยังไม่ถูกลบ

**Q: กู้คืนปีแล้วทำไมยังไม่เป็นปีปัจจุบัน?**

👉 **วิธีแก้:** ระบบไม่ตั้งให้เอง เพราะระหว่างที่ปีถูกลบอาจมีปีอื่นถูกตั้งเป็นปัจจุบันไปแล้ว ให้กด **ใช้เป็นปีปัจจุบัน** เองหลังตรวจรายชื่อครบ
