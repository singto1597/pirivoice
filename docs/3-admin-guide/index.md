# คู่มือผู้ดูแลระบบ

เล่มนี้สำหรับคนที่ดูแลโครงสร้างทั้งระบบ — ปีการศึกษา ภาคเรียน ตำแหน่งและสิทธิ์ของสมาชิก การตั้งค่าที่มีผลทั้งโรงเรียน และการตามรอยย้อนหลังเมื่อมีปัญหา

- 🗓️ **ปีและภาคเรียน** — ตั้งปีปัจจุบัน สร้างภาค สั่งเปิด-ปิด
- 👥 **คนและสิทธิ์** — เพิ่มผู้ใช้ ตั้งตำแหน่ง กำหนดหน้าที่
- 🔎 **บันทึกการใช้งาน** — ตามหาว่าใครแก้อะไร เมื่อไร
- 📊 **แดชบอร์ดและรายงาน** — ดูภาพรวมและสุขภาพระบบ

ภาพเปิดเล่มคือแดชบอร์ดของผู้ดูแล — ตัวเลขทุกใบจะอ่านแบบทั้งโรงเรียนหรือเฉพาะระดับชั้นก็ได้ ขึ้นกับป้ายขอบเขตมุมขวาบน

![ภาพที่ 1 — แดชบอร์ดภาพรวมทั้งโรงเรียน](../assets/screenshots/admin/dashboard-overview.webp)
*วงแดงชี้ป้าย ภาพรวมทั้งโรงเรียน การ์ด เรื่องทั้งหมด กับ รอรับเรื่อง การ์ด งานเกินเวลา และแถบคำอธิบายสีใต้การ์ด*

## ใครได้เล่มนี้ไปใช้

| ตำแหน่ง | สิทธิ์พื้นฐาน | งานในเล่มนี้ |
|---|---|---|
| ผู้ดูแลระบบ (`admin`) | `is_admin` | ทำได้ทุกบท |
| ครูสภานักเรียน (`teacher_council`) | `is_admin` | ทำได้ทุกบท |
| ประธานสภา (`council_president`) | `is_admin` | ทำได้ทุกบท |
| ครูทั่วไป (`teacher`) | ไม่มี `is_admin` | เห็นแดชบอร์ดเฉพาะระดับชั้นของตัวเอง บทอื่นต้องมีสิทธิ์เพิ่ม |

`is_admin` คือแฟล็กที่ทำให้ข้ามการตรวจสิทธิ์รายข้อทั้งหมด
ระบบอ่านค่านี้จากตำแหน่งใน `backend/config/roles.json` ทุกครั้งที่เปลี่ยนตำแหน่ง
จึงไม่มีปุ่มตั้ง `is_admin` แยกจากตำแหน่งในหน้าจอ

บัญชีที่กำหนดในตัวแปร `SUPER_ADMIN_ID` ก็ข้ามการตรวจสิทธิ์เหมือนกัน
ใช้ตอนต้องกู้ระบบกรณีไม่มีผู้ดูแลคนไหนล็อกอินได้

## สิทธิ์ที่เล่มนี้พูดถึง

| สิทธิ์ | ใช้ทำอะไร | บท |
|---|---|---|
| `MANAGE_STUDENTS` | เพิ่มและแก้สมาชิก กำหนดตำแหน่ง | [จัดการผู้ใช้และตำแหน่ง](user-and-role-management.md) |
| `VIEW_AUDIT_LOG` | เปิดบันทึกการใช้งาน | [ตรวจสอบย้อนหลังด้วยบันทึกการใช้งาน](audit-logs-investigation.md) |
| `MANAGE_SETTINGS` | ตั้งปี ภาคเรียน และช่วงเวลาแจ้งเตือน | [ตั้งค่าปีการศึกษาและภาคเรียน](academic-calendar.md) · [ตั้งค่าระบบ](system-configuration.md) |
| `VIEW_DASHBOARD` | เปิดแดชบอร์ดและสถิติการใช้งาน | [แดชบอร์ดและรายงาน](dashboard-and-reports.md) |

การดูบันทึกการใช้งานต้องมีขอบเขตข้อมูลระดับ `super` หรือ `all` เท่านั้น
ครูทั่วไปได้สิทธิ์ `VIEW_AUDIT_LOG` ก็ยังถูกปฏิเสธ เพราะเห็นได้แค่ระดับชั้น

## วันแรกเริ่มยังไง

1. **เข้าสู่ระบบด้วยบัญชีผู้ดูแล** แล้วเปิดแท็บ **เพิ่มเติม** ดูว่ามีเมนูครบไหม
2. **เปิด ปีการศึกษา** ดูว่ามีปีปัจจุบันตรงกับปีที่โรงเรียนใช้อยู่จริง
3. **เปิด ภาคเรียน** ดูว่ามีภาคปัจจุบัน และช่วงวันที่ตรงกับปฏิทินโรงเรียน
4. **เปิด สมาชิก** ดูว่ามีผู้ดูแลระบบอย่างน้อยหนึ่งคนในปีนี้
5. **เปิด ตั้งค่าการแจ้งเตือน** ที่หน้าโปรไฟล์ ตั้งช่วงเวลาเงียบถ้าต้องการ
6. **เปิด แดชบอร์ด** เทียบตัวเลขนักเรียนและห้องกับความจริง

## เมนูของผู้ดูแลอยู่ไหน

ทั้งหมดอยู่ในแท็บ **เพิ่มเติม**

**กลุ่ม ผู้ดูแล**

- **แดชบอร์ด**
- **จัดการรายงาน**
- **สมาชิก**
- **ย้ายห้องนักเรียน**

**กลุ่ม โรงเรียน**

- **จัดการประกาศ**
- **ปีการศึกษา**
- **เลื่อนชั้นนักเรียน**
- **กระทบยอดรายชื่อ**
- **ภาคเรียน**
- **เรื่องที่ผู้รับหมดวาระ**
- **บันทึกการใช้งาน**

ส่วน **เจ้าหน้าที่** กับ **นำเข้านักเรียน** ไม่ได้อยู่ในเมนู เข้าได้จากแท็บและปุ่มในหน้า **สมาชิก**
และ **จัดการกิจกรรม** อยู่ในแท็บ **จัดการ** ของหน้า **กิจกรรม**

## กติกาเพื่อความปลอดภัย

- ทุกการเพิ่ม แก้ไข และลบข้อมูลสำคัญถูกบันทึกใน **บันทึกการใช้งาน** พร้อมคนทำ เวลา และค่าเดิม–ค่าใหม่
- ไม่มีหน้าจอไหนให้แก้หรือลบบันทึกการใช้งาน ถ้าจะปิดร่องรอยต้องทำที่ฐานข้อมูลเท่านั้น
- การเปลี่ยนปีปัจจุบันเปลี่ยนค่าเริ่มต้นของปีการศึกษาของสมาชิกใหม่ทันที ต้องทำนอกเวลาใช้งาน
- การลบในระบบนี้คือการซ่อน (soft delete) ข้อมูลยังอยู่และกู้คืนได้ ยกเว้นที่ระบุไว้เป็นอย่างอื่น
- เก็บรหัสผ่านและไฟล์สำรองฐานข้อมูลให้พ้นจากเครื่องที่นักเรียนเข้าถึงได้

::: warning สี่งานที่ย้อนกลับจากหน้าจอไม่ได้
**ยืนยันเลื่อนชั้นทั้งโรงเรียน** — สมาชิกทั้งโรงเรียนถูกเขียนใหม่ในครั้งเดียว กู้ได้แค่จากไฟล์สำรอง
**ปิดเรื่อง** — เปิดใหม่จากหน้าจอไม่ได้ ต้องแก้ที่ฐานข้อมูล
**ลบปีหรือภาคเรียน** — ซ่อนจากรายการ แต่กด **กู้คืน** ในแท็บ **ถูกลบ** ได้
**เปลี่ยนตำแหน่งสมาชิก** — สิทธิ์เปลี่ยนทันที และแถวของปีเก่าไม่เปลี่ยนตาม
:::

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: เมนูบางรายการไม่ขึ้นทั้งที่เป็นผู้ดูแลระบบ?**

👉 **วิธีแก้:** เมนูถูกกรองด้วยสิทธิ์ของบัญชี และต้องมีแถวสมาชิกที่ใช้งานในปีปัจจุบันด้วย ให้ไปเช็กที่ **สมาชิก** ว่าบัญชีเรามีแถวในปีนี้และยังเป็นผู้ดูแลระบบอยู่

**Q: เปลี่ยนตำแหน่งแล้วสิทธิ์ไม่เปลี่ยนทันที?**

👉 **วิธีแก้:** ระบบอ่านสิทธิ์จากแถวสมาชิกทุกครั้งที่เรียก API ไม่ได้เก็บไว้ในเบราว์เซอร์ ถ้าหน้าจอยังแสดงเมนูเดิม ให้รีเฟรชหน้าหรือออกแล้วเข้าสู่ระบบใหม่

**Q: มีผู้ดูแลระบบได้กี่คน?**

👉 **วิธีแก้:** ไม่จำกัดจำนวน แต่ต้องเหลืออย่างน้อยหนึ่งคนในปีปัจจุบันเสมอ ถ้าเลื่อนชั้นแล้วปีใหม่ไม่มีผู้ดูแลเลย ระบบจะยกเลิกทั้งงานให้เอง

**Q: ผู้ดูแลรีเซ็ตรหัสผ่านให้นักเรียนได้ไหม?**

👉 **วิธีแก้:** หน้าจอไม่มีฟังก์ชันนี้ นักเรียนเปลี่ยนรหัสเองที่หน้าโปรไฟล์ ถ้าลืมรหัสจริง ต้องให้ผู้พัฒนาตั้งรหัสใหม่ที่ฐานข้อมูล

**Q: ทำไมเห็นข้อมูลนักเรียนไม่ครบทั้งโรงเรียน?**

👉 **วิธีแก้:** บัญชีอาจผูกกับระดับชั้น เช่นครูทั่วไปหรือประธานระดับ คนที่เห็นทั้งโรงเรียนคือผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา และตำแหน่งที่มีขอบเขต `all`

**Q: อยากย้อนดูว่าใครแก้อะไรก่อนเกิดปัญหา เริ่มที่ไหน?**

👉 **วิธีแก้:** เปิด **บันทึกการใช้งาน** กรองตามช่วงวันที่และชื่อผู้ใช้ ถ้าไม่รู้ว่าใคร ให้กรองตามชนิดข้อมูล แล้วอ่านค่าเดิม–ค่าใหม่ของรายการที่ใกล้เวลาเกิดเหตุ
