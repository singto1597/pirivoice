# หน้าแรกและแถบเมนูการใช้งาน

เปิดแอปมาแล้วไม่รู้จะกดตรงไหน? ดูแค่สามที่นี้ก็พอ:

- **แถบล่าง** — สลับหมวดทั้งห้า
- **การ์ดบนหน้าแรก** — บอกว่ามีอะไรค้างอยู่
- **กระดิ่งมุมขวาบน** — รวมแจ้งเตือนทุกเรื่อง

หน้าแรกและตำแหน่งแท็บทั้งห้าอยู่ในภาพนี้

![ภาพที่ 1 — หน้าแรกและแท็บทั้งห้า](../assets/screenshots/user/home.webp)
*หมายเลข 1–5 คือแท็บด้านล่าง ส่วนหมายเลข 6 คือกระดิ่ง*

## แถบล่างมีห้าแท็บ

แถบล่างอยู่ติดขอบจอเสมอ ไม่ว่าอยู่หน้าไหนก็กดสลับได้ทันที

- **1 · หน้าแรก** — กลับมาดูภาพรวมว่ามีอะไรต้องทำ
- **2 · เรื่อง** — เรื่องของฉัน และเรื่องที่เราต้องรับผิดชอบ
- **3 · บอร์ด** — อ่าน โหวต และคอมเมนต์
- **4 · กิจกรรม** — ดูกิจกรรมที่เปิดรับและลงทะเบียน
- **5 · เพิ่มเติม** — โปรไฟล์ คู่มือ ตั้งค่า และออกจากระบบ

ส่วน **กระดิ่ง** (หมายเลข 6) อยู่มุมขวาบนของทุกหน้า กดเพื่อดูรายการแจ้งเตือน
ถ้ามีตัวเลขสีแดง แปลว่ายังมีเรื่องที่ยังไม่ได้อ่าน

## หน้าแรกบอกอะไรบ้าง

หน้าแรกไม่ได้เอาทุกอย่างมาใส่ แต่คัดเรื่องที่ต้องทำวันนี้ขึ้นมาก่อน

- **รอฉันตอบ** — มีเรื่องค้างที่เราหรือทีมต้องรับเรื่องหรือปิดเรื่อง
- **โหวตที่ยังไม่โหวต** — มีบอร์ดโหวตที่ยังเปิดอยู่และเรายังไม่ได้ออกเสียง
- **กิจกรรมใกล้ปิดรับ** — มีกิจกรรมที่ใกล้ถึงกำหนดปิดรับสมัคร
- **ประกาศโรงเรียน** — มีประกาศล่าสุดจากสภานักเรียน
- **สรุปเรื่องของฉัน** — อยากเห็นสถานะเรื่องที่ตัวเองแจ้งไว้

บล็อกไหนไม่มีอะไรค้าง จะไม่ขึ้นมาให้รกจอ ไม่ได้แปลว่าระบบพัง
กดที่การ์ดหรือลิงก์ท้ายบล็อกเพื่อไปยังรายการเต็มได้

การ์ดแต่ละใบเป็นทางลัดในตัว อย่างการ์ดโหวตมีปุ่ม **บอร์ด →** ให้กดข้ามไปโหวตได้เลย
ส่วนการ์ดสรุปเรื่องของฉันแยกตัวเลขให้เห็นว่ามีเรื่องค้างสถานะไหนอยู่เท่าไร

![ภาพที่ 2 — ทางลัดบนการ์ดในหน้าแรก](../assets/screenshots/user/home-shortcuts-card.webp)
*หมายเลข 1 การ์ด **โหวตที่ยังไม่โหวต** · 2 ปุ่ม **บอร์ด →** · 3 การ์ด **สรุปเรื่องของฉัน** พร้อมตัวเลขแยกสถานะ*

::: tip หน้าแรกโหลดไม่ขึ้นทั้งหน้า
ถ้าบางส่วนโหลดช้า ให้รอสักครู่แล้วกด **ลองใหม่**
ปกติแต่ละบล็อกโหลดแยกกัน บล็อกที่เสร็จก่อนจะขึ้นให้เห็นเลย
:::

## ทางลัดไประบบอื่นของโรงเรียน

ในหน้าแรกมีส่วน **ระบบโรงเรียน** รวมทางลัดไปยังเว็บที่ใช้บ่อย

- **ระบบดูแลช่วยเหลือนักเรียน**
- **เว็บโรงเรียน**

::: warning กดแล้วออกไปนอกแอปเลยนะ
ระบบจะถามยืนยัน **เปิดเว็บไซต์ภายนอก** ก่อนพาออกไป
PIRIvoice ไม่ได้ดูแลข้อมูลในเว็บเหล่านั้น ถ้ามีปัญหากับเว็บปลายทาง
ต้องติดต่อฝ่ายที่ดูแลเว็บนั้นโดยตรง
:::

## เมนูเพิ่มเติม

แท็บที่ห้า **เพิ่มเติม** รวมเรื่องที่ไม่ได้ใช้ทุกวันไว้ด้วยกัน

![ภาพที่ 3 — เมนูเพิ่มเติมของนักเรียนทั่วไป](../assets/screenshots/user/more.webp)
*สำหรับนักเรียนทั่วไปจะมีหกรายการตามหมายเลขในภาพ*

- **1 · กิจกรรมของฉัน** — ประวัติการแจ้งเรื่อง โหวต คอมเมนต์ และเรื่องที่บันทึกไว้
- **2 · คู่มือการทำงาน** — อ่านคู่มือของสภานักเรียนทั้งหกเล่มในแอป
- **3 · คู่มือการใช้งาน** — เปิดเว็บคู่มือแบบละเอียดที่มีภาพประกอบทุกขั้นตอน
- **4 · โปรไฟล์** — ดูข้อมูลตัวเองและสถิติการใช้งาน
- **5 · ตั้งค่า** — เปิดการแจ้งเตือน เปลี่ยนรหัสผ่าน
- **6 · ออกจากระบบ** — ออกจากบัญชีบนเครื่องนี้

**คู่มือการทำงาน** กับ **คู่มือการใช้งาน** ชื่อใกล้กันแต่คนละที่อ่าน
ตัวแรกเป็นเล่มที่สภาอัปเดตกันเองในแอป อ่านจบได้ในไม่กี่หน้า
ตัวหลังเป็นเว็บคู่มือเล่มใหญ่ที่รวมทุกบททั้งของนักเรียน สภา และผู้ดูแลระบบ

กด **คู่มือการใช้งาน** แล้วหน้าคู่มือจะเปิดในแท็บเดิมของเบราว์เซอร์
อ่านได้เลยไม่ต้องล็อกอินซ้ำ กดปุ่มย้อนกลับก็กลับเข้าแอปได้ตามปกติ
บนคอมพิวเตอร์มีทางเข้าเดียวกันนี้อยู่ในแถบเมนูด้านซ้าย

ถ้ามีตำแหน่งในสภา (หัวหน้าห้อง รองฝ่าย ประธานระดับ สภานักเรียน) หรือเป็นครู
จะเห็นเมนูเพิ่มอีกหลายรายการ เช่น แดชบอร์ด จัดการรายงาน หรือจัดการกิจกรรม
เมนูเหล่านี้อธิบายไว้ใน [คู่มือหัวหน้าห้องและสภานักเรียน เล่ม 2](../2-staff-operations/index.md)

## ข้อจำกัดและข้อควรระวัง

- ไม่มีแท็บ **กิจกรรมของฉัน** โดยตั้งใจ ให้เข้าไปทางเมนู **เพิ่มเติม**
- หน้าแรกไม่มีช่องค้นหาทั่วทั้งระบบ
- หน้าแสกนเช็คอินจะซ่อนหัวจอและแถบล่าง เพื่อไม่ให้กดออกกลางงานโดยไม่ตั้งใจ
- เมนูที่บัญชีไม่มีสิทธิ์จะถูกซ่อนไปเลย ไม่ใช่แสดงแล้วกดไม่ได้
- ถ้าเพิ่งได้ตำแหน่งใหม่แล้วยังไม่เห็นเมนู ให้ออกจากระบบแล้วเข้าใหม่
- ตัวเลขบนแท็บ **เรื่อง** คือจำนวนที่ค้างอยู่ในแท็บย่อยที่กำลังดู
  ส่วนตัวเลขบนกระดิ่งนับรวมทุกกลุ่ม

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: ทำไมไม่เห็นเมนูจัดการกิจกรรม?**

👉 **วิธีแก้:** บัญชีนี้ยังไม่มีสิทธิ์ **จัดการกิจกรรม** ถ้าคิดว่าควรมี ให้บอกครูหรือผู้ดูแลระบบ

**Q: กดแท็บเรื่องแล้วไม่เห็นแท็บ "ที่รับผิดชอบ"?**

👉 **วิธีแก้:** บัญชีไม่มีสิทธิ์รับเรื่อง หรือยังไม่ได้ผูกตำแหน่งในปีการศึกษาปัจจุบัน

**Q: หน้าแรกขึ้นว่าโหลดข้อมูลไม่สำเร็จ?**

👉 **วิธีแก้:** กด **ลองใหม่** ถ้ายังไม่ขึ้นให้เช็กอินเทอร์เน็ตแล้วเปิดใหม่
บล็อกที่โหลดได้แล้วจะยังอยู่ ไม่ต้องรอทั้งหน้า

**Q: ตัวเลขบนแท็บไม่ตรงกับรายการข้างใน?**

👉 **วิธีแก้:** ตัวเลขอัปเดตช้ากว่าหน้าจอเล็กน้อย เปิดแท็บนั้นแล้วรอสักครู่จะตรงกัน

**Q: เปิดลิงก์เก่าจากกลุ่มแชทแล้วเด้งไปหน้าเข้าสู่ระบบ?**

👉 **วิธีแก้:** ปกติ ระบบจำหน้าที่ตั้งใจจะไปไว้ พอเข้าสำเร็จจะพากลับไปหน้านั้นให้เอง
ถ้าลิงก์นั้นเปิดไม่ได้แล้ว จะพาไปหน้าแรกแทน

**Q: อยากกลับหน้าแรกตลอด ต้องกดอะไร?**

👉 **วิธีแก้:** กดแท็บ **หน้าแรก** ที่แถบล่างได้ทุกเมื่อ
