# หน้าแรกและแถบเมนูการใช้งาน

เปิดแอปมาแล้วเจอหน้าแรก ให้ดูสามอย่างนี้ก่อน คือแถบล่างที่ใช้สลับหมวด
การ์ดบนหน้าแรกที่บอกว่ามีอะไรค้างอยู่ และกระดิ่งที่มุมขวาบน
บทนี้อธิบายว่าส่วนไหนทำอะไร

![ภาพที่ 1 — หน้าแรกและแท็บทั้งห้า](../assets/screenshots/user/home.webp)

## แถบล่างมีห้าแท็บ

แถบล่างอยู่ติดกับขอบจอเสมอ ไม่ว่าอยู่หน้าไหนก็กดกลับได้ทันที

| หมายเลข | แท็บ | ใช้ทำอะไร |
|---|---|---|
| 1 | **หน้าแรก** | กลับมาดูภาพรวมว่ามีอะไรต้องทำ |
| 2 | **เรื่อง** | ดูเรื่องของฉัน และเรื่องที่ต้องรับผิดชอบ |
| 3 | **บอร์ด** | อ่าน โหวต และแสดงความคิดเห็น |
| 4 | **กิจกรรม** | ดูกิจกรรมที่เปิดรับและลงทะเบียน |
| 5 | **เพิ่มเติม** | โปรไฟล์ คู่มือ ตั้งค่า และออกจากระบบ |

หมายเลข 6 ในภาพคือ **กระดิ่ง** อยู่ที่มุมขวาบนของทุกหน้า กดเพื่อดูรายการแจ้งเตือน
ถ้ามีตัวเลขสีแดงแปลว่ายังมีเรื่องที่ยังไม่ได้อ่าน

## หน้าแรกบอกอะไรบ้าง

หน้าแรกไม่ได้เอาทุกอย่างมาใส่ไว้ แต่คัดสิ่งที่ต้องทำวันนี้ขึ้นมาก่อน

| บล็อก | ขึ้นเมื่อ |
|---|---|
| **รอฉันตอบ** | มีเรื่องค้างที่เราหรือทีมต้องรับเรื่องหรือปิดเรื่อง |
| **โหวตที่ยังไม่โหวต** | มีบอร์ดโหวตที่ยังเปิดอยู่และเรายังไม่ได้ออกเสียง |
| **กิจกรรมใกล้ปิดรับ** | มีกิจกรรมที่ใกล้ถึงกำหนดปิดรับสมัคร |
| **ประกาศโรงเรียน** | มีประกาศล่าสุดจากสภานักเรียน |
| **สรุปเรื่องของฉัน** | อยากเห็นสถานะเรื่องที่ตัวเองแจ้งไว้ |

ถ้าบล็อกไหนไม่มีอะไรค้างอยู่ จะไม่ขึ้นมาให้รกจอ ไม่ได้แปลว่าระบบพัง
กดที่การ์ดหรือลิงก์ท้ายบล็อกเพื่อไปยังรายการเต็มได้

::: tip หน้าแรกโหลดไม่ขึ้นทั้งหน้า
ถ้าบางส่วนโหลดช้า ให้รอสักครู่แล้วกด **ลองใหม่**
ปกติแต่ละบล็อกโหลดแยกกัน บล็อกที่โหลดเสร็จก่อนจะขึ้นให้เห็นเลย
:::

## ทางลัดไประบบอื่นของโรงเรียน

ในหน้าแรกมีส่วน **ระบบโรงเรียน** รวมทางลัดไปยังเว็บอื่นที่ใช้บ่อย

- **ระบบดูแลช่วยเหลือนักเรียน**
- **เว็บโรงเรียน**

::: warning กดแล้วออกไปนอกแอป
ระบบจะถามยืนยัน **เปิดเว็บไซต์ภายนอก** ก่อนพาออกไป
PIRIvoice ไม่ได้ดูแลข้อมูลในเว็บเหล่านั้น ถ้ามีปัญหากับเว็บปลายทาง
ต้องติดต่อฝ่ายที่ดูแลเว็บนั้นโดยตรง
:::

## เมนูเพิ่มเติม

แท็บที่ห้า **เพิ่มเติม** รวมเรื่องที่ไม่ได้ใช้ทุกวันไว้ด้วยกัน

![ภาพที่ 2 — เมนูเพิ่มเติมของนักเรียนทั่วไป](../assets/screenshots/user/more.webp)

สำหรับนักเรียนทั่วไปจะมีห้ารายการ

| หมายเลข | เมนู | ใช้ทำอะไร |
|---|---|---|
| 1 | **กิจกรรมของฉัน** | ดูประวัติการแจ้งเรื่อง โหวต คอมเมนต์ และเรื่องที่บันทึกไว้ |
| 2 | **คู่มือการทำงาน** | อ่านคู่มือของสภานักเรียนทั้งหกเล่ม |
| 3 | **โปรไฟล์** | ดูข้อมูลตัวเองและสถิติการใช้งาน |
| 4 | **ตั้งค่า** | เปิดการแจ้งเตือน เปลี่ยนรหัสผ่าน |
| 5 | **ออกจากระบบ** | ออกจากบัญชีบนเครื่องนี้ |

::: info ถ้าคุณมีตำแหน่งในสภา
หัวหน้าห้อง รองฝ่าย ประธานระดับ สภานักเรียน และครู จะเห็นเมนูเพิ่มอีกหลายรายการ
เช่น แดชบอร์ด จัดการรายงาน หรือจัดการกิจกรรม เมนูเหล่านี้อธิบายไว้ใน
[คู่มือหัวหน้าห้องและสภานักเรียน เล่ม 2](../2-staff-operations/index.md)
:::

## ระบบทำอะไรเบื้องหลัง

แถบล่างมีห้าแท็บเสมอ เพื่อไม่ให้เมนูบวมจนกดผิด
เมนูที่บัญชีไม่มีสิทธิ์จะถูกซ่อนไปเลย ไม่ใช่แสดงแล้วกดไม่ได้
ถ้าเพิ่งได้รับตำแหน่งใหม่แล้วยังไม่เห็นเมนู ออกจากระบบแล้วเข้าใหม่ก่อน

ตัวเลขบนแท็บ **เรื่อง** คือจำนวนเรื่องที่ยังค้างอยู่ในแท็บย่อยที่กำลังดูอยู่
ส่วนตัวเลขบนกระดิ่งนับรวมทุกกลุ่ม

## ข้อจำกัดและข้อควรระวัง

- ไม่มีแท็บ **กิจกรรมของฉัน** โดยตั้งใจ ให้เข้าไปทางเมนู **เพิ่มเติม**
- หน้าแรกไม่มีช่องค้นหาทั่วทั้งระบบ
- หน้าแสกนเช็คอินจะซ่อนหัวจอและแถบล่าง เพื่อไม่ให้กดออกกลางงานโดยไม่ตั้งใจ
- เมนูอาจเปลี่ยนตามสิทธิ์ ถ้าเพิ่งได้สิทธิ์ใหม่ให้ออกแล้วเข้าใหม่

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: ทำไมไม่เห็นเมนูจัดการกิจกรรม**
ตอบ: บัญชีนี้ยังไม่มีสิทธิ์ **จัดการกิจกรรม** ถ้าคิดว่าควรมี ให้บอกครูหรือผู้ดูแลระบบ

**ถาม: กดแท็บเรื่องแล้วไม่เห็นแท็บ "ที่รับผิดชอบ"**
ตอบ: บัญชีไม่มีสิทธิ์รับเรื่อง หรือยังไม่ได้ผูกตำแหน่งในปีการศึกษาปัจจุบัน

**ถาม: หน้าแรกขึ้นว่าโหลดข้อมูลไม่สำเร็จ**
ตอบ: กด **ลองใหม่** ถ้ายังไม่ขึ้นให้เช็กอินเทอร์เน็ตแล้วเปิดใหม่
บล็อกที่โหลดได้แล้วจะยังแสดงอยู่ ไม่ต้องรอทั้งหน้า

**ถาม: ตัวเลขบนแท็บไม่ตรงกับรายการข้างใน**
ตอบ: ตัวเลขอัปเดตช้ากว่าหน้าจอเล็กน้อย เปิดแท็บนั้นแล้วรอสักครู่จะตรงกัน

**ถาม: เปิดลิงก์เก่าจากกลุ่มแชทแล้วเด้งไปหน้าเข้าสู่ระบบ**
ตอบ: ปกติ ระบบจำหน้าที่ตั้งใจจะไปไว้ พอเข้าสำเร็จจะพากลับไปหน้านั้นให้เอง
ถ้าลิงก์นั้นเปิดไม่ได้แล้ว จะพาไปหน้าแรกแทน

**ถาม: อยากกลับหน้าแรกตลอด ต้องกดอะไร**
ตอบ: กดแท็บ **หน้าแรก** ที่แถบล่างได้ทุกเมื่อ
