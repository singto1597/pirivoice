# หน้าแรกและเมนูนำทาง

บทนี้อธิบายวิธีหาสิ่งที่ต้องทำในแต่ละวัน และวิธีไปยังหน้าที่ต้องการโดยไม่ต้องจำที่อยู่เว็บ

## ใครใช้บทนี้

ผู้ใช้ทุกคน

## ก่อนเริ่ม

- เข้าสู่ระบบแล้ว
- เมนูที่เห็นขึ้นอยู่กับตำแหน่งและสิทธิ์ของบัญชี

::: info เมนูขึ้นตามสิทธิ์
ระบบจะซ่อนเมนูที่บัญชีไม่มีสิทธิ์ ไม่ใช่แสดงแล้วกดไม่ได้ หากเพิ่งได้รับสิทธิ์ใหม่ ให้ออกจากระบบแล้วเข้าใหม่
:::

## ถ้าต้องการรู้ว่าวันนี้มีอะไรต้องทำ

เปิด **หน้าแรก** แล้วอ่านทีละบล็อก

| บล็อก | ใช้เมื่อ |
|---|---|
| **รอฉันตอบ** | มีเรื่องค้างที่คุณหรือทีมต้องรับเรื่องหรือปิดเรื่อง |
| **โหวตที่ยังไม่โหวต** | มีบอร์ดโหวตที่ยังเปิดและคุณยังไม่ได้ออกเสียง |
| **กิจกรรมใกล้ปิดรับ** | มีกิจกรรมที่ใกล้ปิดรับสมัคร |
| **ประกาศโรงเรียน** | มีประกาศล่าสุดจากสภา |
| **สรุปเรื่องของฉัน** | ต้องการดูสถานะเรื่องที่ตนเองแจ้ง |
| **คิวจัดการรายงาน** | ผู้มีสิทธิ์เห็นคอมเมนต์ที่ถูกรายงาน |
| **ภาพรวม** | ผู้มีสิทธิ์เห็นสถิติโรงเรียนหรือระดับชั้น |

กดการ์ดหรือลิงก์ท้ายบล็อกเพื่อไปยังรายการเต็ม

## ถ้าต้องการไปหน้าเรื่อง

1. กดแท็บ **เรื่อง** ที่แถบล่าง
2. เลือก **ของฉัน** เพื่อดูเรื่องที่คุณแจ้ง
3. เลือก **ที่รับผิดชอบ** เพื่อดูเรื่องที่คุณต้องดำเนินการ
4. กดเรื่องเพื่อเปิดรายละเอียด

::: info ถ้าไม่เห็นแท็บ "ที่รับผิดชอบ"
บัญชีไม่มีสิทธิ์รับเรื่อง หรือยังไม่ได้ผูกตำแหน่งในปีการศึกษาปัจจุบัน
:::

## ถ้าต้องการไปหน้าบอร์ด

1. กดแท็บ **บอร์ด**
2. เลือก **ทั้งหมด** **โหวต** **พูดคุย** หรือ **ข้อเสนอแนะ**
3. กดกระทู้เพื่ออ่านหรือโหวต
4. กด **เสนอไอเดีย** เพื่อสร้างข้อเสนอใหม่

## ถ้าต้องการไปหน้ากิจกรรม

1. กดแท็บ **กิจกรรม**
2. เลือก **ทั้งหมด** เพื่อดูกิจกรรมที่เผยแพร่
3. ผู้มีสิทธิ์จัดการจะเห็น **จัดการ** เพิ่ม
4. กดกิจกรรมเพื่อลงทะเบียนหรือดูรายละเอียด

## ถ้าต้องการหาหน้าจัดการหรือหน้าตั้งค่า

1. กดแท็บ **เพิ่มเติม**
2. เลือกกลุ่มเมนู

กลุ่ม **ผู้ดูแล**

- **แดชบอร์ด**
- **จัดการรายงาน**
- **สมาชิก**
- **ย้ายห้องนักเรียน**
- **จัดการกิจกรรม** (แสดงเฉพาะผู้มีสิทธิ์)
- **เจ้าหน้าที่** (แสดงเฉพาะผู้มีสิทธิ์)
- **นำเข้านักเรียน** (แสดงเฉพาะผู้มีสิทธิ์)

กลุ่ม **โรงเรียน**

- **จัดการประกาศ**
- **ปีการศึกษา**
- **เลื่อนชั้นนักเรียน**
- **กระทบยอดรายชื่อ**
- **ภาคเรียน**
- **เรื่องที่ผู้รับหมดวาระ**
- **บันทึกการใช้งาน**

กลุ่ม **ทั่วไป**

- **กิจกรรมของฉัน**
- **คู่มือการทำงาน**

กลุ่ม **บัญชี**

- **โปรไฟล์**
- **ตั้งค่า**
- **ออกจากระบบ**

## ถ้าต้องการเปิดระบบอื่นของโรงเรียน

ในหน้าแรกมีการ์ด **ระบบโรงเรียน** ทางลัดสองรายการ

- **ระบบดูแลช่วยเหลือนักเรียน**
- **เว็บโรงเรียน**

::: warning ลิงก์ออกนอกระบบ
เมื่อกด ระบบจะแจ้ง **เปิดเว็บไซต์ภายนอก** แล้วพาออกไปยังเว็บนั้น PIRIvoice ไม่ได้จัดการข้อมูลในระบบเหล่านั้น
:::

## ถ้าต้องการกลับหน้าก่อนหน้า

::: info ปุ่มย้อนกลับไม่ย้อนประวัติทั้งก้อน
ระบบจะพากลับหน้าหลักของหมวดนั้น ไม่ย้อนกลับไปยังหน้าที่อาจไม่เกี่ยวข้อง เช่น หน้าสแกนคิวอาร์
:::

## ระบบทำอะไรเบื้องหลัง

- แถบล่างมี 5 แท็บเสมอ เพื่อไม่ให้เมนูบวม
- เมนูที่ไม่มีสิทธิ์จะถูกซ่อน ไม่ใช่แสดงแล้วกดไม่ได้
- ตัวเลขบนแท็บ **เรื่อง** คือจำนวนเรื่องในแท็บย่อยที่กำลังดู
- ตัวเลขบน **เพิ่มเติม** คือจำนวนที่เหลือหลังหักแท็บอื่น เพื่อไม่ให้นับซ้ำ
- หน้าแรกโหลดข้อมูลหลายส่วนพร้อมกัน หากส่วนใดล้มเหลว ส่วนอื่นยังแสดงได้

## ข้อจำกัดและข้อควรระวัง

- ไม่มีแท็บ **กิจกรรมของฉัน** โดยเจตนา ให้ใช้ **กิจกรรมของฉัน** ในเมนูเพิ่มเติม
- ไม่มีช่องค้นหาทั่วทั้งระบบจากหน้าแรก
- หน้าสแกนเช็คอินซ่อนทั้งหัวและแถบล่าง เพื่อไม่ให้กดออกกลางงานโดยไม่ตั้งใจ
- เมนูอาจเปลี่ยนตามสิทธิ์ หากเพิ่งได้รับสิทธิ์ใหม่ให้ออกแล้วเข้าใหม่

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: ทำไมไม่เห็นเมนูจัดการกิจกรรม**
ตอบ: บัญชีไม่มีสิทธิ์ **จัดการกิจกรรม** ให้ติดต่อผู้ดูแลระบบ

**ถาม: กดแท็บเรื่องแล้วไม่เห็น "ที่รับผิดชอบ"**
ตอบ: บัญชีไม่มีสิทธิ์รับเรื่อง หรือยังไม่ได้ผูกตำแหน่งในปีการศึกษาปัจจุบัน

**ถาม: หน้าแรกขึ้น "โหลดข้อมูลหน้าแรกไม่สำเร็จ"**
ตอบ: กด **ลองใหม่** หากยังไม่ได้ ให้ตรวจอินเทอร์เน็ตแล้วเปิดใหม่
ข้อมูลบางส่วนอาจแสดงได้แม้ส่วนอื่นล้มเหลว

**ถาม: ตัวเลขบนแท็บไม่ตรงกับรายการ**
ตอบ: ตัวเลขอาจอัปเดตช้ากว่าหน้าจอ ให้เปิดแท็บนั้นแล้วรอสักครู่ ระบบถามใหม่ทุก 30 วินาที

**ถาม: เปิดลิงก์เก่าจากกลุ่ม LINE แล้วไปหน้าเข้าสู่ระบบ**
ตอบ: ระบบจำหน้าที่ตั้งใจจะไปไว้ หากเข้าสู่ระบบสำเร็จจะพากลับไปหน้านั้น
เว้นแต่ลิงก์ไม่ปลอดภัย ระบบจะพาไปหน้าแรกแทน

**ถาม: อยากกลับไปหน้าแรกตลอด ต้องกดอะไร**
ตอบ: กดแท็บ **หน้าแรก** ที่แถบล่าง
