# บอร์ดพูดคุย การโหวต และการเสนอไอเดีย

บอร์ดคือที่ที่นักเรียนคุยกันเอง ไม่ต้องผ่านการรับเรื่องแบบแจ้งปัญหา
ใช้โหวตหาเสียงข้างมาก คุยเรื่องทั่ว ๆ ไป หรือเสนอไอเดียที่อยากให้สภาช่วยผลักดัน

- 🗳️ โหวตได้บอร์ดละหนึ่งเสียง
- 💬 คอมเมนต์และตอบกลับกันได้
- 💡 เสนอไอเดียใหม่ขึ้นบอร์ดได้เอง

## บอร์ดมีสามแบบ

![ภาพที่ 1 — หน้ารวมบอร์ดและตัวกรอง](../assets/screenshots/user/boards.webp)
*ตัวกรองอยู่ใต้หัวจอ เลือกดูเฉพาะประเภทที่สนใจได้*

- 🗳️ **โหวต** — เลือกจากตัวเลือกที่ตั้งไว้ หนึ่งคนหนึ่งเสียง และไม่มีช่องคอมเมนต์
- 💬 **พูดคุย** — ตั้งกระทู้คุยกันเรื่องทั่วไป ตอบกลับได้
- 💡 **ข้อเสนอแนะ** — เสนอไอเดียให้สภาพิจารณา ตอบกลับได้

ถ้าอยากหาเรื่องที่สนใจ ใช้ช่อง **ค้นหาบอร์ด...** ได้เลย

## อ่านบอร์ด

**ทางเข้า:** แท็บ **บอร์ด** ➔ เลือกประเภท (หรือปล่อยไว้ที่ **ทั้งหมด**) ➔ กดการ์ดกระทู้ ➔ เลื่อนอ่านคอมเมนต์ด้านล่าง

กระทู้ที่ถูกซ่อนหรือปิดแล้วจะไม่ขึ้นในรายการ

## วิธีโหวต

**สำหรับบอร์ดโหวต (PIRI Vote):** กดเข้าไปในหัวข้อที่สนใจ ➔ อ่านตัวเลือกให้ครบก่อน ➔ เลือกตัวเลือกที่ต้องการ ➔ กดปุ่ม **ส่งเสียงโหวต**

![ภาพที่ 2 — หน้าบอร์ดโหวต](../assets/screenshots/user/board-vote.webp)
*หมายเลข 1–2 คือตัวเลือก หมายเลข 3 คือปุ่มโหวต และหมายเลข 4 คือไอคอนบุ๊กมาร์ก*

พอกดเสร็จปุ๊บ ระบบจะโชว์ผลคะแนนและเปอร์เซ็นต์ของทุกตัวเลือกให้ดูทันที

::: warning เช็กให้ชัวร์ก่อนกด! โหวตแล้วเปลี่ยนใจไม่ได้นะ
1 คนโหวตได้แค่ **1 ครั้งต่อ 1 เรื่อง** เท่านั้น กดส่งเสียงไปแล้วกลับมาเปลี่ยนตัวเลือกทีหลังไม่ได้
และในบอร์ดโหวตจะไม่มีช่องให้คอมเมนต์ เพราะเน้นนับคะแนนเสียงอย่างเดียว
:::

ถ้าอยากกลับมาอ่านบอร์ดเดิมทีหลัง กดไอคอนบุ๊กมาร์กในภาพ
แล้วไปดูได้ที่ **เพิ่มเติม** ➔ **กิจกรรมของฉัน** ➔ **บันทึกไว้**

## แสดงความคิดเห็นและตอบกลับ

บอร์ด **พูดคุย** และ **ข้อเสนอแนะ** เปิดให้คอมเมนต์

**วิธีคอมเมนต์:** เลื่อนลงไปที่ช่อง **ร่วมแสดงความเห็น...** ➔ พิมพ์ข้อความ ➔ กด **ส่ง**

ถ้าจะตอบใคร ให้กดปุ่มตอบใต้คอมเมนต์ของคนนั้น
ถ้าตอบซ้อนกันหลายชั้นจนถึงขีดจำกัดของระบบ ให้กดตอบกลับที่คอมเมนต์ชั้นบนแทน
ข้อความจะยังอยู่ในเธรดเดียวกันและอ่านง่ายกว่า

::: tip คุยกันให้สนุกนะ
คอมเมนต์แสดงชื่อจริงของคนเขียนเสมอ เขียนเหมือนคุยกับเพื่อนต่อหน้า
ถ้าไม่เห็นด้วย ให้แย้งที่เหตุผล ไม่ต้องแย้งที่ตัวคน
:::

## เสนอไอเดียใหม่

**ทางเข้า:** แท็บ **บอร์ด** ➔ ปุ่ม **เสนอไอเดีย** (มุมล่างขวา)

![ภาพที่ 3 — หน้าสร้างข้อเสนอ](../assets/screenshots/user/new-suggestion.webp)
*หมายเลข 1 หัวข้อ · 2 รายละเอียด · 3 ช่องไม่แสดงชื่อผู้เสนอ · 4 ปุ่มเผยแพร่*

1. **ตั้งหัวข้อให้ชัด** ว่าอยากเสนออะไร
2. **เขียนรายละเอียด** ว่าไอเดียนี้ช่วยอะไร และทำได้ยังไง
3. **ติ๊กไม่แสดงชื่อถ้าต้องการ** ที่ช่อง **ไม่แสดงชื่อผู้เสนอ**
4. **กดเผยแพร่ข้อเสนอ** แล้วขึ้นบอร์ดทันที ไม่ต้องรออนุมัติ

ถ้าติ๊กไม่แสดงชื่อ คนทั่วไปจะไม่เห็นว่าใครเสนอ แต่สภานักเรียนยังเห็น
เพื่อให้ตรวจย้อนหลังได้ถ้ามีปัญหา

## รายงานคอมเมนต์ที่ไม่เหมาะสม

เจอข้อความที่ทำให้คนอื่นเสียหาย ช่วยกันรายงานได้

**วิธีรายงาน:** เปิดคอมเมนต์นั้น ➔ **รายงาน** ➔ เลือกเหตุผล ➔ พิมพ์อธิบายสั้น ๆ ➔ ส่ง

เหตุผลที่เลือกได้

- 🚫 **กลั่นแกล้ง/คุกคาม** — มีการข่มขู่หรือคุกคาม
- 🤬 **คำหยาบคาย** — ใช้ถ้อยคำไม่สุภาพ
- 📢 **สแปม/โฆษณา** — โพสต์ซ้ำหรือขายของ
- 🔒 **เปิดเผยข้อมูลส่วนตัว** — เปิดเผยชื่อ เบอร์ หรือข้อมูลของคนอื่น
- ❓ **อื่น ๆ** — กรณีอื่นที่ไม่อยู่ในรายการ

รายงานจะเข้าคิวของสภานักเรียน สภาจะดูแล้วตัดสินว่าจะซ่อนคอมเมนต์หรือไม่
ผลจะแจ้งกลับให้คนที่รายงานทราบ บัญชีหนึ่งรายงานค้างได้สิบรายการ
และรายงานคอมเมนต์เดิมซ้ำไม่ได้

## ถ้ากระทู้หรือคอมเมนต์ถูกซ่อน

- กระทู้ที่ถูกซ่อนจะหายจากรายการ และเปิดจากลิงก์เดิมไม่ได้
- คอมเมนต์ที่ถูกซ่อนจะหายไปทั้งคอมเมนต์และของที่ตอบอยู่ใต้มัน
- ถ้าเปิดลิงก์ที่ถูกซ่อนอยู่ จะเห็นข้อความ **เนื้อหานี้เปิดดูไม่ได้แล้ว**

ถ้าเป็นกระทู้ของเราเองที่ถูกซ่อน และคิดว่าเข้าใจผิด ให้ติดต่อสภานักเรียนโดยตรง

## ข้อจำกัดและข้อควรระวัง

- โหวตแล้วเปลี่ยนไม่ได้ และบอร์ดโหวตไม่มีคอมเมนต์
- แก้ไขกระทู้หลังเผยแพร่จากหน้าผู้ใช้ไม่ได้
- ไม่มีแชทส่วนตัวในระบบ
- การซ่อนกระทู้ทำได้เฉพาะสภานักเรียนและผู้ดูแลระบบ
- กระทู้ที่มาจากเรื่องที่สภาอนุมัติจะผูกกับเรื่องต้นทาง ตามกลับไปดูที่มาได้
- คอมเมนต์ใหม่จะแจ้งเตือนเจ้าของกระทู้และคนที่ถูกตอบ

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: กดโหวตแล้วขึ้นว่าโหวตบอร์ดนี้ไปแล้ว?**

👉 **วิธีแก้:** บัญชีนี้เคยโหวตบอร์ดนี้แล้ว ระบบให้หนึ่งเสียงต่อคนต่อบอร์ด

**Q: เสนอไอเดียแล้วไม่เห็นบนบอร์ด?**

👉 **วิธีแก้:** เช็กว่ากด **เผยแพร่ข้อเสนอ** สำเร็จแล้วหรือยัง
ถ้าขึ้นว่าผิดพลาดให้ลองใหม่ ถ้าสำเร็จจริงข้อเสนอจะขึ้นทันที

**Q: ตอบคอมเมนต์ไม่ได้?**

👉 **วิธีแก้:** อาจถึงความลึกสูงสุดของเธรด ให้กดตอบกลับที่คอมเมนต์ชั้นบนแทน

**Q: รายงานแล้วต้องรอนานไหม?**

👉 **วิธีแก้:** ไม่มีกำหนดตายตัว สภาจะตรวจตามลำดับคิว เมื่อจัดการแล้วจะแจ้งผลกลับให้

**Q: กระทู้หายไปไหน?**

👉 **วิธีแก้:** อาจถูกซ่อนโดยสภา ถ้าเปิดจากลิงก์เดิมจะเห็นข้อความแจ้ง ให้กลับไปที่หน้ารวมบอร์ด

**Q: ข้อเสนอของฉันจะแสดงชื่อไหม?**

👉 **วิธีแก้:** ถ้าติ๊ก **ไม่แสดงชื่อผู้เสนอ** คนอื่นจะไม่เห็นชื่อ แต่สภานักเรียนยังเห็น
เพื่อให้ตรวจย้อนหลังได้ถ้ามีปัญหา
