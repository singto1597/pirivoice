# บอร์ดพูดคุย การโหวต และการเสนอไอเดีย

บอร์ดคือที่ที่นักเรียนคุยกันเอง ไม่ได้ผ่านการรับเรื่องแบบกรณีปัญหา
ใช้โหวตหาเสียงข้างมาก ใช้คุยเรื่องทั่ว ๆ ไป และใช้เสนอไอเดียที่อยากให้สภาช่วยผลักดัน

## บอร์ดมีสามแบบ

![ภาพที่ 1 — หน้ารวมบอร์ดและตัวกรอง](../assets/screenshots/user/boards.webp)

| ประเภท | ใช้ทำอะไร | คอมเมนต์ |
|---|---|---|
| **โหวต** | เลือกตัวเลือกจากที่ตั้งไว้ หนึ่งคนหนึ่งเสียง | ไม่มี |
| **พูดคุย** | ตั้งกระทู้คุยกันเรื่องทั่วไป | มี |
| **ข้อเสนอแนะ** | เสนอไอเดียให้สภานักเรียนพิจารณา | มี |

ตัวกรอง **ทั้งหมด** **โหวต** **พูดคุย** **ข้อเสนอแนะ** อยู่ใต้หัวจอ
ถ้าอยากหาเรื่องที่สนใจ ใช้ช่อง **ค้นหาบอร์ด...** ได้

## อ่านบอร์ด

1. กดแท็บ **บอร์ด**
2. เลือกประเภทที่อยากอ่าน หรือปล่อยไว้ที่ **ทั้งหมด**
3. กดการ์ดกระทู้เพื่อเปิดอ่าน
4. เลื่อนอ่านคอมเมนต์ด้านล่าง

กระทู้ที่ถูกซ่อนหรือปิดแล้วจะไม่ขึ้นในรายการ

## โหวต

1. เปิดบอร์ดประเภท **โหวต**
2. อ่านตัวเลือกทั้งหมดก่อน
3. กดเลือกตัวเลือกที่ต้องการ ตามหมายเลข 1 หรือ 2 ในภาพ
4. กดปุ่มโหวตตามหมายเลข 3

![ภาพที่ 2 — หน้าบอร์ดโหวต](../assets/screenshots/user/board-vote.webp)

หลังโหวต ระบบจะแสดงจำนวนเสียงและเปอร์เซ็นต์ของแต่ละตัวเลือก
และขึ้นข้อความว่า **คุณส่งเสียงโหวตแล้ว — แต่ละคนโหวตได้ 1 ครั้ง**

::: warning โหวตแล้วเปลี่ยนไม่ได้
เลือกได้หนึ่งตัวเลือกต่อบอร์ด และแก้ทีหลังไม่ได้ เลือกให้ดีก่อนกด
:::

ถ้าอยากกลับมาอ่านบอร์ดเดิมทีหลัง กดไอคอนบุ๊กมาร์กตามหมายเลข 4 ในภาพ
แล้วไปดูได้ที่ **เพิ่มเติม** → **กิจกรรมของฉัน** → **บันทึกไว้**

## แสดงความคิดเห็นและตอบกลับ

บอร์ด **พูดคุย** และ **ข้อเสนอแนะ** เปิดให้คอมเมนต์

1. เลื่อนลงไปที่ช่อง **ร่วมแสดงความเห็น...**
2. พิมพ์ข้อความแล้วกด **ส่ง**
3. ถ้าจะตอบใคร ให้กดปุ่มตอบใต้คอมเมนต์ของคนนั้น

ถ้าตอบซ้อนกันหลายชั้นจนถึงขีดจำกัดของระบบ ให้กดตอบกลับที่คอมเมนต์ชั้นบนแทน
ข้อความจะยังอยู่ในเธรดเดียวกันและอ่านง่ายกว่า

::: tip คุยกันให้สนุก
คอมเมนต์แสดงชื่อจริงของคนเขียนเสมอ เขียนเหมือนคุยกับเพื่อนต่อหน้า
ถ้าไม่เห็นด้วยให้แย้งที่เหตุผล ไม่ต้องแย้งที่ตัวคน
:::

## เสนอไอเดียใหม่

1. กดแท็บ **บอร์ด**
2. กดปุ่ม **เสนอไอเดีย** ที่มุมล่างขวา
3. กรอก **หัวข้อ** อย่างน้อย 3 ตัวอักษร
4. เขียน **รายละเอียด** ว่าไอเดียนี้ช่วยอะไร และทำได้อย่างไร
5. ถ้าไม่อยากให้เห็นชื่อ ให้ติ๊ก **ไม่แสดงชื่อผู้เสนอ**
6. กด **เผยแพร่ข้อเสนอ**

![ภาพที่ 3 — หน้าสร้างข้อเสนอ](../assets/screenshots/user/new-suggestion.webp)

หมายเลขในภาพคือ 1 หัวข้อ 2 รายละเอียด 3 ช่องไม่แสดงชื่อผู้เสนอ และ 4 ปุ่มเผยแพร่

::: info ขึ้นบอร์ดทันที แต่สภายังเห็นว่าใครเสนอ
ข้อเสนอไม่ต้องรออนุมัติ ขึ้นบอร์ดให้ทุกคนเห็นเลย
แต่ถ้าติ๊กไม่แสดงชื่อ ผู้ใช้ทั่วไปจะไม่เห็นชื่อผู้เสนอ ขณะที่สภานักเรียนยังเห็น
เพื่อให้ตรวจสอบย้อนหลังได้หากมีปัญหา
:::

## รายงานคอมเมนต์ที่ไม่เหมาะสม

ถ้าเจอข้อความที่ทำให้คนอื่นเสียหาย ช่วยกันรายงานได้

1. เปิดคอมเมนต์นั้น
2. กดตัวเลือก **รายงาน**
3. เลือกเหตุผล

| เหตุผล | ใช้เมื่อ |
|---|---|
| **กลั่นแกล้ง/คุกคาม** | มีการข่มขู่หรือคุกคาม |
| **คำหยาบคาย** | ใช้ถ้อยคำไม่สุภาพ |
| **สแปม/โฆษณา** | โพสต์ซ้ำหรือขายของ |
| **เปิดเผยข้อมูลส่วนตัว** | เปิดเผยชื่อ เบอร์ หรือข้อมูลของผู้อื่น |
| **อื่น ๆ** | กรณีอื่นที่ไม่อยู่ในรายการ |

4. เขียนรายละเอียดเพิ่มเติมได้ไม่เกิน 500 ตัวอักษร
5. กดส่ง

::: info รายงานแล้วเกิดอะไรต่อ
รายงานจะเข้าคิวของสภานักเรียน สภาจะดูแล้วตัดสินว่าจะซ่อนคอมเมนต์หรือไม่
ผลจะแจ้งกลับให้คนที่รายงานทราบ
บัญชีหนึ่งรายงานค้างได้ไม่เกิน 10 รายการ และรายงานคอมเมนต์เดิมซ้ำไม่ได้
:::

## ถ้ากระทู้หรือคอมเมนต์ถูกซ่อน

- กระทู้ที่ถูกซ่อนจะหายจากรายการ และเปิดจากลิงก์เดิมไม่ได้
- คอมเมนต์ที่ถูกซ่อนจะหายไปทั้งคอมเมนต์และของที่ตอบอยู่ใต้มัน
- ถ้าเปิดลิงก์ที่ถูกซ่อนอยู่ จะเห็นข้อความ **เนื้อหานี้เปิดดูไม่ได้แล้ว**

ถ้าเป็นกระทู้ของเราเองที่ถูกซ่อน และคิดว่าเข้าใจผิด ให้ติดต่อสภานักเรียนโดยตรง

## ระบบทำอะไรเบื้องหลัง

บอร์ดที่มาจากเรื่องที่สภาอนุมัติจะผูกกับเรื่องต้นทาง เพื่อให้ตามกลับไปดูที่มาได้

การโหวตถูกบันทึกหนึ่งครั้งต่อคนต่อบอร์ด นับคะแนนทันทีที่กด
การเปิดกระทู้นับยอดผู้อ่านแบบไม่ซ้ำคน

คอมเมนต์ใหม่จะแจ้งเตือนเจ้าของกระทู้และคนที่ถูกตอบ
ส่วนผลการตรวจรายงานจะแจ้งกลับคนที่รายงาน

## ข้อจำกัดและข้อควรระวัง

- โหวตแล้วเปลี่ยนไม่ได้ และบอร์ดโหวตไม่มีคอมเมนต์
- แก้ไขกระทู้หลังเผยแพร่จากหน้าผู้ใช้ไม่ได้
- ไม่มีแชทส่วนตัวในระบบ
- การซ่อนกระทู้ทำได้เฉพาะสภานักเรียนและผู้ดูแลระบบ

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: กดโหวตแล้วขึ้นว่าโหวตบอร์ดนี้ไปแล้ว**
ตอบ: บัญชีนี้เคยโหวตบอร์ดนี้แล้ว ระบบให้หนึ่งเสียงต่อคนต่อบอร์ด

**ถาม: เสนอไอเดียแล้วไม่เห็นบนบอร์ด**
ตอบ: เช็กว่ากด **เผยแพร่ข้อเสนอ** สำเร็จและขึ้นข้อความยืนยันแล้วหรือยัง
ถ้าขึ้นข้อความผิดพลาดให้ลองใหม่ ถ้าสำเร็จจริงข้อเสนอจะขึ้นทันที

**ถาม: ตอบคอมเมนต์ไม่ได้**
ตอบ: อาจถึงความลึกสูงสุดของเธรด ให้กดตอบกลับที่คอมเมนต์ชั้นบนแทน

**ถาม: รายงานแล้วต้องรอนานไหม**
ตอบ: ไม่มีกำหนดตายตัว สภาจะตรวจตามลำดับคิว เมื่อจัดการแล้วระบบจะแจ้งผลกลับ

**ถาม: กระทู้หายไปไหน**
ตอบ: อาจถูกซ่อนโดยสภา ถ้าเปิดจากลิงก์เดิมจะเห็นข้อความแจ้ง ให้กลับไปที่หน้ารวมบอร์ด

**ถาม: ข้อเสนอของฉันแสดงชื่อไหม**
ตอบ: ถ้าติ๊ก **ไม่แสดงชื่อผู้เสนอ** ผู้อื่นจะไม่เห็นชื่อ แต่สภานักเรียนยังเห็น
เพื่อรับผิดชอบต่อข้อเสนอที่เผยแพร่
