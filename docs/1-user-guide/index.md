# คู่มือผู้ใช้ PIRIvoice

PIRIvoice เป็นช่องทางของนักเรียนสำหรับบอกสภานักเรียนว่าโรงเรียนมีอะไรที่อยากให้แก้
หรือมีอะไรที่ดีอยู่แล้วและอยากให้ทำต่อ เรื่องเล็กอย่างน้ำดื่มในโรงอาหาร เรื่องใหญ่
อย่างห้องเรียนที่ร้อนจนเรียนไม่ไหว หรือเรื่องที่อยากให้เพื่อนทั้งโรงเรียนช่วยกันโหวต
ส่งผ่านแอปนี้ได้ทั้งหมด

ในแอปเดียวคุณจะแจ้งเรื่อง ติดตามว่าเรื่องไปถึงไหนแล้ว โหวตบอร์ด ลงทะเบียนกิจกรรม
และอ่านคู่มือการทำงานของสภานักเรียนได้ครบ ไม่ต้องจำหลายเว็บ

คู่มือเล่มนี้เขียนแบบพี่เล่าให้น้องฟัง อ่านทีละบทไม่ยาก แต่ละบทมีภาพประกอบที่วงปุ่มไว้
ให้เห็นชัดว่าต้องกดตรงไหน ถ้าเพิ่งเริ่มใช้ ให้อ่านสามบทแรกตามลำดับ ที่เหลือค่อยเปิด
ตอนต้องใช้จริง

## สิ่งที่ระบบยังไม่รองรับ

คู่มือเล่มนี้เขียนจากสิ่งที่ทำได้จริงในระบบ ถ้าลองหาปุ่มต่อไปนี้แล้วไม่เจอ
ไม่ใช่เพราะหาไม่เจอ แต่เพราะยังไม่มีในเวอร์ชันนี้

::: warning ยังไม่มีในระบบ
- ไม่มีปุ่มลืมรหัสผ่าน ไม่มี OTP และไม่มีรีเซ็ตทางอีเมล ถ้าลืมรหัสต้องบอกครูหรือผู้ดูแลระบบ
- สมัครสมาชิกเองไม่ได้ บัญชีสร้างโดยโรงเรียน
- แนบรูปหรือไฟล์ในเรื่องและคอมเมนต์ไม่ได้
- ไม่มีโหมดมืด ไม่มีภาษาอังกฤษ และไม่มีการแจ้งเตือนทางอีเมลหรือ SMS
:::

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: ต้องใช้อีเมลโรงเรียนหรือรหัสจากที่ไหนเข้าล่ะ**
ตอบ: ใช้ **รหัสนักเรียน** เป็นทั้งชื่อผู้ใช้และรหัสผ่านครั้งแรก โรงเรียนเป็นคนออกบัญชีให้
ไม่ต้องมีอีเมล

**ถาม: ต้องติดตั้งแอปก่อนถึงจะใช้ได้ไหม**
ตอบ: ไม่ต้อง เปิดผ่านเบราว์เซอร์ก็ใช้ได้ครบ แต่ถ้าติดตั้งลงหน้าจอโฮมจะเปิดเร็วกว่า
และรับแจ้งเตือนได้ด้วย ดูวิธีได้ที่ [การเข้าสู่ระบบและติดตั้งแอปลงมือถือ](getting-started-pwa.md)

**ถาม: ใช้บนคอมพิวเตอร์ได้ไหม**
ตอบ: ได้ ระบบออกแบบมาให้ใช้บนมือถือก่อน แต่หน้าจอคอมพิวเตอร์ก็เปิดได้ปกติ

**ถาม: แจ้งเรื่องแล้วคนอื่นจะรู้ไหมว่าเป็นเรา**
ตอบ: เลือกได้ ตอนกรอกรายละเอียดมีช่อง **ซ่อนชื่อฉัน (ไม่ระบุตัวตน)**
แต่ผู้ที่ต้องลงมือแก้เรื่องยังเห็นข้อมูลเท่าที่จำเป็น อ่านรายละเอียดได้ที่
[การแจ้งเรื่องและติดตามสถานะ](issue-reporting-tracking.md)

**ถาม: เจอคำที่ไม่เข้าใจในคู่มือ ทำอย่างไรดี**
ตอบ: เปิดบทที่ตรงกับเรื่องนั้นก่อน บทเหล่านี้อธิบายคำที่ใช้ในแอปไปพร้อมกับขั้นตอน
ถ้ายังไม่ชัด ให้ถามครูที่ดูแลระบบหรือสภานักเรียนได้เลย
