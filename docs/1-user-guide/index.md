# เล่ม 1 — คู่มือผู้ใช้

เล่มนี้สำหรับนักเรียนและสมาชิกทุกคนที่เข้าใช้งาน PIRIvoice ด้วยบัญชีของตนเอง
อ่านตามลำดับได้ หรือข้ามไปยังงานที่ต้องการได้ทันที

## ใครใช้เล่มนี้

- นักเรียนที่ต้องการแจ้งเรื่อง ติดตามสถานะ โหวตบอร์ด หรือลงทะเบียนกิจกรรม
- หัวหน้าห้อง รองฝ่าย ประธานระดับ สภานักเรียน และครู ที่ต้องการใช้ฟังก์ชันพื้นฐาน
  ส่วนงานจัดการมีรายละเอียดใน [เล่ม 2](../2-staff-operations/index.md)

## เริ่มใน 10 นาที

1. เข้าเว็บไซต์ของโรงเรียน หรือเปิดแอปที่ติดตั้งไว้
2. กรอก **รหัสนักเรียน** และ **รหัสผ่าน** รหัสผ่านเริ่มต้นคือรหัสนักเรียนของตนเอง
3. หากระบบแจ้งให้เปลี่ยนรหัสผ่าน ให้ตั้งรหัสใหม่ทันที
4. อนุญาตการแจ้งเตือนบนอุปกรณ์ หากต้องการรับข่าวแม้ปิดแอป
5. เปิด **หน้าแรก** เพื่อดูงานที่รอ ประกาศ และกิจกรรมใกล้ปิดรับ
6. กดปุ่ม **แจ้งเรื่อง** เมื่อต้องการส่งปัญหาหรือข้อเสนอแนะ

## สิ่งที่ระบบยังไม่รองรับ

- ไม่มีปุ่มลืมรหัสผ่านหรือรีเซ็ตผ่านอีเมล หากลืมรหัสให้ติดต่อผู้ดูแลระบบ
- ไม่มีสมัครสมาชิกเอง บัญชีสร้างโดยผู้ดูแลหรือการนำเข้า Excel
- ไม่มีโหมดมืด ภาษาอังกฤษ หรือการแจ้งเตือนทางอีเมลและ SMS
- ไม่สามารถแนบรูปในเรื่องหรือคอมเมนต์ได้

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: เปิดเว็บแล้วขึ้นหน้าเข้าสู่ระบบตลอด ทำไมไม่เข้าหน้าแรก**
ตอบ: ระบบต้องยืนยันตัวตนก่อนทุกครั้งที่ไม่มี token ที่ยังใช้ได้ ให้กรอกรหัสนักเรียนและรหัสผ่าน
หากเพิ่งเปลี่ยนรหัส ให้ใช้รหัสใหม่

**ถาม: รหัสผ่านเริ่มต้นคืออะไร**
ตอบ: รหัสนักเรียนของตนเอง ระบบจะบังคับให้เปลี่ยนหลังเข้าครั้งแรกหรือเมื่อผู้ดูแลตั้งค่าไว้

**ถาม: ทำไมบางเมนูไม่แสดง**
ตอบ: เมนูแสดงตามสิทธิ์ของตำแหน่ง เช่น เมนู **จัดการกิจกรรม** แสดงเฉพาะผู้มีสิทธิ์จัดการกิจกรรม
หากคิดว่าควรมีสิทธิ์ ให้ติดต่อผู้ดูแลระบบ

**ถาม: ใช้เว็บบนมือถือได้ไหม**
ตอบ: ได้ ระบบออกแบบสำหรับมือถือก่อน และติดตั้งเป็นแอปได้ทั้ง Android และ iPhone
ดูขั้นตอนใน [เริ่มใช้งานและติดตั้งแอป](getting-started-pwa.md)

**ถาม: ข้อมูลของฉันปลอดภัยแค่ไหน**
ตอบ: ระบบเก็บรหัสผ่านแบบ hash ไม่เก็บข้อความจริง เรื่องที่แจ้งแบบไม่ระบุตัวตนจะซ่อนชื่อผู้แจ้ง
แต่ผู้ดูแลระบบและผู้ที่เกี่ยวข้องยังเห็นข้อมูลเท่าที่จำเป็นต่อการดำเนินงาน

**ถาม: อยากอ่านคู่มือแบบไฟล์เดียว**
ตอบ: เอกสารชุดนี้แยกเป็นไฟล์ตามบท เปิดจาก [หน้าหลัก](../index.md) ได้ทุกบท
