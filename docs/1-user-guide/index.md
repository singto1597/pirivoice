# คู่มือผู้ใช้ PIRIvoice

PIRIvoice คือช่องทางที่นักเรียนคุยกับสภานักเรียนได้ตรง ๆ
อยากให้โรงเรียนแก้อะไร ส่งเข้ามาแล้วตามดูได้เลยว่าเรื่องไปถึงไหนแล้ว

ในเล่มนี้มีอะไรให้ใช้บ้าง:

- ✉️ **แจ้งเรื่อง** — ปัญหาในโรงเรียน ข้อเสนอ หรือเรื่องสุขภาวะทางใจ
- 🗳️ **บอร์ดโหวตและพูดคุย** — หนึ่งคนหนึ่งเสียง และคอมเมนต์ได้
- 🎫 **กิจกรรม** — ลงทะเบียน เข้าคิวสำรอง และบัตรเช็คอิน
- 📚 **คู่มือสภา 6 เล่ม** — เปิดอ่านได้ทุกคน ไม่ต้องเป็นสมาชิกสภาก่อน

คู่มือเขียนแบบพี่เล่าให้น้องฟัง ทุกภาพวงปุ่มที่ต้องกดไว้ให้แล้ว
ถ้าเพิ่งเริ่ม ให้อ่านสามบทแรกตามลำดับ ที่เหลือค่อยเปิดตอนต้องใช้จริง

## ยังไม่มีในระบบนี้

ถ้าลองหาปุ่มพวกนี้แล้วไม่เจอ ไม่ใช่เพราะหาไม่เจอนะ แต่ยังไม่มีจริง ๆ ในเวอร์ชันนี้

- ❌ ไม่มีปุ่มลืมรหัสผ่าน ไม่มี OTP และไม่มีรีเซ็ตทางอีเมล — ถ้าลืมต้องบอกครูหรือผู้ดูแลระบบ
- ❌ สมัครสมาชิกเองไม่ได้ โรงเรียนเป็นคนสร้างบัญชีให้
- ❌ แนบรูปหรือไฟล์ในเรื่องและคอมเมนต์ไม่ได้
- ❌ ไม่มีโหมดมืด ไม่มีภาษาอังกฤษ และไม่มีการแจ้งเตือนทางอีเมลหรือ SMS

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: ต้องใช้อีเมลโรงเรียนหรือรหัสจากไหนเข้าล่ะ?**

👉 **วิธีแก้:** ใช้ **รหัสนักเรียน** เป็นทั้งชื่อผู้ใช้และรหัสผ่านครั้งแรก โรงเรียนเป็นคนออกบัญชีให้ ไม่ต้องมีอีเมล

**Q: ต้องติดตั้งแอปก่อนหรือเปล่า ถึงจะใช้ได้?**

👉 **วิธีแก้:** ไม่ต้อง เปิดผ่านเบราว์เซอร์ก็ใช้ได้ครบ แต่ถ้าติดตั้งลงหน้าจอโฮมจะเปิดเร็วกว่าและรับแจ้งเตือนได้ — วิธีติดตั้งอยู่ใน [เข้าสู่ระบบและติดตั้งแอป](getting-started-pwa.md)

**Q: ใช้บนคอมพิวเตอร์ได้ไหม?**

👉 **วิธีแก้:** ได้ครับ ออกแบบมาให้ใช้บนมือถือก่อน แต่เปิดบนจอคอมก็ใช้ได้ปกติ

**Q: แจ้งเรื่องแล้วคนอื่นจะรู้ไหมว่าเป็นเรา?**

👉 **วิธีแก้:** เลือกได้ ตอนกรอกรายละเอียดมีช่อง **ซ่อนชื่อฉัน (ไม่ระบุตัวตน)** ติ๊กไว้ได้เลย แต่คนที่ต้องลงมือแก้ยังเห็นข้อมูลเท่าที่จำเป็น — อ่านต่อที่ [แจ้งเรื่องและติดตามสถานะ](issue-reporting-tracking.md)

**Q: เจอคำในคู่มือที่ไม่เข้าใจ ทำไงดี?**

👉 **วิธีแก้:** เปิดบทที่ตรงกับเรื่องนั้นก่อน บทเหล่านี้อธิบายคำไปพร้อมกับขั้นตอน ถ้ายังไม่ชัด ทักครูที่ดูแลระบบหรือสภานักเรียนได้เลย
