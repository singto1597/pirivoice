# การแจ้งเตือนและการตั้งค่า

การแจ้งเตือนมีสองชั้น ชั้นแรกคือรายการในแอปที่รอให้เราเปิดมาอ่าน
ชั้นที่สองคือเสียงหรือป้ายที่เด้งขึ้นบนมือถือตอนปิดแอปอยู่
บทนี้อธิบายวิธีเปิดชั้นที่สอง และวิธีเลือกว่าจะรับเรื่องไหนบ้าง

## เปิดการแจ้งเตือนบนมือถือ

1. เปิด **เพิ่มเติม** ที่แถบล่าง
2. เลือก **ตั้งค่า**
3. เลื่อนลงจนเจอการ์ด **แจ้งเตือนถึงมือถือ**
4. กดสวิตช์ในการ์ดนั้น
5. เบราว์เซอร์จะถามสิทธิ์ ให้เลือก **อนุญาต**

![ภาพที่ 1 — การ์ดแจ้งเตือนถึงมือถือในหน้าตั้งค่า](../assets/screenshots/user/push-settings.webp)

เมื่อเปิดสำเร็จ การ์ดจะเปลี่ยนจาก **ยังไม่ได้เปิดบนเครื่องนี้** เป็นสถานะที่เปิดแล้ว

::: tip เปิดแยกทีละเครื่อง
การเปิดบนมือถือไม่ทำให้คอมพิวเตอร์ที่บ้านได้เสียงเตือนด้วย
ต้องเปิดบนอุปกรณ์เครื่องนั้นเองทุกเครื่อง
:::

::: info iPhone ต้องติดตั้งก่อน
บน iPhone ต้องเพิ่ม PIRIvoice ลงหน้าจอโฮมก่อน จึงจะเปิดการแจ้งเตือนได้
ถ้ายังไม่ได้ติดตั้ง ทำตาม [การเข้าสู่ระบบและติดตั้งแอปลงมือถือ](getting-started-pwa.md) ก่อน
:::

## เลือกว่าจะรับเรื่องอะไร

ในหน้า **ตั้งค่า** หัวข้อ **การแจ้งเตือน** มีสวิตช์ให้เลือกห้ากลุ่ม

![ภาพที่ 2 — กลุ่มการแจ้งเตือนที่ปิดได้](../assets/screenshots/user/notification-settings.webp)

| หมายเลข | กลุ่ม | จะเตือนเมื่อ |
|---|---|---|
| 1 | **เรื่องของฉัน** | เรื่องที่เราแจ้งมีคนตอบกลับ หรือสถานะเปลี่ยน |
| 2 | **เรื่องที่รับผิดชอบ** | มีเรื่องใหม่เข้ามาในระดับที่เราดูแล |
| 3 | **บอร์ด** | มีกระทู้ใหม่ มีคนตอบ หรือผลโหวตเปลี่ยน |
| 4 | **จัดการรายงาน** | มีคนรายงานเนื้อหา และเมื่อผลตรวจออก |
| 5 | **กิจกรรม** | มีกิจกรรมใหม่เปิดรับ หรือเราถูกเลื่อนจากคิวสำรองเป็นตัวจริง |

ปิดสวิตช์ไหน เรื่องนั้นจะไม่ขึ้นทั้งในแอปและการแจ้งเตือนบนมือถือ
ถ้าเป็นนักเรียนทั่วไปที่ไม่ได้มีหน้าที่ในสภา จะเห็นกลุ่ม **เรื่องที่รับผิดชอบ**
และ **จัดการรายงาน** อยู่ด้วย แต่จะไม่มีการแจ้งเตือนเข้ามา เพราะไม่มีเรื่องส่งมาถึงเรา

::: warning ประกาศฉุกเฉินปิดไม่ได้
รายการสุดท้ายคือ **ประกาศฉุกเฉิน** ซึ่งมีรูปกุญแจและข้อความ **ปิดไม่ได้**
เพราะใช้แจ้งเรื่องที่ทุกคนต้องรู้ทันเวลา เช่น เหตุฉุกเฉินในโรงเรียน
:::

## ช่วงเวลาเงียบ

โรงเรียนตั้งช่วงเวลาเงียบไว้ที่ **22:00–06:00** ในช่วงนี้ระบบจะไม่ส่งเสียงหรือป้าย
ขึ้นที่มือถือ แต่ยังสร้างรายการไว้ในแอปตามปกติ

![ภาพที่ 3 — ช่วงเวลาไม่ส่งแจ้งเตือน](../assets/screenshots/user/quiet-hours.webp)

พอตื่นเช้ามาเปิดแอป จะเห็นรายการที่เกิดขึ้นตอนกลางคืนครบ ไม่มีอะไรหายไป
ยกเว้น **ประกาศฉุกเฉิน** ที่ข้ามช่วงเวลาเงียบได้เสมอ ถ้ามีเหตุจริงตอนตีสอง
มือถือยังดัง

ค่าในช่วงเวลาเงียบเป็นค่าของทั้งโรงเรียน นักเรียนดูได้แต่แก้ไม่ได้
ถ้าคิดว่าควรปรับ ให้บอกครูหรือผู้ดูแลระบบ

## ดูย้อนหลังและกดอ่านทั้งหมด

1. กดไอคอน **กระดิ่ง** ที่มุมขวาบนของทุกหน้า
2. เลือกดู **ทั้งหมด** หรือ **ยังไม่อ่าน**
3. กดที่รายการเพื่อเปิดหน้าที่เกี่ยวข้อง
4. กดปุ่มเมนูข้างกระดิ่งเพื่อกรองตามกลุ่ม หรือกด **อ่านทั้งหมด** เพื่อเคลียร์ทั้งกลุ่ม

![ภาพที่ 4 — ศูนย์การแจ้งเตือน](../assets/screenshots/user/notifications.webp)

ตัวเลขบนกระดิ่งคือจำนวนที่ยังไม่อ่าน ถ้าเกินเก้าสิบเก้าจะแสดงเป็น `99+`
ตัวเลขจะลดลงเมื่อเปิดอ่าน แล้วจะหายไปเมื่ออ่านครบ

## ระบบทำอะไรเบื้องหลัง

รายการแจ้งเตือนถูกเก็บไว้ในระบบของโรงเรียน ไม่ได้อยู่ในมือถือ
ดังนั้นเปลี่ยนเครื่องแล้วยังเห็นรายการเก่าได้ครบ

การปิดกลุ่มมีผลกับการแจ้งเตือนใหม่ ไม่ได้ลบรายการเก่าที่ค้างอยู่
ถ้าอยากเคลียร์ของเก่า ให้กด **อ่านทั้งหมด**

การส่งเสียงเตือนไปยังมือถืออาจล่าช้าได้เล็กน้อยถ้าสัญญาณไม่ดี
แต่รายการในแอปจะมาถึงก่อนเสมอ

## ข้อจำกัดและข้อควรระวัง

- ถ้าปิดสิทธิ์แจ้งเตือนใน Settings ของเครื่อง จะไม่ได้รับเสียงเตือนเลย
  แม้ในแอปจะเปิดไว้ก็ตาม
- ระบบไม่มีอีเมลหรือ SMS สำรอง ถ้าไม่ได้รับเสียงเตือนให้เปิดแอปมาดู
- เปลี่ยนมือถือต้องเปิด **แจ้งเตือนถึงมือถือ** บนเครื่องใหม่เอง
- โหมดห้ามรบกวนของมือถืออาจกลบเสียงเตือนของแอปได้

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: เปิดแล้วแต่ยังไม่มีเสียงเตือน**
ตอบ: เช็กสามจุด หนึ่ง สิทธิ์การแจ้งเตือนใน Settings ของเครื่อง สอง โหมดห้ามรบกวน
สาม กลุ่มนั้นยังเปิดอยู่ในหน้า **ตั้งค่า** ของ PIRIvoice หรือไม่

**ถาม: ปิดกลุ่มแล้วทำไมยังมีรายการในแอป**
ตอบ: รายการที่เกิดก่อนปิดจะยังอยู่ การปิดมีผลกับรายการใหม่เท่านั้น
กด **อ่านทั้งหมด** เพื่อเคลียร์ของเก่า

**ถาม: ปิดประกาศฉุกเฉินได้ไหม**
ตอบ: ไม่ได้ ระบบตั้งใจให้ประกาศประเภทนี้ถึงทุกคนเสมอ

**ถาม: กลางคืนไม่มีเสียงเลย ปกติไหม**
ตอบ: ปกติ เพราะอยู่ในช่วงเวลาเงียบ 22:00–06:00 รายการยังเข้ามาครบ
เปิดแอปตอนเช้าจะเห็นทั้งหมด

**ถาม: ตัวเลขบนกระดิ่งไม่ตรงกับรายการ**
ตอบ: ตัวเลขอัปเดตช้ากว่าหน้าจอเล็กน้อย เปิดหน้าการแจ้งเตือนแล้วรอสักครู่จะตรงกัน

**ถาม: เปลี่ยนมือถือแล้วต้องทำอะไร**
ตอบ: เปิด **แจ้งเตือนถึงมือถือ** บนเครื่องใหม่ และถ้าเครื่องเก่ายังใช้ได้ให้ปิดไว้
ระบบรองรับหลายเครื่อง แต่แต่ละเครื่องต้องเปิดสิทธิ์เอง
