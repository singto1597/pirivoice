# การแจ้งเตือนและการตั้งค่า

บทนี้อธิบายวิธีเลือกว่าจะรับเรื่องอะไร เปิดการแจ้งเตือนบนอุปกรณ์ และทำความเข้าใจช่วงเวลาเงียบของโรงเรียน

## ใครใช้บทนี้

ผู้ใช้ทุกคนที่ต้องการควบคุมการแจ้งเตือนของตนเอง

## ก่อนเริ่ม

- ต้องเข้าสู่ระบบแล้ว
- การเปิด push ต้องอนุญาตการแจ้งเตือนในเบราว์เซอร์หรือระบบปฏิบัติการ
- ค่า **ช่วงเวลาเงียบ** เป็นค่าของทั้งโรงเรียน ผู้ใช้ทั่วไปดูได้แต่แก้ไม่ได้

## ถ้าต้องการปิดการแจ้งเตือนบางกลุ่ม

1. เปิด **เพิ่มเติม**
2. เลือก **ตั้งค่า**
3. ในหัวข้อ **การแจ้งเตือน** จะเห็นรายการกลุ่ม
4. ปิดสวิตช์กลุ่มที่ไม่ต้องการ เช่น **เรื่องของฉัน** หรือ **บอร์ด**
5. ยืนยันในหน้าต่างที่ขึ้นมา

กลุ่มที่ปิดได้มี 5 กลุ่ม

| กลุ่ม | แจ้งเมื่อ |
|---|---|
| เรื่องของฉัน | เรื่องที่คุณแจ้งมีการรับเรื่อง คอมเมนต์ หรือเปลี่ยนสถานะ |
| เรื่องที่รับผิดชอบ | มีเรื่องใหม่เข้ามาในระดับที่คุณดูแล |
| บอร์ด | มีกระทู้ใหม่ มีคนตอบกลับ หรือกระทู้ของคุณถูกซ่อน |
| จัดการรายงาน | มีรายงานเนื้อหาใหม่รอสภานักเรียนตรวจ |
| กิจกรรม | มีกิจกรรมใหม่ กิจกรรมถูกยกเลิก หรือคุณได้ที่นั่งจากคิวสำรอง |

**ประกาศฉุกเฉิน** ปิดไม่ได้ เพราะใช้แจ้งเหตุที่ต้องถึงทุกคน

## ถ้าต้องการเปิดการแจ้งเตือนบนมือถือ

1. เปิด **ตั้งค่า**
2. เลื่อนไปที่การ์ด **การแจ้งเตือนบนอุปกรณ์**
3. กด **เปิดการแจ้งเตือน**
4. เบราว์เซอร์จะถามสิทธิ์ ให้เลือก **อนุญาต**
5. เมื่อสำเร็จ การ์ดจะแสดงว่าอุปกรณ์นี้เปิดอยู่

แต่ละอุปกรณ์ต้องเปิดแยกกัน การเปิดบนมือถือไม่ทำให้คอมพิวเตอร์ได้รับ push ด้วย

## ถ้าต้องการปิด push บนอุปกรณ์นี้

1. เปิด **ตั้งค่า**
2. ไปที่การ์ด **การแจ้งเตือนบนอุปกรณ์**
3. กด **ปิดการแจ้งเตือน**
4. ระบบจะลบข้อมูลอุปกรณ์นี้ออกจากเซิร์ฟเวอร์

การปิด push ไม่ได้ลบรายการแจ้งเตือนในแอป รายการยังอยู่ใน **การแจ้งเตือน**

## ถ้าต้องการอ่านรายการแจ้งเตือนย้อนหลัง

1. กดไอคอนกระดิ่งที่มุมขวาบน หรือเปิด **เพิ่มเติม** แล้วเลือก **การแจ้งเตือน**
2. เลือกกลุ่มที่ต้องการจากปุ่มกรอง
3. กดรายการเพื่อเปิดหน้าที่เกี่ยวข้อง
4. กด **อ่านทั้งหมด** เพื่อทำเครื่องหมายว่าอ่านแล้วทั้งกลุ่ม

ตัวเลขบนกระดิ่งจะลดลงเมื่ออ่านแล้ว ตัวเลขสูงสุดที่แสดงคือ `99+`

## ถ้าต้องการรู้ว่าทำไมกลางคืนไม่มีเสียงแจ้งเตือน

โรงเรียนกำหนด **ช่วงเวลาเงียบ** ไว้ เช่น 22:00–06:00 ในช่วงนี้ระบบยังสร้างรายการแจ้งเตือนในแอป
แต่จะไม่ส่ง push ไปยังอุปกรณ์

- เปิดแอปตอนเช้าจะยังเห็นรายการครบ
- ประกาศ **ด่วนมาก** ข้ามช่วงเวลาเงียบได้
- ผู้ใช้ทั่วไปดูค่าได้ที่ **ตั้งค่า** แต่แก้ไม่ได้
- ผู้มีสิทธิ์ **จัดการตั้งค่า** เท่านั้นที่แก้ช่วงเวลาได้

## ถ้าต้องการรับประกาศฉุกเฉินให้ได้แม้ปิดกลุ่มอื่น

ไม่มีอะไรต้องตั้งเพิ่ม ประกาศ **ด่วนมาก** ถูกส่งถึงทุกคนและข้ามช่วงเวลาเงียบเสมอ
อย่าปิดการแจ้งเตือนทั้งระบบในเบราว์เซอร์ เพราะจะทำให้ไม่ได้รับแม้ประกาศฉุกเฉิน

## ระบบทำอะไรเบื้องหลัง

- แจ้งเตือนในแอปถูกเก็บในตาราง `notifications`
- รายการใหม่ถูกผลักไปยังหน้าจอผ่าน SSE ทันที หากไม่ได้ใช้ SSE ระบบจะถามใหม่ทุก 30 วินาที
- push ส่งผ่าน outbox ซึ่งมี retry และตรวจอุปกรณ์ที่ปิดใช้งานแล้ว
- การปิดกลุ่มมีผลทั้งในแอปและ push ยกเว้นกลุ่มประกาศ
- ช่วงเวลาเงียบมีผลเฉพาะ push ไม่มีผลกับรายการในแอปและ SSE

## ข้อจำกัดและข้อควรระวัง

- iPhone บางเวอร์ชันรองรับ Web Push เฉพาะเมื่อติดตั้งแอปไว้ที่หน้าจอหลัก
- การปิดสิทธิ์แจ้งเตือนในระบบปฏิบัติการจะทำให้ระบบส่ง push ไม่ถึง แม้ในแอปจะเปิดไว้
- ระบบไม่มีอีเมลหรือ SMS สำรอง
- การเปลี่ยนอุปกรณ์ต้องเปิด push ใหม่บนเครื่องนั้น

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: เปิด push แล้วแต่ไม่ได้รับแจ้งเตือน**
ตอบ: ตรวจสิทธิ์การแจ้งเตือนใน Settings ของเครื่อง ตรวจว่าปิดโหมดห้ามรบกวนหรือไม่
และตรวจว่ากลุ่มนั้นยังเปิดอยู่ในหน้า **ตั้งค่า** ของ PIRIvoice

**ถาม: ทำไมรายการในแอปยังขึ้นทั้งที่ปิดกลุ่มแล้ว**
ตอบ: รายการที่เกิดก่อนปิดจะยังอยู่ การปิดมีผลกับรายการใหม่เท่านั้น
ให้กด **อ่านทั้งหมด** เพื่อเคลียร์รายการเก่า

**ถาม: ปิดประกาศฉุกเฉินได้ไหม**
ตอบ: ไม่ได้ ระบบออกแบบให้ประกาศด่วนถึงทุกคนเสมอ

**ถาม: ตัวเลขบนกระดิ่งไม่ตรงกับรายการ**
ตอบ: ตัวเลขมาจากเซิร์ฟเวอร์และอาจอัปเดตช้ากว่าหน้าจอเล็กน้อย กดเปิดหน้าการแจ้งเตือนเพื่อซิงก์ใหม่

**ถาม: ครูสั่งเปิดช่วงเวลาเงียบ แต่ทำไมยังมีเสียง**
ตอบ: ประกาศด่วนมากข้ามช่วงเวลาเงียบได้ และผู้ใช้ที่ปิดสิทธิ์ระบบปฏิบัติการอาจไม่ได้รับ push
แต่ยังเห็นรายการในแอป

**ถาม: เปลี่ยนมือถือแล้วต้องทำอะไร**
ตอบ: เปิด push บนเครื่องใหม่ และปิด push บนเครื่องเก่าหากยังใช้งานได้
ระบบเก็บอุปกรณ์หลายเครื่องได้ แต่แต่ละเครื่องต้องเปิดสิทธิ์เอง
