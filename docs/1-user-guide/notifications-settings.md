# การแจ้งเตือนและการตั้งค่า

การแจ้งเตือนมีสองชั้น ชั้นแรกคือรายการในแอปที่รอให้เราเปิดมาอ่าน
ชั้นที่สองคือเสียงหรือป้ายที่เด้งขึ้นบนมือถือตอนปิดแอป

- เปิดให้เด้งบนมือถือได้ ในหน้าตั้งค่า
- เลือกได้ว่าจะเตือนเรื่องอะไรบ้าง
- กลางคืน 22:00–06:00 ระบบจะเงียบให้เอง

## เปิดการแจ้งเตือนบนมือถือ

**ทางเข้า:** แท็บ **เพิ่มเติม** ➔ **ตั้งค่า** ➔ การ์ด **แจ้งเตือนถึงมือถือ** ➔ กดสวิตช์ ➔ เบราว์เซอร์ถามสิทธิ์ ให้เลือก **อนุญาต**

![ภาพที่ 1 — การ์ดแจ้งเตือนถึงมือถือในหน้าตั้งค่า](../assets/screenshots/user/push-settings.webp)
*พอกดเปิดสำเร็จ การ์ดจะเปลี่ยนจาก "ยังไม่ได้เปิดบนเครื่องนี้" เป็นสถานะที่เปิดแล้ว*

บน iPhone ต้องเพิ่ม PIRIvoice ลงหน้าจอโฮมก่อน ถึงจะเปิดการแจ้งเตือนได้
ถ้ายังไม่ได้ติดตั้ง ทำตาม [การเข้าสู่ระบบและติดตั้งแอป](getting-started-pwa.md) ก่อน

::: tip เปิดแยกทีละเครื่องนะ
เปิดบนมือถือแล้ว คอมพิวเตอร์ที่บ้านไม่ได้เสียงเตือนตามไปด้วย
ต้องเปิดบนเครื่องนั้นเองทุกเครื่อง
:::

## เลือกได้ว่าจะเตือนเรื่องอะไร

ในหน้า **ตั้งค่า** หัวข้อ **การแจ้งเตือน** มีสวิตช์ให้เลือกห้ากลุ่ม

![ภาพที่ 2 — กลุ่มการแจ้งเตือนที่ปิดได้](../assets/screenshots/user/notification-settings.webp)
*หมายเลข 1–5 คือกลุ่มที่ปิดได้ตามใจเรา*

- **1 · เรื่องของฉัน** — เรื่องที่เราแจ้งมีคนตอบกลับ หรือสถานะเปลี่ยน
- **2 · เรื่องที่รับผิดชอบ** — มีเรื่องใหม่เข้ามาในระดับที่เราดูแล
- **3 · บอร์ด** — มีกระทู้ใหม่ มีคนตอบ หรือผลโหวตเปลี่ยน
- **4 · จัดการรายงาน** — มีคนรายงานเนื้อหา และเมื่อผลตรวจออก
- **5 · กิจกรรม** — มีกิจกรรมใหม่เปิดรับ หรือเราถูกเลื่อนจากคิวสำรองเป็นตัวจริง

ปิดสวิตช์ไหน เรื่องนั้นจะไม่ขึ้นทั้งในแอปและการแจ้งเตือนบนมือถือ
ถ้าเป็นนักเรียนทั่วไปที่ไม่ได้มีหน้าที่ในสภา จะเห็นกลุ่ม **เรื่องที่รับผิดชอบ**
และ **จัดการรายงาน** อยู่ด้วย แต่จะไม่มีการแจ้งเตือนเข้ามา เพราะไม่มีเรื่องส่งมาถึงเรา

::: warning ประกาศฉุกเฉินปิดไม่ได้นะ
รายการสุดท้ายคือ **ประกาศฉุกเฉิน** ที่มีรูปกุญแจและข้อความ **ปิดไม่ได้**
เพราะใช้แจ้งเรื่องที่ทุกคนต้องรู้ทันเวลา เช่น เหตุฉุกเฉินในโรงเรียน
:::

## ช่วงเวลาเงียบ 22:00–06:00

โรงเรียนตั้งช่วงเวลาเงียบไว้ที่ **22:00–06:00** ในช่วงนี้ระบบจะไม่ส่งเสียงหรือป้ายขึ้นที่มือถือ
แต่ยังสร้างรายการไว้ในแอปตามปกติ

![ภาพที่ 3 — ช่วงเวลาที่ไม่ส่งแจ้งเตือน](../assets/screenshots/user/quiet-hours.webp)
*การ์ดนี้บอกช่วงเวลาเงียบของโรงเรียน*

พอตื่นเช้ามาเปิดแอป จะเห็นรายการที่เกิดตอนกลางคืนครบ ไม่มีอะไรหายไป
ยกเว้น **ประกาศฉุกเฉิน** ที่ข้ามช่วงเวลาเงียบได้เสมอ ถ้ามีเหตุจริงตอนตีสอง มือถือยังดัง

ค่าในช่วงเวลาเงียบเป็นค่าของทั้งโรงเรียน นักเรียนดูได้แต่แก้ไม่ได้
ถ้าคิดว่าควรปรับ ให้บอกครูหรือผู้ดูแลระบบ

## ดูย้อนหลังและกดอ่านทั้งหมด

**ทางเข้า:** กด **กระดิ่ง** มุมขวาบนของทุกหน้า ➔ เลือก **ทั้งหมด** หรือ **ยังไม่อ่าน** ➔ กดรายการเพื่อเปิดเรื่องนั้น

![ภาพที่ 4 — ศูนย์การแจ้งเตือน](../assets/screenshots/user/notifications.webp)
*ในหน้านี้กดเมนูข้างกระดิ่งเพื่อกรองตามกลุ่ม หรือกด **อ่านทั้งหมด** เพื่อเคลียร์ทั้งกลุ่ม*

ตัวเลขบนกระดิ่งคือจำนวนที่ยังไม่อ่าน ถ้าเกินเก้าสิบเก้าจะแสดงเป็น `99+`
ตัวเลขจะลดลงเมื่อเปิดอ่าน แล้วหายไปเมื่ออ่านครบ

## ข้อจำกัดและข้อควรระวัง

- ถ้าปิดสิทธิ์แจ้งเตือนใน Settings ของเครื่อง จะไม่ได้เสียงเตือนเลย แม้ในแอปจะเปิดไว้
- ระบบไม่มีอีเมลหรือ SMS สำรอง ถ้าไม่ได้ยินเสียงเตือน ให้เปิดแอปมาดู
- เปลี่ยนมือถือต้องเปิด **แจ้งเตือนถึงมือถือ** บนเครื่องใหม่เอง
- โหมดห้ามรบกวนของมือถืออาจกลบเสียงเตือนของแอปได้
- รายการแจ้งเตือนเก็บอยู่ในระบบของโรงเรียน ไม่ได้อยู่ในมือถือ เปลี่ยนเครื่องแล้วยังเห็นของเก่าได้ครบ
- การปิดกลุ่มมีผลกับการแจ้งเตือนใหม่ ไม่ได้ลบรายการเก่า ถ้าอยากเคลียร์ให้กด **อ่านทั้งหมด**

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: เปิดแล้วแต่ยังไม่มีเสียงเตือน?**

👉 **วิธีแก้:** เช็กสามจุด — สิทธิ์การแจ้งเตือนใน Settings ของเครื่อง, โหมดห้ามรบกวน, และกลุ่มนั้นยังเปิดอยู่ในหน้า **ตั้งค่า** ของ PIRIvoice หรือไม่

**Q: ปิดกลุ่มแล้วทำไมยังมีรายการในแอป?**

👉 **วิธีแก้:** รายการที่เกิดก่อนปิดจะยังอยู่ การปิดมีผลกับรายการใหม่เท่านั้น
กด **อ่านทั้งหมด** เพื่อเคลียร์ของเก่า

**Q: ปิดประกาศฉุกเฉินได้ไหม?**

👉 **วิธีแก้:** ไม่ได้ ระบบตั้งใจให้ประกาศประเภทนี้ถึงทุกคนเสมอ

**Q: กลางคืนไม่มีเสียงเลย ปกติไหม?**

👉 **วิธีแก้:** ปกติ เพราะอยู่ในช่วงเวลาเงียบ 22:00–06:00 รายการยังเข้ามาครบ
เปิดแอปตอนเช้าจะเห็นทั้งหมด

**Q: ตัวเลขบนกระดิ่งไม่ตรงกับรายการ?**

👉 **วิธีแก้:** ตัวเลขอัปเดตช้ากว่าหน้าจอเล็กน้อย เปิดหน้าการแจ้งเตือนแล้วรอสักครู่จะตรงกัน

**Q: เปลี่ยนมือถือแล้วต้องทำอะไรบ้าง?**

👉 **วิธีแก้:** เปิด **แจ้งเตือนถึงมือถือ** บนเครื่องใหม่ และถ้าเครื่องเก่ายังใช้ได้ให้ปิดไว้
ระบบรองรับหลายเครื่อง แต่แต่ละเครื่องต้องเปิดสิทธิ์เอง
