# เริ่มใช้งานและติดตั้งแอป

บทนี้อธิบายวิธีเข้าสู่ระบบครั้งแรก เปลี่ยนรหัสผ่าน ติดตั้ง PIRIvoice บนมือถือ และใช้งานเมื่อไม่มีอินเทอร์เน็ต

## ใครใช้บทนี้

นักเรียนและบุคลากรทุกคนที่ได้รับบัญชีจากโรงเรียน

## ก่อนเริ่ม

- รู้ **รหัสนักเรียน** หรือชื่อผู้ใช้ที่ผู้ดูแลออกให้
- รหัสผ่านเริ่มต้นคือรหัสนักเรียนของตนเอง เช่น `47001`
- เปิดผ่าน `https://` เท่านั้น หากเปิดผ่าน HTTP เบราว์เซอร์จะไม่ให้ติดตั้งแอปและไม่ให้ใช้กล้องสแกน

## ถ้าต้องการเข้าสู่ระบบครั้งแรก

1. เปิดเว็บไซต์ PIRIvoice
2. กด **เข้าสู่ระบบ**
3. กรอก **รหัสนักเรียน** เช่น `41001`
4. กรอก **รหัสผ่าน** เป็นรหัสนักเรียนเช่นเดียวกัน
5. กด **เข้าสู่ระบบเลย**
6. หากระบบพาไปหน้า **เปลี่ยนรหัสผ่าน** แสดงว่าบัญชีนี้ถูกบังคับให้ตั้งรหัสใหม่
7. กรอกรหัสเดิม รหัสใหม่ และยืนยันรหัสใหม่ แล้วกด **เปลี่ยนรหัสผ่าน**
8. หลังเปลี่ยนสำเร็จ ระบบจะพากลับไปยังหน้าที่ตั้งใจจะเปิดก่อนหน้า

![ภาพที่ 2 — หน้าเข้าสู่ระบบ](../assets/screenshots/public/02-login.webp)

## ถ้าต้องการเปลี่ยนรหัสผ่านภายหลัง

1. เปิด **เพิ่มเติม** ที่แถบล่าง
2. เลือก **ตั้งค่า**
3. ในหัวข้อ **บัญชี** กด **เปลี่ยนรหัสผ่าน**
4. กรอก **รหัสผ่านเดิม** **รหัสผ่านใหม่** และ **ยืนยันรหัสผ่านใหม่**
5. รหัสใหม่ต้องยาวอย่างน้อย 4 ตัว และต้องไม่ซ้ำรหัสเดิม
6. กด **เปลี่ยนรหัสผ่าน**

หากจำรหัสเดิมไม่ได้ ระบบไม่มีปุ่มลืมรหัสผ่าน ให้ติดต่อผู้ดูแลระบบเพื่อตั้งรหัสใหม่

## ถ้าต้องการติดตั้งบน Android

1. เปิดเว็บด้วย Chrome
2. รอให้มีแบนเนอร์ **ติดตั้งแอป** หรือเปิดเมนู `⋮` แล้วเลือก **ติดตั้งแอป**
3. กด **ติดตั้งเลย**
4. ไอคอน PIRIvoice จะปรากฏบนหน้าจอหลัก เปิดได้เหมือนแอปทั่วไป

หากไม่เห็นแบนเนอร์ ให้เปิด **ตั้งค่า** แล้วดูหัวข้อ **ติดตั้งแอป** ระบบจะบอกว่าเครื่องนี้พร้อมติดตั้งหรือไม่

## ถ้าต้องการติดตั้งบน iPhone หรือ iPad

1. เปิดเว็บด้วย Safari
2. กดปุ่ม **แชร์** ที่แถบล่างของจอ
3. เลือก **เพิ่มไปที่หน้าจอ**
4. กด **เพิ่ม**

iOS ไม่มีปุ่มติดตั้งอัตโนมัติจากเว็บ ต้องทำผ่านเมนูแชร์เท่านั้น

![ภาพที่ 3 — คำแนะนำการติดตั้งบน iPhone](../assets/screenshots/user/03-ios-install.webp)

## ถ้าต้องการใช้งานเมื่อไม่มีอินเทอร์เน็ต

แอปที่ติดตั้งไว้จะเปิดหน้าจอหลักได้จากแคช แต่ **ไม่สามารถดูข้อมูลใหม่ได้**

- เปิดแอปได้ แต่รายการเรื่อง บอร์ด กิจกรรม และประกาศจะโหลดไม่ได้
- ระบบไม่แคชข้อมูลจาก `/api/*` เพื่อป้องกันข้อมูลเก่าหรือข้อมูลส่วนบุคคลค้างในเครื่อง
- เมื่ออินเทอร์เน็ตกลับมา ให้กดรีเฟรช ข้อมูลจะโหลดใหม่

## ถ้าต้องการอัปเดตแอปเป็นเวอร์ชันใหม่

1. เปิดแอปขณะมีอินเทอร์เน็ต
2. หากมีเวอร์ชันใหม่ ระบบจะแสดงแบนเนอร์ให้อัปเดต
3. กดอัปเดตแล้วรอให้โหลดเสร็จ
4. หากไม่เห็นแบนเนอร์ ให้ปิดแอปแล้วเปิดใหม่

## ถ้าต้องการออกจากระบบ

1. เปิด **เพิ่มเติม**
2. เลื่อนลงไปที่ส่วนบัญชี
3. กด **ออกจากระบบ**
4. ยืนยัน **ออกจากระบบ**

หากใช้เครื่องร่วมกับผู้อื่น ต้องออกจากระบบทุกครั้งหลังใช้งาน

## ระบบทำอะไรเบื้องหลัง

- เก็บ token ไว้ใน `localStorage` ภายใต้ชื่อ `access_token` และ `user_id_str`
- token มีอายุ 30 วัน นับจากวันที่ออก
- เมื่อ API ตอบ 401 ระบบจะล้าง token และพากลับหน้าเข้าสู่ระบบ พร้อมจำหน้าที่ตั้งใจจะไป
- บัญชีที่ถูกตั้ง `must_change_password` จะถูกบังคับให้เปลี่ยนรหัสก่อนใช้ฟีเจอร์อื่น
- service worker แคชเฉพาะโครงแอป ไม่แตะข้อมูล API

## ข้อจำกัดและข้อควรระวัง

- ไม่มีปุ่มลืมรหัสผ่าน ไม่มี OTP และไม่มีรีเซ็ตทางอีเมล
- ไม่มีสมัครสมาชิกเอง
- รหัสผ่านเริ่มต้นเดาได้ง่าย ต้องเปลี่ยนทันทีเมื่อระบบขอ
- อย่าติดตั้งแอปบนเครื่องสาธารณะที่คนอื่นใช้ร่วมกัน
- การติดตั้งบน iOS ต้องใช้ Safari เท่านั้น

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: ล็อกอินแล้วขึ้น "รหัสนักเรียนหรือรหัสผ่านไม่ถูกต้อง"**
ตอบ: ตรวจว่ารหัสผ่านเป็นรหัสนักเรียน ไม่ใช่รหัสที่เคยเปลี่ยนไว้หรือรหัสจากระบบอื่น
หากเพิ่งเปลี่ยนรหัส ให้ใช้รหัสใหม่ หากยังไม่ได้ ให้ติดต่อผู้ดูแลระบบ

**ถาม: ระบบพาไปหน้าเปลี่ยนรหัสผ่านทุกครั้ง**
ตอบ: บัญชีนี้ยังมีสถานะต้องเปลี่ยนรหัส ให้ตั้งรหัสใหม่ให้สำเร็จก่อน
หลังเปลี่ยนแล้วระบบจะไม่บังคับอีก

**ถาม: ติดตั้งบน Android ไม่ได้**
ตอบ: ต้องเปิดด้วย Chrome ผ่าน `https://` และเครื่องต้องไม่เคยเลือก "ไม่ติดตั้ง" มาก่อน
ให้เปิด **ตั้งค่า** แล้วดูหัวข้อ **ติดตั้งแอป** เพื่อตรวจสถานะ

**ถาม: เปิดแอปแล้วขึ้นหน้า "ลองใหม่" อย่างเดียว**
ตอบ: แอปโหลดโครงได้แต่เชื่อมต่อ API ไม่ได้ ตรวจอินเทอร์เน็ตแล้วกดลองใหม่
หากยังไม่ได้ ให้ปิดแอปแล้วเปิดใหม่

**ถาม: เปลี่ยนรหัสแล้วเข้าด้วยรหัสเก่าไม่ได้**
ตอบ: ถูกต้อง ระบบใช้รหัสใหม่ทันที ให้ใช้รหัสใหม่ในการเข้าครั้งถัดไป

**ถาม: ใช้เครื่องของเพื่อนแล้วลืมออกจากระบบ**
ตอบ: ให้กลับไปที่ **เพิ่มเติม** แล้วกด **ออกจากระบบ** ทันที
หากเข้าเครื่องไม่ได้ ให้แจ้งผู้ดูแลระบบเพื่อเพิกถอน token
