# การเข้าสู่ระบบและติดตั้งแอปลงมือถือ

ครั้งแรกอาจดูยุ่งนิดนึง แต่ทำตามนี้จบในสิบห้านาที:

- เข้าสู่ระบบด้วย **รหัสนักเรียน**
- ตั้งรหัสผ่านใหม่ของตัวเองก่อนใช้งาน
- ติดตั้งไอคอน PIRIvoice ไว้บนหน้าจอโฮม

## สิ่งที่ต้องเตรียม

- **รหัสนักเรียน** ของตัวเอง เช่น `47001`
- รหัสผ่านครั้งแรกก็คือรหัสนักเรียนเหมือนกัน
- มือถือที่ใช้ Chrome (Android) หรือ Safari (iPhone/iPad)

::: warning ตั้งรหัสใหม่ก่อนเลยนะ
รหัสเริ่มต้นคือรหัสนักเรียน เพื่อนที่รู้รหัสเราก็เดาได้
ระบบจึงบังคับให้ตั้งรหัสใหม่ก่อนใช้งานอย่างอื่น
:::

## เข้าสู่ระบบครั้งแรก

**ทางเข้า:** เปิดเว็บ PIRIvoice ของโรงเรียน ➔ กด **เข้าสู่ระบบ**

1. **ใส่รหัสนักเรียน** ลงในช่องแรก
2. **ใส่รหัสผ่าน** เป็นรหัสนักเรียนเช่นกัน แล้วกด **เข้าสู่ระบบเลย**
3. **ตั้งรหัสใหม่ถ้าระบบพามา** — ถ้าเจอหน้า **เปลี่ยนรหัสผ่าน** แปลว่าบัญชีนี้ต้องตั้งรหัสก่อน
   ให้กรอก **รหัสผ่านเดิม** **รหัสผ่านใหม่** และ **ยืนยันรหัสผ่านใหม่**
4. **กดยืนยัน** แล้วระบบจะพาเข้าหน้าแรกให้เอง

![ภาพที่ 1 — หน้าเข้าสู่ระบบ](../assets/screenshots/public/login.webp)
*หมายเลขในภาพ: 1 ช่องรหัสนักเรียน · 2 ช่องรหัสผ่าน · 3 ปุ่มเข้าสู่ระบบ · 4 ข้อความเตือนเรื่องรหัสผ่านเริ่มต้น*

::: tip ตั้งรหัสแบบไหนดี
ยาวสัก 4 ตัวขึ้นไป และต้องไม่ซ้ำของเดิม
อย่าใช้ `1234` หรือวันเกิด เพราะเพื่อนเดาออกในสามวิ
:::

## ติดตั้งบน Android

ติดตั้งแล้วเปิดจากหน้าจอโฮมได้เหมือนแอปทั่วไป และรับแจ้งเตือนได้ด้วย

**วิธีติดตั้ง:** เปิดเว็บด้วย **Chrome** ➔ รอแถบ **ติดตั้ง PIRIvoice** ขึ้นใต้หัวจอ ➔ กด **ติดตั้ง**

![ภาพที่ 2 — แถบติดตั้งที่ขึ้นในแอป](../assets/screenshots/user/install-android.webp)
*ถ้าแถบนี้ไม่ขึ้น ให้กด `⋮` มุมขวาบนแล้วเลือก **ติดตั้งแอป** แทน*

ถ้ายังไม่เห็นตัวเลือกติดตั้ง ให้เข้า **เพิ่มเติม** ➔ **ตั้งค่า** แล้วดูการ์ด **ติดตั้งแอป**
การ์ดนี้จะบอกว่าเครื่องนี้พร้อมติดตั้งหรือไม่ และแนะนำวิธีสำหรับเครื่องนั้นโดยตรง

## ติดตั้งบน iPhone หรือ iPad

iPhone ไม่มีปุ่มติดตั้งอัตโนมัติ ต้องเพิ่มผ่านเมนูแชร์ของ Safari

**วิธีติดตั้ง:** เปิดเว็บด้วย **Safari** เท่านั้น ➔ ปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น) ➔ **เพิ่มไปที่หน้าจอโฮม** ➔ **เพิ่ม**

![ภาพที่ 3 — ขั้นตอนติดตั้งบน iPhone ในหน้าตั้งค่า](../assets/screenshots/user/ios-install.webp)
*จำขั้นตอนไม่ได้ไม่เป็นไร การ์ดนี้อยู่ในหน้าตั้งค่าของแอป เปิดดูซ้ำได้ตลอด*

บน iPhone ต้องเพิ่มลงหน้าจอโฮมก่อน ถึงจะรับเสียงเตือนนอกแอปได้
ถ้ายังไม่ติดตั้ง จะได้แค่แจ้งเตือนในแอป

## เปลี่ยนรหัสผ่านทีหลัง

**ทางเข้า:** แท็บ **เพิ่มเติม** ➔ **ตั้งค่า** ➔ หมวด **บัญชี** ➔ **เปลี่ยนรหัสผ่าน**

กรอกรหัสเดิม รหัสใหม่ และยืนยันอีกรอบ แล้วกดยืนยัน

![ภาพที่ 4 — หน้าเปลี่ยนรหัสผ่าน](../assets/screenshots/user/change-password.webp)
*ถ้าจำรหัสเดิมไม่ได้ ไม่มีปุ่มลืมรหัสผ่าน ต้องบอกครูหรือผู้ดูแลระบบให้ตั้งใหม่ให้*

## ออกจากระบบ

**ทางเข้า:** แท็บ **เพิ่มเติม** ➔ เลื่อนลงไปจนสุด ➔ **ออกจากระบบ** ➔ ยืนยันอีกครั้ง

ถ้าใช้เครื่องของโรงเรียนหรือเครื่องที่คนอื่นใช้ร่วมกัน อย่าลืมออกทุกครั้ง
ถ้าลืมแล้วไม่ได้เครื่องคืน ให้บอกครูหรือผู้ดูแลระบบทันที เพื่อให้ระบบออกจากทุกเครื่องที่ค้างอยู่

## ถ้าอินเทอร์เน็ตหลุด

แอปที่ติดตั้งไว้ยังเปิดได้ แต่จะเห็นแค่โครงหน้า
ข้อมูลอย่างเรื่อง บอร์ด กิจกรรม และประกาศจะโหลดไม่ขึ้น

ระบบตั้งใจไม่เก็บข้อมูลไว้ในเครื่อง เพื่อไม่ให้ข้อมูลส่วนตัวค้างอยู่ในมือถือที่อาจใช้ร่วมกัน
พอเน็ตกลับมา ให้กดรีเฟรชหรือปิดแอปแล้วเปิดใหม่ ข้อมูลจะกลับมาเอง

## ข้อจำกัดและข้อควรระวัง

- ไม่มีปุ่มลืมรหัสผ่าน ไม่มี OTP และไม่มีรีเซ็ตทางอีเมล
- สมัครสมาชิกเองไม่ได้ โรงเรียนเป็นคนสร้างบัญชีให้
- อย่าติดตั้งแอปบนเครื่องสาธารณะที่หลายคนใช้
- iPhone ต้องใช้ Safari และต้องเพิ่มลงหน้าจอโฮมก่อน ถึงจะรับแจ้งเตือนได้
- ถ้าเคยเลือก "ไม่ติดตั้ง" ไว้ แถบติดตั้งอาจไม่ขึ้นอีก ให้ใช้วิธีในหน้าตั้งค่าแทน
- ระบบจำการเข้าสู่ระบบไว้ราวหนึ่งเดือน ถ้าเปลี่ยนรหัสจากเครื่องอื่น แอปจะพากลับไปหน้าเข้าสู่ระบบเอง

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: กดเข้าสู่ระบบแล้วขึ้นว่ารหัสนักเรียนหรือรหัสผ่านไม่ถูกต้อง?**

👉 **วิธีแก้:** เช็กก่อนว่าใช้ **รหัสนักเรียน** ไม่ใช่เลขบัตรประชาชนหรือรหัสของระบบอื่น
ถ้าเพิ่งเปลี่ยนรหัส ให้ใช้รหัสใหม่ ถ้ายังไม่ได้ให้บอกครูหรือผู้ดูแลระบบ

**Q: ลืมรหัสผ่าน ทำยังไงดี?**

👉 **วิธีแก้:** ระบบยังไม่มีปุ่มลืมรหัสผ่าน ให้ติดต่อครูหรือผู้ดูแลระบบเพื่อตั้งรหัสใหม่
แล้วเข้าด้วยรหัสใหม่ตามปกติ

**Q: ทุกครั้งที่เข้าจะโดนบังคับเปลี่ยนรหัสไหม?**

👉 **วิธีแก้:** ไม่ครับ ถ้าตั้งรหัสใหม่สำเร็จแล้ว ครั้งต่อไปเข้าหน้าแรกได้เลย

**Q: ติดตั้งบน Android แล้วไม่มีแถบติดตั้งขึ้นมา?**

👉 **วิธีแก้:** ต้องเปิดด้วย Chrome และเปิดผ่านที่อยู่ที่ขึ้นต้นด้วย `https://` เท่านั้น
ถ้ายังไม่ขึ้น ให้เข้า **เพิ่มเติม** ➔ **ตั้งค่า** ➔ การ์ด **ติดตั้งแอป** เพื่อดูสถานะของเครื่อง

**Q: ไม่มีอินเทอร์เน็ตแล้วเปิดแอปได้ไหม?**

👉 **วิธีแก้:** เปิดได้ แต่เห็นแค่หน้าโครง ข้อมูลจะขึ้นเมื่อต่อเน็ตได้
ถ้าต้องใช้ตอนเน็ตไม่ดี ให้จดสิ่งที่ต้องการไว้แล้วค่อยเข้ามาใหม่

**Q: ใช้เครื่องเพื่อนแล้วลืมออกจากระบบ?**

👉 **วิธีแก้:** กลับไปที่ **เพิ่มเติม** ➔ **ออกจากระบบ** ทันที
ถ้าเอาเครื่องคืนไม่ได้ ให้แจ้งผู้ดูแลระบบให้ออกจากระบบให้ทุกเครื่อง
