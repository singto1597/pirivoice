# การเข้าสู่ระบบและติดตั้งแอปลงมือถือ

บทนี้พาไปตั้งแต่เปิดแอปครั้งแรก ตั้งรหัสผ่านของตัวเอง ไปจนถึงมีไอคอน PIRIvoice
อยู่บนหน้าจอมือถือ ใช้เวลารวมไม่ถึงสิบนาที

## สิ่งที่ต้องเตรียม

- **รหัสนักเรียน** ของตัวเอง เช่น `47001`
- รหัสผ่านครั้งแรกคือ **รหัสนักเรียน** เหมือนกัน
- มือถือที่ใช้ Chrome (Android) หรือ Safari (iPhone/iPad)

::: warning เปลี่ยนรหัสผ่านทันทีเมื่อเข้าครั้งแรก
รหัสผ่านเริ่มต้นคือรหัสนักเรียน ซึ่งเพื่อนที่รู้รหัสเราก็เดาได้
ระบบจึงบังคับให้ตั้งรหัสใหม่ก่อนใช้งานอย่างอื่น
:::

## เข้าสู่ระบบครั้งแรก

1. เปิดเว็บไซต์ PIRIvoice ของโรงเรียน
2. กด **เข้าสู่ระบบ**
3. กรอก **รหัสนักเรียน** ลงในช่องแรก
4. กรอก **รหัสผ่าน** เป็นรหัสนักเรียนเช่นกัน
5. กด **เข้าสู่ระบบเลย**
6. ถ้าระบบพาไปหน้า **เปลี่ยนรหัสผ่าน** แปลว่าบัญชีนี้ต้องตั้งรหัสใหม่ก่อน
7. กรอก **รหัสผ่านเดิม** **รหัสผ่านใหม่** และ **ยืนยันรหัสผ่านใหม่**
8. กดยืนยัน ระบบจะพาเข้าสู่หน้าแรกให้เอง

![ภาพที่ 1 — หน้าเข้าสู่ระบบ](../assets/screenshots/public/login.webp)

หมายเลขในภาพคือ 1 ช่องรหัสนักเรียน 2 ช่องรหัสผ่าน 3 ปุ่มเข้าสู่ระบบ
และ 4 ข้อความเตือนเรื่องรหัสผ่านเริ่มต้น

::: tip รหัสผ่านใหม่ต้องเป็นอย่างไร
- ยาวอย่างน้อย 4 ตัวอักษร
- ต้องไม่ซ้ำกับรหัสเดิม
- จำง่ายแต่คนอื่นเดาไม่ได้ อย่าใช้ `1234` หรือวันเกิด
:::

## ติดตั้งบน Android

ติดตั้งแล้วจะเปิดแอปได้จากหน้าจอโฮมเหมือนแอปทั่วไป และรับแจ้งเตือนได้ด้วย

1. เปิดเว็บด้วย **Chrome**
2. รอสักครู่ จะมีแถบ **ติดตั้ง PIRIvoice** ขึ้นมาใต้หัวจอ
3. กด **ติดตั้ง** ในแถบนั้น
4. ถ้าไม่มีแถบขึ้น ให้กดเมนู `⋮` ที่มุมขวาบน แล้วเลือก **ติดตั้งแอป**

![ภาพที่ 2 — แถบติดตั้งที่ขึ้นในแอป](../assets/screenshots/user/install-android.webp)

ถ้ายังไม่เห็นตัวเลือกติดตั้ง ให้เปิด **เพิ่มเติม** → **ตั้งค่า** แล้วดูการ์ด **ติดตั้งแอป**
ระบบจะบอกว่าเครื่องนี้พร้อมติดตั้งหรือไม่ และบอกวิธีสำหรับเครื่องนั้นโดยตรง

## ติดตั้งบน iPhone หรือ iPad

iPhone ไม่มีปุ่มติดตั้งอัตโนมัติ ต้องเพิ่มผ่านเมนูแชร์ของ Safari

1. เปิดเว็บด้วย **Safari** เท่านั้น เบราว์เซอร์อื่นทำไม่ได้
2. กดปุ่ม **แชร์** ที่แถบล่างของจอ (รูปสี่เหลี่ยมมีลูกศรชี้ขึ้น)
3. เลือก **เพิ่มไปที่หน้าจอโฮม**
4. กด **เพิ่ม** ที่มุมขวาบน

![ภาพที่ 3 — ขั้นตอนติดตั้งบน iPhone ในหน้าตั้งค่า](../assets/screenshots/user/ios-install.webp)

ในหน้า **ตั้งค่า** ของแอปมีการ์ด **ติดตั้งแอป** ที่สรุปขั้นตอนไว้ให้ดูซ้ำได้ตลอด
ถ้าจำขั้นตอนไม่ได้ให้กลับมาดูการ์ดนี้

::: info ทำไม iPhone ต้องติดตั้งก่อนถึงจะรับแจ้งเตือนได้
Safari บน iPhone จะส่งการแจ้งเตือนให้เฉพาะเว็บที่ถูกเพิ่มลงหน้าจอโฮมแล้วเท่านั้น
ถ้ายังไม่ติดตั้ง จะได้แจ้งเตือนในแอปแต่ไม่มีเสียงเตือนนอกแอป
:::

## เปลี่ยนรหัสผ่านภายหลัง

1. เปิด **เพิ่มเติม** ที่แถบล่าง
2. เลือก **ตั้งค่า**
3. ในหัวข้อ **บัญชี** กด **เปลี่ยนรหัสผ่าน**
4. กรอก **รหัสผ่านเดิม** **รหัสผ่านใหม่** และ **ยืนยันรหัสผ่านใหม่**
5. กดปุ่มยืนยัน

![ภาพที่ 4 — หน้าเปลี่ยนรหัสผ่าน](../assets/screenshots/user/change-password.webp)

ถ้าจำรหัสเดิมไม่ได้ ระบบไม่มีปุ่มลืมรหัสผ่าน ให้บอกครูหรือผู้ดูแลระบบ
เพื่อให้ตั้งรหัสใหม่ให้

## ออกจากระบบ

ถ้าใช้เครื่องของโรงเรียนหรือเครื่องที่คนอื่นใช้ร่วมกัน ต้องออกจากระบบทุกครั้ง

1. เปิด **เพิ่มเติม**
2. เลื่อนลงไปจนสุด
3. กด **ออกจากระบบ**
4. ยืนยันอีกครั้ง

::: warning ถ้าใช้เครื่องร่วมกับคนอื่น
ถ้าลืมออกจากระบบแล้วไม่ได้เครื่องคืน ให้บอกครูหรือผู้ดูแลระบบทันที
เพื่อให้ระบบออกจากทุกเครื่องที่ค้างอยู่ อย่าปล่อยไว้ข้ามวัน
:::

## ถ้าอินเทอร์เน็ตหลุด

แอปที่ติดตั้งไว้ยังเปิดได้ แต่จะเห็นแค่โครงหน้า ข้อมูลอย่างรายการเรื่อง บอร์ด
กิจกรรม และประกาศจะโหลดไม่ขึ้น เพราะระบบตั้งใจไม่เก็บข้อมูลไว้ในเครื่อง
เพื่อไม่ให้ข้อมูลส่วนตัวค้างอยู่ในมือถือที่อาจถูกใช้ร่วมกัน

พออินเทอร์เน็ตกลับมา ให้กดรีเฟรชหรือปิดแอปแล้วเปิดใหม่ ข้อมูลจะกลับมาเอง

## ระบบทำอะไรเบื้องหลัง

ระบบจำการเข้าสู่ระบบไว้ให้ราวหนึ่งเดือน ไม่ต้องกรอกรหัสทุกครั้งที่เปิด
ถ้ามีอะไรทำให้การเข้าสู่ระบบใช้ไม่ได้ เช่น เปลี่ยนรหัสจากเครื่องอื่น
แอปจะพากลับไปหน้าเข้าสู่ระบบเอง และจะพากลับมาหน้าเดิมที่ตั้งใจเปิด
หลังเข้าสำเร็จ

การติดตั้งแอปไม่ได้ทำให้ข้อมูลถูกเก็บถาวรในเครื่อง ข้อมูลทุกอย่างยังโหลดสดจากโรงเรียน

## ข้อจำกัดและข้อควรระวัง

- ไม่มีปุ่มลืมรหัสผ่าน ไม่มี OTP และไม่มีรีเซ็ตทางอีเมล
- สมัครสมาชิกเองไม่ได้
- อย่าติดตั้งแอปบนเครื่องสาธารณะที่หลายคนใช้
- iPhone ต้องใช้ Safari และต้องเพิ่มลงหน้าจอโฮมก่อนจึงจะรับแจ้งเตือนได้
- ถ้าเครื่องเคยเลือก "ไม่ติดตั้ง" ไว้ แถบติดตั้งอาจไม่ขึ้นอีก ให้ใช้วิธีในหน้าตั้งค่าแทน

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: กดเข้าสู่ระบบแล้วขึ้นว่ารหัสนักเรียนหรือรหัสผ่านไม่ถูกต้อง**
ตอบ: เช็กก่อนว่าใช้ **รหัสนักเรียน** ไม่ใช่เลขบัตรประชาชนหรือรหัสของระบบอื่น
ถ้าเพิ่งเปลี่ยนรหัส ให้ใช้รหัสใหม่ ถ้ายังไม่ได้ให้บอกครูหรือผู้ดูแลระบบ

**ถาม: ลืมรหัสผ่าน ทำอย่างไร**
ตอบ: ระบบยังไม่มีปุ่มลืมรหัสผ่าน ให้ติดต่อครูหรือผู้ดูแลระบบเพื่อตั้งรหัสใหม่
จากนั้นเข้าด้วยรหัสใหม่ตามปกติ

**ถาม: ทุกครั้งที่เข้าจะโดนบังคับเปลี่ยนรหัสไหม**
ตอบ: ไม่ ถ้าตั้งรหัสใหม่สำเร็จแล้ว ครั้งต่อไปจะเข้าหน้าแรกได้เลย

**ถาม: ติดตั้งบน Android ไม่ขึ้นแถบติดตั้ง**
ตอบ: ต้องเปิดด้วย Chrome และเปิดผ่านที่อยู่ที่ขึ้นต้นด้วย `https://` เท่านั้น
ถ้ายังไม่ขึ้น ให้เข้า **เพิ่มเติม** → **ตั้งค่า** → การ์ด **ติดตั้งแอป** เพื่อดูสถานะของเครื่อง

**ถาม: ไม่มีอินเทอร์เน็ตแล้วเปิดแอปได้ไหม**
ตอบ: เปิดได้ แต่เห็นเพียงหน้าโครง ข้อมูลจะขึ้นเมื่อต่อเน็ตได้
ถ้าต้องใช้ตอนเน็ตไม่ดี ให้จดสิ่งที่ต้องการไว้แล้วค่อยเข้ามาใหม่

**ถาม: ใช้เครื่องเพื่อนแล้วลืมออกจากระบบ**
ตอบ: กลับไปที่ **เพิ่มเติม** แล้วกด **ออกจากระบบ** ทันที
ถ้าเอาเครื่องคืนไม่ได้ ให้แจ้งผู้ดูแลระบบให้ออกจากระบบให้ทุกเครื่อง
