# หน้าเว็บสาธารณะก่อนเข้าสู่ระบบ

หน้าแรกของเว็บโรงเรียนเปิดให้ทุกคนดูได้ ไม่ต้องมีบัญชีก็เข้าได้
หน้านี้ตอบคำถามง่าย ๆ สองข้อ คือโรงเรียนกำลังเจอเรื่องอะไรบ้าง
และเรื่องที่แจ้งไปแล้วได้รับการแก้จริงหรือเปล่า

ถ้าเป็นผู้ปกครองที่อยากรู้ว่าโรงเรียนดูแลนักเรียนอย่างไร หรือเป็นนักเรียนที่ยังไม่ได้
ล็อกอิน ลองเปิดหน้านี้ดูก่อนได้เลย

![ภาพที่ 1 — หน้าแรกของเว็บโรงเรียน](../assets/screenshots/public/landing-hero.webp)

ในภาพมีสี่จุดที่ใช้บ่อย

1. **เข้าสู่ระบบ** ที่มุมขวาบน ใช้เมื่อพร้อมจะเข้าไปใช้งานเต็มรูปแบบ
2. **ประกาศ:** แถบข่าวสั้นจากสภานักเรียน
3. **แจ้งเรื่องเลย** ทางลัดไปยังหน้าเข้าสู่ระบบสำหรับคนที่ตั้งใจมาแจ้งเรื่อง
4. **ดูรายงานสถิติ** เลื่อนลงไปดูตัวเลขภาพรวมของโรงเรียน

## ดูภาพรวมว่าโรงเรียนกำลังทำอะไรอยู่

เลื่อนลงมาที่หัวข้อ **รายงานสถิติสถานะปัจจุบัน** จะเห็นตัวเลขห้าช่อง

![ภาพที่ 2 — รายงานสถิติสถานะปัจจุบัน](../assets/screenshots/public/landing-stats.webp)

| ตัวเลข | หมายถึง |
|---|---|
| **เรื่องส่งเข้ามาทั้งหมด** | จำนวนเรื่องที่นักเรียนแจ้งเข้ามาทั้งหมด |
| **อยู่ระหว่างดำเนินการ** | เรื่องที่ยังไม่ปิด |
| **ดำเนินการเสร็จสิ้น** | เรื่องที่ปิดเรียบร้อยแล้ว |
| **อัตราการปิดเรื่อง** | สัดส่วนเรื่องที่ปิดแล้วต่อเรื่องทั้งหมด เป็นเปอร์เซ็นต์ |
| **เวลาเฉลี่ยต่อเคส** | เฉลี่ยว่าแต่ละเรื่องใช้เวลากี่ชั่วโมงกว่าจะจบ |

ถ้าตัวเลขยังน้อยหรือเป็นศูนย์ แปลว่าโรงเรียนเพิ่งเริ่มใช้ระบบ ยังไม่มีเรื่องสะสมมากนัก

ใต้ตัวเลขมีกราฟ **ปริมาณการแจ้งเรื่องที่เข้าสู่ระบบ** แสดงย้อนหลัง 14 วัน
ใช้ดูว่าช่วงไหนมีคนแจ้งเรื่องมากเป็นพิเศษ เช่น หลังสอบกลางภาคหรือช่วงเปิดเทอม

## อ่านประกาศล่าสุด

ประกาศจากสภานักเรียนแสดงอยู่บนหน้าแรกเลย ประกาศที่สำคัญมากจะอยู่บนสุดและใช้สีเด่น
กดที่ประกาศเพื่ออ่านข้อความเต็มหรือเปิดลิงก์ที่แนบมา

ถ้ายังไม่มีประกาศ จะเห็นข้อความว่า **ยังไม่มีประกาศในขณะนี้** ซึ่งเป็นเรื่องปกติ

## ดูเรื่องที่แก้เสร็จแล้ว

เลื่อนลงมาที่หัวข้อ **ผลลัพธ์ที่เกิดขึ้นจริง** ส่วนนี้ตั้งใจให้เห็นว่าเรื่องที่แจ้งไป
ไม่ได้หายเข้าระบบ แต่มีคนลงมือทำจริง

แต่ละเรื่องจะบอก **ประเด็นที่รับแจ้ง** **ผลการดำเนินการ** **หน่วยงานที่รับผิดชอบ**
และ **ระยะเวลาดำเนินการ** เช่น แจ้งว่าห้องน้ำอาคาร 3 น้ำไม่ไหล ใช้เวลาสองวันซ่อมเสร็จ

![ภาพที่ 3 — ตัวอย่างเรื่องที่ดำเนินการเสร็จแล้ว](../assets/screenshots/public/landing-resolved.webp)

ชื่อคนแจ้งจะถูกปิดไว้เสมอ ในภาพจะเห็นว่าแสดงเป็น **แจ้งโดย** ตามด้วยข้อความกลาง ๆ
เช่น **นักเรียน (ไม่ประสงค์ออกนาม)** หรือ **นักเรียน ม.4/1** ตามที่ระบบกำหนด
ไม่มีการเปิดเผยชื่อจริงบนหน้าสาธารณะ

## รู้จัก PIRI Talk และ PIRI Vote

ส่วน **ระบบนิเวศน์ PIRIvoice** แนะนำสองบริการที่ทำงานคู่กับระบบแจ้งเรื่อง

- **PIRI Talk** บอร์ดสนทนาสำหรับแลกเปลี่ยนความคิดเห็น โดยมีสภานักเรียนช่วยดูแล
- **PIRI Vote** บอร์ดโหวตสำหรับหาข้อสรุปร่วมกัน หนึ่งคนหนึ่งเสียง

::: warning บอร์ดต้องเข้าสู่ระบบก่อน
ผู้เยี่ยมชมยังอ่านบอร์ดไม่ได้ เพราะในบอร์ดมีคอมเมนต์ของนักเรียนที่ต้องดูแลเรื่อง
ความเป็นส่วนตัวและความเหมาะสม
:::

## ข้อจำกัดและข้อควรระวัง

- ตัวเลขบนหน้านี้เป็นข้อมูลจริงของโรงเรียน แต่เป็นภาพรวม เจาะดูรายเรื่องไม่ได้
  พอมีคนปิดเรื่องเสร็จ ตัวเลขจะขยับตามเมื่อเปิดหน้าใหม่
- หน้าเว็บสาธารณะไม่มีช่องค้นหาเรื่อง และไม่มีรายชื่อนักเรียน
- ประกาศที่ถูกปลดออกหรือลบไปแล้วจะไม่แสดง และเรื่องที่ยังเปิดอยู่จะไม่ปรากฏ
  ในส่วน **ผลลัพธ์ที่เกิดขึ้นจริง**
- ถ้าเปิดแล้วข้อมูลไม่ขึ้น ให้กด **ดึงข้อมูลอีกครั้ง** มักเกิดจากสัญญาณอินเทอร์เน็ต

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: ตัวเลขไม่ตรงกับที่ครูบอกในห้อง**
ตอบ: หน้านี้ดึงข้อมูลสด ณ ตอนที่เปิด ถ้าเพิ่งมีการปิดเรื่อง ให้กดรีเฟรชอีกครั้ง
ตัวเลขอาจต่างจากรายงานที่พิมพ์ไว้ก่อนหน้าอยู่บ้าง

**ถาม: ขึ้นว่า "ไม่สามารถดึงข้อมูลสถิติได้ในขณะนี้" ต้องทำอย่างไร**
ตอบ: กด **ดึงข้อมูลอีกครั้ง** ถ้ายังไม่หายให้รอสักครู่แล้วลองใหม่
ข้อความนี้หมายถึงโหลดข้อมูลไม่สำเร็จ ไม่ได้หมายความว่าข้อมูลหายไป

**ถาม: ทำไมไม่เห็นชื่อคนแจ้ง**
ตอบ: ระบบปิดชื่อผู้แจ้งบนทุกหน้าที่ไม่ต้องล็อกอิน เพื่อปกป้องข้อมูลส่วนบุคคลของนักเรียน

**ถาม: เปิดบอร์ดจากหน้านี้ได้ไหม**
ตอบ: ไม่ได้ ต้องเข้าสู่ระบบก่อน เพราะบอร์ดมีคอมเมนต์ที่ต้องดูแล

**ถาม: ตัวเลขที่เห็นเป็นของทั้งโรงเรียนหรือของระดับไหน**
ตอบ: เป็นภาพรวมของทั้งโรงเรียน ข้อมูลแยกรายระดับชั้นจะเห็นได้หลังเข้าสู่ระบบ
และเฉพาะผู้ที่มีสิทธิ์เท่านั้น

**ถาม: เปิดเว็บแล้วค้างอยู่ที่หน้าโลโก้**
ตอบ: ตรวจอินเทอร์เน็ตก่อน แล้วเปิดใหม่ ถ้ายังค้างให้บอกผู้ดูแลระบบพร้อมเวลาที่เจอปัญหา

## พร้อมแล้วก็เข้ามาใช้เลย

ถ้าดูแล้วอยากลองใช้เอง กด **เข้าสู่ระบบ** ที่มุมขวาบน แล้วกรอกรหัสนักเรียน
กับรหัสผ่านครั้งแรก (รหัสผ่านเริ่มต้นคือรหัสนักเรียน) ระบบจะพาไปหน้าแรกให้เอง

เข้าไปแล้วลองสองอย่างนี้ก่อน

1. เปิด [บอร์ดพูดคุย การโหวต และการเสนอไอเดีย](boards-and-voting.md) แล้วดูว่าตอนนี้เพื่อน ๆ กำลังคุยเรื่องอะไร
2. อ่าน [การแจ้งเรื่องและติดตามสถานะ](issue-reporting-tracking.md) แล้วลองส่งเรื่องแรกของคุณดู

ไม่ต้องรอให้มีเรื่องใหญ่ เรื่องเล็กที่เจอในชีวิตประจำวันก็มีประโยชน์ทั้งนั้น
