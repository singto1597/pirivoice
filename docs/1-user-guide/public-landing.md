# หน้าเว็บสาธารณะก่อนเข้าสู่ระบบ

หน้าแรกของเว็บโรงเรียนเปิดให้ทุกคนดู ไม่ต้องมีบัญชีก็เข้าได้
อยากรู้ว่าโรงเรียนกำลังเจอเรื่องอะไร และเรื่องที่แจ้งไปแล้วได้แก้จริงหรือเปล่า ดูจบในหน้านี้

![ภาพที่ 1 — หน้าแรกของเว็บโรงเรียน](../assets/screenshots/public/landing-hero.webp)
*วงแดงในภาพคือสี่จุดที่คนกดบ่อยที่สุด*

ในภาพมีสี่จุดที่ใช้บ่อย

1. **เข้าสู่ระบบ** (มุมขวาบน) — ใช้เมื่อพร้อมเข้าไปใช้งานเต็มรูปแบบ
2. **ประกาศ:** — แถบข่าวสั้นจากสภานักเรียน
3. **แจ้งเรื่องเลย** — ทางลัดพาไปหน้าเข้าสู่ระบบ สำหรับคนที่ตั้งใจมาแจ้งเรื่อง
4. **ดูรายงานสถิติ** — เลื่อนลงไปดูตัวเลขภาพรวมของโรงเรียน

## ดูตัวเลขภาพรวมของโรงเรียน

เลื่อนลงมาที่หัวข้อ **รายงานสถิติสถานะปัจจุบัน** จะเห็นตัวเลขห้าช่อง

![ภาพที่ 2 — รายงานสถิติสถานะปัจจุบัน](../assets/screenshots/public/landing-stats.webp)
*ตัวเลขชุดนี้ดึงสดจากระบบ ไม่ใช่ยอดที่พิมพ์ค้างไว้*

- **เรื่องส่งเข้ามาทั้งหมด** — นับทุกเรื่องที่นักเรียนแจ้งเข้ามา
- **อยู่ระหว่างดำเนินการ** — เรื่องที่ยังไม่ปิด
- **ดำเนินการเสร็จสิ้น** — เรื่องที่ปิดเรียบร้อยแล้ว
- **อัตราการปิดเรื่อง** — สัดส่วนเรื่องที่ปิดแล้วต่อเรื่องทั้งหมด คิดเป็นเปอร์เซ็นต์
- **เวลาเฉลี่ยต่อเคส** — เฉลี่ยว่าแต่ละเรื่องใช้เวลากี่ชั่วโมงกว่าจะจบ

ถ้าตัวเลขยังน้อยหรือเป็นศูนย์ แปลว่าโรงเรียนเพิ่งเริ่มใช้ระบบ ยังไม่มีเรื่องสะสมมากนัก

ใต้ตัวเลขมีกราฟ **ปริมาณการแจ้งเรื่องที่เข้าสู่ระบบ** ย้อนหลัง 14 วัน
ใช้ดูว่าช่วงไหนมีคนแจ้งเรื่องเยอะเป็นพิเศษ เช่น หลังสอบกลางภาคหรือช่วงเปิดเทอม

## อ่านประกาศล่าสุด

ประกาศจากสภานักเรียนขึ้นอยู่บนหน้าแรกเลย ประกาศที่สำคัญมากจะอยู่บนสุดและใช้สีเด่น
กดที่ประกาศเพื่ออ่านข้อความเต็มหรือเปิดลิงก์ที่แนบมา

ถ้ายังไม่มีประกาศ จะเห็นข้อความว่า **ยังไม่มีประกาศ...** ซึ่งเป็นเรื่องปกติ

## ดูเรื่องที่แก้เสร็จแล้ว

เลื่อนลงมาที่หัวข้อ **ผลลัพธ์ที่เกิดขึ้นจริง** ส่วนนี้ตั้งใจให้เห็นว่า
เรื่องที่แจ้งไปไม่ได้หายเข้าระบบ แต่มีคนลงมือทำจริง

แต่ละเรื่องจะบอก **ประเด็นที่รับแจ้ง** **ผลการดำเนินการ** **หน่วยงานที่รับผิดชอบ**
และ **ระยะเวลาดำเนินการ** เช่น แจ้งว่าห้องน้ำอาคาร 3 น้ำไม่ไหล ใช้เวลาสองวันซ่อมเสร็จ

![ภาพที่ 3 — ตัวอย่างเรื่องที่ดำเนินการเสร็จแล้ว](../assets/screenshots/public/landing-resolved.webp)
*ชื่อคนแจ้งถูกปิดไว้ทุกเรื่อง เหลือแค่ "แจ้งโดย" กับสถานะนักเรียน*

จุดที่คนแจ้งแสดงเป็น **แจ้งโดย** ตามด้วยข้อความกลาง ๆ เช่น
**นักเรียน (ไม่ประสงค์ออกนาม)** หรือ **นักเรียน ม.4/1** ตามที่ระบบกำหนด
ชื่อจริงไม่เคยขึ้นบนหน้าสาธารณะ

## รู้จัก PIRI Talk และ PIRI Vote

ส่วน **ระบบนิเวศน์ PIRIvoice** แนะนำสองบริการที่ทำงานคู่กับระบบแจ้งเรื่อง

- 💬 **PIRI Talk** — บอร์ดสนทนาสำหรับแลกเปลี่ยนความคิดเห็น โดยมีสภานักเรียนช่วยดูแล
- 🗳️ **PIRI Vote** — บอร์ดโหวตสำหรับหาข้อสรุปร่วมกัน หนึ่งคนหนึ่งเสียง

::: warning อยากเข้าบอร์ด ต้องล็อกอินก่อนนะ
คนที่เข้ามาดูเฉย ๆ ยังอ่านบอร์ดไม่ได้ เพราะในบอร์ดมีคอมเมนต์ของนักเรียน
ที่ต้องดูแลเรื่องความเป็นส่วนตัวและความเหมาะสม
:::

## ข้อจำกัดและข้อควรระวัง

- ตัวเลขบนหน้านี้เป็นข้อมูลจริงของโรงเรียน แต่เป็นภาพรวม เจาะดูรายเรื่องไม่ได้
  พอมีคนปิดเรื่องเสร็จ ตัวเลขจะขยับตามเมื่อเปิดหน้าใหม่
- หน้าเว็บสาธารณะไม่มีช่องค้นหาเรื่อง และไม่มีรายชื่อนักเรียน
- ประกาศที่ถูกปลดออกหรือลบไปแล้วจะไม่แสดง และเรื่องที่ยังเปิดอยู่
  จะไม่ปรากฏในส่วน **ผลลัพธ์ที่เกิดขึ้นจริง**
- ถ้าเปิดแล้วข้อมูลไม่ขึ้น ให้กด **ดึงข้อมูลอีกครั้ง** มักเกิดจากสัญญาณอินเทอร์เน็ต

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: ตัวเลขไม่ตรงกับที่ครูบอกในห้อง?**

👉 **วิธีแก้:** หน้านี้ดึงข้อมูลสดตอนที่เปิด ถ้าเพิ่งมีการปิดเรื่อง ให้กดรีเฟรชอีกครั้ง
ตัวเลขอาจต่างจากรายงานที่พิมพ์ไว้ก่อนหน้าอยู่บ้าง

**Q: ขึ้นว่า "ไม่สามารถดึงข้อมูลสถิติได้" ต้องทำยังไง?**

👉 **วิธีแก้:** กด **ดึงข้อมูลอีกครั้ง** ถ้ายังไม่หายให้รอสักครู่แล้วลองใหม่
ข้อความนี้แปลว่าโหลดไม่สำเร็จ ไม่ได้แปลว่าข้อมูลหายไป

**Q: ทำไมไม่เห็นชื่อคนแจ้ง?**

👉 **วิธีแก้:** ระบบปิดชื่อผู้แจ้งบนทุกหน้าที่ไม่ต้องล็อกอิน เพื่อปกป้องข้อมูลส่วนตัวของนักเรียน

**Q: เปิดบอร์ดจากหน้านี้ได้ไหม?**

👉 **วิธีแก้:** ไม่ได้ ต้องล็อกอินก่อน เพราะบอร์ดมีคอมเมนต์ที่ต้องดูแล

**Q: ตัวเลขที่เห็นเป็นของทั้งโรงเรียนหรือของระดับไหน?**

👉 **วิธีแก้:** เป็นภาพรวมของทั้งโรงเรียน ข้อมูลแยกรายระดับชั้นจะเห็นได้หลังล็อกอิน
และเฉพาะคนที่มีสิทธิ์เท่านั้น

**Q: เปิดเว็บแล้วค้างอยู่ที่หน้าโลโก้?**

👉 **วิธีแก้:** เช็กอินเทอร์เน็ตก่อน แล้วเปิดใหม่ ถ้ายังค้างให้บอกผู้ดูแลระบบพร้อมเวลาที่เจอปัญหา

## พร้อมแล้วก็เข้ามาใช้เลย

ถ้าดูแล้วอยากลองใช้เอง กด **เข้าสู่ระบบ** ที่มุมขวาบน
แล้วกรอกรหัสนักเรียนกับรหัสผ่านครั้งแรก (รหัสผ่านเริ่มต้นคือรหัสนักเรียน) ระบบจะพาไปหน้าแรกให้เอง

เข้าไปแล้วลองสองอย่างนี้ก่อน

1. เปิด [บอร์ด การโหวต และไอเดีย](boards-and-voting.md) ดูว่าเพื่อน ๆ กำลังคุยเรื่องอะไร
2. อ่าน [การแจ้งเรื่องและติดตามสถานะ](issue-reporting-tracking.md) แล้วลองส่งเรื่องแรกดู

ไม่ต้องรอให้มีเรื่องใหญ่ เรื่องเล็กที่เจอในชีวิตประจำวันก็มีประโยชน์ทั้งนั้น
