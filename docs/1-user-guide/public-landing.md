# หน้าเว็บสาธารณะก่อนเข้าสู่ระบบ

หน้านี้สำหรับผู้ที่ยังไม่ล็อกอิน ใช้ดูว่าธรรมเนียมการรับเรื่องของโรงเรียนเป็นอย่างไร
มีประกาศอะไรบ้าง และระบบแก้เรื่องที่ผ่านมาได้จริงหรือไม่

## ใครใช้บทนี้

ผู้ปกครอง นักเรียน ครู หรือผู้เยี่ยมชมที่เปิดเว็บโรงเรียนโดยยังไม่มีบัญชี
ไม่ต้องล็อกอินก็อ่านได้

## ก่อนเริ่ม

- เปิดที่อยู่เว็บหลักของโรงเรียน จะเห็นหน้าแนะนำระบบที่ `/`
- ข้อมูลบนหน้านี้เป็นข้อมูลสรุปจากฐานข้อมูลจริง ไม่ใช่ข้อมูลตัวอย่าง
- ชื่อผู้แจ้งเรื่องที่แสดงในผลลัพธ์ถูกปิดนามตามนโยบายความเป็นส่วนตัว

![ภาพที่ 1 — หน้าเว็บสาธารณะ](../assets/screenshots/public/landing-hero.webp)

## ถ้าต้องการดูว่าปัจจุบันมีเรื่องอะไรบ้าง

1. เลื่อนลงไปที่หัวข้อ **รายงานสถิติสถานะปัจจุบัน**
2. อ่านตัวเลข **เรื่องส่งเข้ามาทั้งหมด** **อยู่ระหว่างดำเนินการ** **ดำเนินการเสร็จสิ้น**
   **อัตราการปิดเรื่อง** และ **เวลาเฉลี่ยต่อเคส**
3. ดูกราฟ **ปริมาณการแจ้งเรื่องที่เข้าสู่ระบบ** ซึ่งแสดงย้อนหลัง 14 วัน
4. หากต้องการข้อมูลละเอียดกว่า ให้เข้าสู่ระบบแล้วเปิด **แดชบอร์ด**

::: info ตัวเลขสดจากฐานข้อมูลจริง
ผู้เยี่ยมชมดูได้อย่างเดียว ไม่สามารถแก้ไขข้อมูลได้
:::

## ถ้าต้องการอ่านประกาศล่าสุด

1. ดูแถบ **กระดานข่าว** ใต้ส่วนหัว หรือการ์ด **อัปเดตล่าสุด**
2. ประกาศที่มีความสำคัญ **ด่วนมาก** จะแสดงสีแดงและอยู่บนสุด
3. กดประกาศเพื่ออ่านข้อความเต็มหรือเปิดลิงก์ที่แนบไว้
4. หากยังไม่มีประกาศ จะเห็นข้อความ **ยังไม่มีประกาศในขณะนี้**

## ถ้าต้องการดูตัวอย่างเรื่องที่แก้ไขแล้ว

1. เลื่อนไปที่หัวข้อ **ผลลัพธ์ที่เกิดขึ้นจริง**
2. ระบบแสดงเรื่องที่ปิดแล้วล่าสุด พร้อม **ประเด็นที่รับแจ้ง** **ผลการดำเนินการ**
   **หน่วยงานที่รับผิดชอบ** และ **ระยะเวลาดำเนินการ**
3. ชื่อผู้แจ้งถูกแทนด้วยข้อความเช่น **นักเรียน (ไม่ประสงค์ออกนาม)** หรือ
   **นักเรียน ม.4/1** ตามที่ระบบกำหนด
4. หากยังไม่มีเรื่องที่ปิด จะเห็นข้อความ **อยู่ระหว่างดำเนินการเคสแรก**

## ถ้าต้องการเข้าใจว่าบอร์ดคืออะไร

ส่วน **ระบบนิเวศน์ PIRIvoice** อธิบายสองบริการ

- **PIRI Talk** กระดานสนทนาสาธารณะ แลกเปลี่ยนความคิดเห็นภายใต้การดูแลของสภานักเรียน
- **PIRI Vote** ระบบลงคะแนนเสียงเพื่อหาฉันทามติ

::: warning บอร์ดต้องเข้าสู่ระบบก่อน
ผู้เยี่ยมชมยังอ่านบอร์ดไม่ได้ เพราะบอร์ดอาจมีเนื้อหาที่ต้องดูแล
:::

## ถ้าต้องการแจ้งเรื่องหรือเข้าใช้งาน

1. กด **แจ้งเรื่องเลย** หรือ **เข้าสู่ระบบ**
2. กรอกรหัสนักเรียนและรหัสผ่าน
3. อ่านขั้นตอนเริ่มใช้งานใน [เริ่มใช้งานและติดตั้งแอป](getting-started-pwa.md)

## ระบบทำอะไรเบื้องหลัง

::: info ข้อมูลสาธารณะถูกคัดกรองแล้ว
- เรียกข้อมูลจาก `/api/v1/public/stats`, `/api/v1/public/stats/trend`,
  `/api/v1/public/resolved-cases` และ `/api/v1/public/announcements`
- ไม่ต้องใช้ token และไม่แสดงข้อมูลติดต่อส่วนตัว
- หมายเลขโทรศัพท์ อีเมล และชื่อเต็มของผู้แจ้งไม่ถูกส่งออกใน API สาธารณะ
- หากฐานข้อมูลตอบช้า หน้าจะแสดงข้อความขอให้ลองใหม่ ไม่ค้างที่หน้าโหลด
:::

## ข้อจำกัดและข้อควรระวัง

- ตัวเลขสถิติเป็นภาพรวม ไม่สามารถเจาะรายเรื่องได้จากหน้า public
- ประกาศที่ถูก **ปลดระวาง** หรือ **ลบ** จะไม่แสดง
- เรื่องที่ยังเปิดอยู่จะไม่ปรากฏในส่วนผลลัพธ์
- หน้า public ไม่มีช่องค้นหาเรื่อง และไม่มีรายชื่อนักเรียน

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: ทำไมตัวเลขสถิติไม่ตรงกับที่ครูบอก**
ตอบ: หน้าสาธารณะดึงข้อมูลสด ณ เวลาที่เปิดหน้า หากเพิ่งมีการปิดเรื่อง ให้กดรีเฟรชอีกครั้ง
ตัวเลขอาจต่างจากรายงานที่พิมพ์ไว้ก่อนหน้า

**ถาม: เห็นข้อความ "ไม่สามารถดึงข้อมูลสถิติได้ในขณะนี้" ต้องทำอย่างไร**
ตอบ: กด **ดึงข้อมูลอีกครั้ง** หากยังไม่หาย ให้รอสักครู่แล้วลองใหม่ ปัญหานี้มักเกิดจากเครือข่าย
หรือฐานข้อมูลตอบช้า ไม่ได้แปลว่าข้อมูลหาย

**ถาม: ทำไมไม่เห็นชื่อผู้แจ้ง**
ตอบ: ระบบปิดนามผู้แจ้งในทุกหน้าที่ไม่ต้องล็อกอิน เพื่อปกป้องข้อมูลส่วนบุคคล

**ถาม: เปิดบอร์ดจากหน้า public ได้ไหม**
ตอบ: ไม่ได้ ต้องเข้าสู่ระบบก่อน เพราะบอร์ดอาจมีคอมเมนต์ที่ต้องตรวจสอบและดูแล

**ถาม: หน้า public ใช้ข้อมูลชุดเดียวกับแอปหรือไม่**
ตอบ: ใช้ฐานข้อมูลเดียวกัน แต่ API สาธารณะส่งออกเฉพาะข้อมูลสรุปและข้อมูลที่ปิดนามแล้ว

**ถาม: เปิดเว็บแล้วเห็นหน้าโลโก้ค้าง**
ตอบ: ตรวจการเชื่อมต่ออินเทอร์เน็ต แล้วลองเปิดใหม่ หากยังค้างให้แจ้งผู้ดูแลระบบพร้อมเวลาที่เกิดปัญหา
