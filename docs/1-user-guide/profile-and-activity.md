# โปรไฟล์ กิจกรรมของฉัน และบุ๊กมาร์ก

บทนี้อธิบายวิธีแก้ข้อมูลติดต่อ ดูสถิติส่วนตัว และย้อนดูสิ่งที่เคยทำในระบบ

## ใครใช้บทนี้

ผู้ใช้ทุกคน

## ก่อนเริ่ม

- เข้าสู่ระบบแล้ว
- ข้อมูลบางช่องแก้ได้เฉพาะผู้ดูแลระบบ เช่น ห้องเรียน ตำแหน่ง และรหัสนักเรียน

## ถ้าต้องการแก้ข้อมูลส่วนตัว

1. เปิด **เพิ่มเติม**
2. เลือก **โปรไฟล์**
3. กด **แก้ไขโปรไฟล์**
4. แก้ **คำนำหน้า** **ชื่อ** **นามสกุล** **ชื่อเล่น** **เบอร์โทร** หรือ **อีเมล**
5. กด **บันทึก**

::: warning แก้ได้เฉพาะข้อมูลติดต่อ
ชื่อและนามสกุลจำเป็นต้องกรอก ส่วนห้องเรียน ตำแหน่ง และรหัสนักเรียนแก้จากหน้านี้ไม่ได้
:::

## ถ้าต้องการดูสถิติของตนเอง

1. เปิด **โปรไฟล์**
2. เลื่อนไปที่การ์ด **สถิติของฉัน**
3. อ่านตัวเลข 6 ช่อง

| ช่อง | นับอะไร |
|---|---|
| **เรื่องที่แจ้ง** | เรื่องที่คุณแจ้งในช่วงสถิติ |
| **ปิดแล้ว** | เรื่องที่ปิดแล้วในช่วงสถิติ |
| **กำลังดำเนินการ** | เรื่องที่ยังรอรับ กำลังทำ หรือส่งต่อ |
| **โหวต** | จำนวนครั้งที่คุณโหวต |
| **คอมเมนต์บอร์ด** | จำนวนคอมเมนต์บนบอร์ด |
| **คอมเมนต์เรื่อง** | จำนวนคอมเมนต์ในเรื่อง |

::: info ตัวเลขสถิติขึ้นกับภาคเรียนปัจจุบัน
- ตั้งภาคเรียนแล้ว → นับเฉพาะช่วงของภาคนั้น
- ยังไม่ตั้งภาค → แสดง **สถิติทั้งหมด (ยังไม่ได้ตั้งภาคเรียน)**
:::

## ถ้าต้องการดูว่าตนเคยทำอะไรบ้าง

1. เปิด **เพิ่มเติม**
2. เลือก **กิจกรรมของฉัน**
3. เลือกแท็บ **ทั้งหมด** **แจ้งเรื่อง** **โหวต** **คอมเมนต์บอร์ด** หรือ **คอมเมนต์เรื่อง**
4. กดรายการเพื่อเปิดเรื่องหรือบอร์ดต้นทาง

::: tip กิจกรรมของฉัน ≠ สถิติของฉัน
- **กิจกรรมของฉัน** แสดงทุกอย่างที่เคยทำ ไม่กรองตามภาคเรียน
- **สถิติของฉัน** กรองตามภาคเรียนปัจจุบัน
:::

## ถ้าต้องการดูเรื่องหรือบอร์ดที่บันทึกไว้

1. เปิด **กิจกรรมของฉัน**
2. เลือกแท็บ **บันทึกไว้**
3. กดรายการเพื่อเปิด

หากยังไม่มีรายการ ให้กดไอคอนบุ๊กมาร์กที่หัวเรื่องหรือหัวบอร์ดก่อน

## ถ้าต้องการเอารายการออกจากบุ๊กมาร์ก

1. เปิดเรื่องหรือบอร์ดที่บันทึกไว้
2. กดไอคอนบุ๊กมาร์กอีกครั้งเพื่อยกเลิก
3. รายการจะหายจากแท็บ **บันทึกไว้**

## ถ้าต้องการเปลี่ยนรหัสผ่าน

1. เปิด **ตั้งค่า**
2. ในหัวข้อ **บัญชี** กด **เปลี่ยนรหัสผ่าน**
3. กรอกข้อมูลแล้วกด **เปลี่ยนรหัสผ่าน**

รายละเอียดอยู่ใน [เริ่มใช้งานและติดตั้งแอป](getting-started-pwa.md)

## ระบบทำอะไรเบื้องหลัง

- โปรไฟล์เชื่อมกับผู้ใช้และแถวสมาชิกในปีการศึกษาปัจจุบัน
- การแก้โปรไฟล์ถูกบันทึกในบันทึกการใช้งาน
- สถิติกรองตาม `academic_terms` ปัจจุบัน โดยนับวันสุดท้ายของภาคด้วย
- กิจกรรมรวม 4 ชนิด คือแจ้งเรื่อง โหวต คอมเมนต์บอร์ด และคอมเมนต์เรื่อง
- หากต้นทางถูกลบ รายการกิจกรรมจะไม่ทำลิงก์ให้กด

## ข้อจำกัดและข้อควรระวัง

- แก้ห้องเรียน ตำแหน่ง หรือรหัสนักเรียนจากหน้าโปรไฟล์ไม่ได้
- ไม่มีการอัปโหลดรูปโปรไฟล์จากหน้าเว็บ
- สถิติของฉันกับกิจกรรมของฉันใช้ช่วงเวลาต่างกันตามการออกแบบ
- บุ๊กมาร์กรองรับเฉพาะเรื่องและบอร์ด

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: แก้ชื่อแล้วแต่ชื่อในเรื่องเก่ายังเป็นชื่อเดิม**
ตอบ: เรื่องและคอมเมนต์เก็บชื่อ ณ เวลาที่สร้างไว้ เพื่อให้ประวัติไม่เปลี่ยนย้อนหลัง
ชื่อใหม่จะใช้กับรายการใหม่

**ถาม: สถิติเป็นศูนย์ทั้งที่เคยแจ้งเรื่อง**
ตอบ: ตรวจว่ามีภาคเรียนปัจจุบันที่ครอบช่วงเวลานั้นหรือไม่
หากยังไม่ตั้งภาค ระบบจะนับทั้งหมดและแสดงข้อความกำกับ

**ถาม: กิจกรรมของฉันกับสถิติตัวเลขไม่ตรงกัน**
ตอบ: เป็นไปได้เพราะกิจกรรมไม่กรองตามภาค ส่วนสถิติกรองตามภาคปัจจุบัน
ให้ดูข้อความใต้หัวข้อ **สถิติของฉัน** ว่ากำลังนับช่วงใด

**ถาม: บุ๊กมาร์กหายไป**
ตอบ: ตรวจว่าเปิดบัญชีเดิม และเรื่องหรือบอร์ดยังไม่ถูกลบ
รายการที่ต้นทางถูกลบจะไม่แสดงลิงก์

**ถาม: เปลี่ยนชื่อแล้วต้องแจ้งครูไหม**
ตอบ: ไม่ต้อง ระบบใช้ชื่อใหม่กับรายการใหม่โดยอัตโนมัติ
แต่หากต้องการให้เอกสารราชการตรงกัน ให้แจ้งผู้ดูแลระบบด้วย

**ถาม: ทำไมแก้เบอร์โทรแล้วระบบไม่ส่ง OTP**
ตอบ: ระบบไม่มี OTP หรือยืนยันเบอร์ โปรไฟล์ใช้สำหรับติดต่อภายในเท่านั้น
