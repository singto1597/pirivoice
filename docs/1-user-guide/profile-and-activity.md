# โปรไฟล์ ประวัติกิจกรรม และบุ๊กมาร์ก

หน้าโปรไฟล์คือที่รวมข้อมูลของเรา สถิติการใช้งาน และรายการที่เคยทำในระบบ
บางช่องแก้ได้เอง บางช่องต้องให้โรงเรียนแก้ให้ บทนี้บอกว่าแต่ละอย่างอยู่ตรงไหน

## ดูโปรไฟล์ของฉัน

1. เปิด **เพิ่มเติม** ที่แถบล่าง
2. เลือก **โปรไฟล์**

![ภาพที่ 1 — หน้าโปรไฟล์](../assets/screenshots/user/profile.webp)

จะเห็นชื่อ ห้องเรียน และข้อมูลติดต่อ ถ้าเป็นตำแหน่งในสภา จะมีข้อมูลตำแหน่งแสดงด้วย

## แก้ข้อมูลส่วนตัว

1. เปิด **เพิ่มเติม** → **โปรไฟล์**
2. กด **แก้ไขโปรไฟล์**
3. แก้ช่องที่ต้องการ
4. กด **บันทึก**

![ภาพที่ 2 — หน้าแก้ไขโปรไฟล์](../assets/screenshots/user/profile-edit.webp)

ช่องที่แก้เองได้ตามหมายเลขในภาพ

| หมายเลข | ช่อง |
|---|---|
| 1 | **คำนำหน้า** |
| 2 | **ชื่อ** |
| 3 | **นามสกุล** |
| 4 | **ชื่อเล่น** |
| 5 | **เบอร์โทร** |
| 6 | **อีเมล** |

::: warning บางช่องต้องให้โรงเรียนแก้
รหัสนักเรียน ห้องเรียน และตำแหน่ง แก้จากหน้านี้ไม่ได้
เพราะผูกกับทะเบียนนักเรียนของโรงเรียน ถ้าต้องแก้ให้บอกครูหรือผู้ดูแลระบบ
:::

::: tip กรอกเบอร์โทรและอีเมลให้ถูก
ข้อมูลนี้ใช้ตอนที่สภานักเรียนหรือครูต้องติดต่อกลับเรื่องที่เราแจ้ง
ถ้าเปลี่ยนเบอร์ใหม่ อย่าลืมกลับมาแก้
:::

## สถิติของฉัน

เลื่อนลงมาใต้ข้อมูลส่วนตัว จะเจอการ์ด **สถิติของฉัน** ที่มีตัวเลขหกช่อง

![ภาพที่ 3 — สถิติของฉันหกช่อง](../assets/screenshots/user/profile-stats.webp)

| ช่อง | นับอะไร |
|---|---|
| **เรื่องที่แจ้ง** | เรื่องที่เราแจ้งในภาคเรียนนี้ |
| **ปิดแล้ว** | เรื่องที่ปิดเรียบร้อยแล้ว |
| **กำลังดำเนินการ** | เรื่องที่ยังรอรับ กำลังทำ หรือส่งต่อ |
| **โหวต** | จำนวนครั้งที่เรากดโหวตบนบอร์ด |
| **คอมเมนต์บอร์ด** | จำนวนคอมเมนต์ที่เราเขียนในบอร์ด |
| **คอมเมนต์เรื่อง** | จำนวนคอมเมนต์ที่เราเขียนในเรื่อง |

::: info สถิตินับเฉพาะภาคเรียนปัจจุบัน
ใต้หัวข้อจะบอกว่าเป็นสถิติของภาคเรียนไหนและช่วงวันที่เท่าไร
เช่น สถิติภาคเรียนที่ 1/2569 ตั้งแต่ 10 พ.ค. ถึง 3 ต.ค. 2569
ถ้ายังไม่มีการตั้งภาคเรียน ระบบจะนับทั้งหมดและบอกไว้ให้รู้
:::

## กิจกรรมของฉัน

ถ้าอยากดูว่าตั้งแต่เข้าเรียนมาเคยทำอะไรบ้าง ใช้หน้า **กิจกรรมของฉัน**

1. เปิด **เพิ่มเติม**
2. เลือก **กิจกรรมของฉัน**
3. เลือกแท็บย่อย **ทั้งหมด** **แจ้งเรื่อง** **โหวต** **คอมเมนต์บอร์ด** หรือ **คอมเมนต์เรื่อง**
4. กดรายการเพื่อเปิดเรื่องหรือบอร์ดต้นทาง

![ภาพที่ 4 — กิจกรรมของฉันและแท็บบันทึกไว้](../assets/screenshots/user/activity.webp)

::: tip กิจกรรมของฉัน ≠ สถิติของฉัน
**กิจกรรมของฉัน** แสดงทุกอย่างที่เคยทำ ไม่จำกัดภาคเรียน
ส่วน **สถิติของฉัน** นับเฉพาะภาคเรียนปัจจุบัน
ตัวเลขจึงไม่เท่ากันเป็นเรื่องปกติ
:::

## เรื่องและบอร์ดที่บันทึกไว้

ถ้าเจอเรื่องหรือบอร์ดที่อยากกลับมาอ่านทีหลัง ให้กดไอคอนบุ๊กมาร์กที่หัวเรื่อง
หรือหัวบอร์ดก่อน

1. เปิด **เพิ่มเติม** → **กิจกรรมของฉัน**
2. เลือกแท็บ **บันทึกไว้**
3. กดรายการเพื่อเปิด

ถ้าอยากเอาออกจากรายการ ให้เปิดเรื่องนั้นแล้วกดไอคอนบุ๊กมาร์กอีกครั้ง

## เปลี่ยนรหัสผ่าน

อยู่ในหน้า **โปรไฟล์** เช่นกัน

1. เปิด **เพิ่มเติม** → **โปรไฟล์**
2. กด **เปลี่ยนรหัสผ่าน**
3. กรอกรหัสเดิม รหัสใหม่ และยืนยัน
4. กดยืนยัน

ขั้นตอนละเอียดอยู่ใน [การเข้าสู่ระบบและติดตั้งแอปลงมือถือ](getting-started-pwa.md)

## ระบบทำอะไรเบื้องหลัง

โปรไฟล์ผูกกับทะเบียนนักเรียนของปีการศึกษาปัจจุบัน
เวลาแก้ข้อมูล ระบบจะบันทึกไว้ในประวัติการใช้งานของโรงเรียนด้วย

สถิติคิดจากช่วงวันที่ของภาคเรียนที่ตั้งไว้ รวมวันสุดท้ายของภาคด้วย
ส่วนประวัติกิจกรรมเก็บทุกอย่างไว้ไม่จำกัดเวลา

ถ้าเรื่องหรือบอร์ดต้นทางถูกลบ รายการกิจกรรมนั้นจะยังอยู่แต่กดเปิดไม่ได้

## ข้อจำกัดและข้อควรระวัง

- แก้ห้องเรียน ตำแหน่ง หรือรหัสนักเรียนเองไม่ได้
- อัปโหลดรูปโปรไฟล์จากหน้าเว็บไม่ได้
- สถิติกับกิจกรรมใช้ช่วงเวลาต่างกัน
- บุ๊กมาร์กใช้ได้กับเรื่องและบอร์ดเท่านั้น

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: แก้ชื่อแล้วทำไมเรื่องเก่ายังเป็นชื่อเดิม**
ตอบ: เรื่องและคอมเมนต์เก็บชื่อ ณ วันที่เขียนไว้ เพื่อไม่ให้ประวัติเปลี่ยนย้อนหลัง
ชื่อใหม่จะใช้กับรายการใหม่

**ถาม: สถิติเป็นศูนย์ทั้งที่เคยแจ้งเรื่อง**
ตอบ: เช็กว่าภาคเรียนปัจจุบันครอบช่วงที่แจ้งหรือไม่
ถ้ายังไม่ตั้งภาคเรียน ระบบจะนับทั้งหมดและมีข้อความบอกไว้

**ถาม: ตัวเลขกิจกรรมของฉันกับสถิติไม่ตรงกัน**
ตอบ: ปกติ เพราะกิจกรรมไม่กรองตามภาค ส่วนสถิติกรองตามภาคปัจจุบัน

**ถาม: บุ๊กมาร์กหายไป**
ตอบ: เช็กว่าเข้าบัญชีเดิม และเรื่องหรือบอร์ดนั้นยังไม่ถูกลบ

**ถาม: แก้เบอร์โทรแล้วต้องยืนยันอะไรไหม**
ตอบ: ไม่ต้อง ระบบไม่มี OTP หรือการยืนยันเบอร์ ใช้สำหรับติดต่อภายในเท่านั้น
