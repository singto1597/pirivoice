# กิจกรรม การลงทะเบียน และคิวอาร์เช็คอิน

กิจกรรมของโรงเรียนรวมไว้ในแท็บ **กิจกรรม** ที่เดียว
ไม่ว่าจะเป็นค่าย การแข่งขัน หรือกิจกรรมวันสำคัญ

- ดูว่ากิจกรรมไหนเปิดรับ แล้วกดลงทะเบียน
- ที่นั่งเต็ม? เข้าคิวสำรองได้เลย
- ถึงวันงาน ยื่นบัตรคิวอาร์ให้สตาฟสแกน

## ดูรายการกิจกรรม

**ทางเข้า:** แท็บ **กิจกรรม** ➔ เลือก **กำลังจะมาถึง** **ผ่านไปแล้ว** หรือ **ทั้งหมด** ➔ กดการ์ดกิจกรรม

![ภาพที่ 1 — หน้าแรกของแท็บกิจกรรม](../assets/screenshots/user/events.webp)
*ปุ่มตัวกรองที่วงไว้ใช้สลับดูตามช่วงเวลา*

ถ้าอยากดูเฉพาะหมวด ให้เลือกหมวดจากตัวกรองด้านขวา
การ์ดแต่ละใบบอกวัน เวลา และจำนวนคนที่ลงทะเบียนแล้ว

![ภาพที่ 2 — การ์ดกิจกรรมและป้ายสถานะ](../assets/screenshots/user/events-list.webp)
*ป้ายมุมขวาบนของการ์ดบอกสถานะของกิจกรรม*

- 🟢 **เปิดรับสมัคร** — ยังสมัครได้
- 🔴 **ปิดรับสมัครแล้ว** — เลยกำหนดหรือกิจกรรมเริ่มแล้ว
- ⚫ **ยกเลิกแล้ว** — กิจกรรมถูกยกเลิก
- 🔵 **ไม่จำกัดจำนวน** — ไม่มีเพดานคน
- 👥 **N คน** — จำนวนคนที่ลงทะเบียนแล้ว

## เปิดรายละเอียดกิจกรรม

กดการ์ดกิจกรรม จะเห็นวันเวลา สถานที่ และรายละเอียดว่ากิจกรรมทำอะไร

![ภาพที่ 3 — หน้ารายละเอียดกิจกรรม](../assets/screenshots/user/event-detail.webp)
*หัวจอบอกสถานะและเหลือเวลาอีกกี่วันก่อนปิดรับ*

ถ้าปิดรับแล้ว ป้ายจะเปลี่ยนเป็น **ปิดรับสมัครแล้ว** และปุ่มสมัครจะหายไป

## ลงทะเบียน

**วิธีลงทะเบียน:** เปิดรายละเอียดกิจกรรม ➔ อ่านวันเวลาและสถานที่ให้ดี ➔ กด **ลงทะเบียนเข้าร่วม**

![ภาพที่ 4 — ปุ่มลงทะเบียนในหน้ารายละเอียดกิจกรรม](../assets/screenshots/user/event-register.webp)
*ปุ่มนี้จะอยู่ใต้รายละเอียดกิจกรรม*

ถ้ามีที่นั่ง หน้าจอจะขึ้นว่าลงทะเบียนสำเร็จทันที
และสถานะในหน้ากิจกรรมจะเปลี่ยนเป็น **ลงทะเบียนแล้ว**

การลงทะเบียนจะปิดเมื่อถึงกำหนดปิดรับ หรือเมื่อถึงเวลาจัดกิจกรรม แล้วแต่เวลาไหนถึงก่อน

## ที่นั่งเต็ม ทำยังไงดี

ถ้ากิจกรรมจำกัดจำนวนคนและเต็มแล้ว จะถูกพาเข้าคิวสำรองให้อัตโนมัติ

![ภาพที่ 5 — สถานะคิวสำรองและลำดับคิว](../assets/screenshots/user/event-waitlist.webp)
*หน้านี้จะบอกว่าเข้าคิวแล้วและอยู่ลำดับที่เท่าไร*

1. **กดเข้าคิวสำรอง** แล้วรอ
2. **ดูลำดับของตัวเอง** หน้าจอจะบอกว่าอยู่คิวที่เท่าไร
3. **รอต่อไป** ถ้ามีคนถอน คนแรกในคิวจะถูกเลื่อนขึ้นมาเอง
4. **รอแจ้งเตือน** พอได้ที่นั่ง จะมีแจ้งเตือนว่า **คุณได้ที่นั่งแล้ว**

คิวเรียงตามเวลาที่ลงทะเบียน คนที่มาก่อนได้ก่อน จัดลำดับเองไม่ได้
คิวไม่หมดอายุเอง ถ้าอยากถอนก็กดถอนได้ตลอด

## ถอนการลงทะเบียน

**ทางเข้า:** เปิดรายละเอียดกิจกรรม ➔ **ถอนการลงทะเบียน** ➔ ยืนยันอีกครั้ง

ถ้ามีคนอยู่ในคิวสำรอง คนแรกในคิวจะถูกเลื่อนขึ้นมาทันที
ถ้าวันหลังอยากลงใหม่ ต้องรอให้มีที่นั่งว่างจริง ๆ และลำดับคิวใหม่จะต่อท้าย

## เช็คอินที่หน้างาน

พอไปถึงงาน ให้เปิดรายละเอียดกิจกรรมแล้วดูการ์ด **บัตรเช็คอินของคุณ**

![ภาพที่ 6 — บัตรเช็คอินที่มีคิวอาร์](../assets/screenshots/user/checkin-card.webp)
*ยื่นหน้าจอนี้ให้เจ้าหน้าที่สแกน ไม่ต้องกดอะไรเอง*

1. **เปิดบัตรเช็คอิน** ขึ้นมา
2. **ยื่นหน้าจอให้เจ้าหน้าที่สแกน**
3. **รอจนสแกนเสร็จ** สถานะจะเปลี่ยนเป็น **เช็คอินแล้ว** พร้อมเวลา

::: warning เช็คอินเองไม่ได้นะ ต้องให้สตาฟสแกน
หน้านี้เรากดเช็คอินเองไม่ได้ เพราะต้องเช็กว่าเรามาถึงหน้างานจริง ๆ
ถ้าใครบอกให้กดเช็คอินให้ ก็ไม่ต้องทำ
:::

::: tip แบตหมด ลืมมือถือ หรือสแกนไม่ติด ทำยังไงดี?
บอกเจ้าหน้าที่ว่าเราเป็นใคร เจ้าหน้าที่เปิดรายชื่อผู้สมัครแล้วกดเช็คอินให้ได้
หรืออ่านรหัสใต้คิวอาร์ให้เจ้าหน้าที่พิมพ์ก็ได้ ไม่ต้องตกใจ
:::

## แชร์กิจกรรมให้เพื่อน

**ทางเข้า:** เปิดรายละเอียดกิจกรรม ➔ เลื่อนไปที่ **ชวนเพื่อนมาร่วมกิจกรรม** ➔ กด **คัดลอก**

แล้วส่งลิงก์ในกลุ่มแชทได้เลย คนที่เปิดลิงก์ต้องเข้าสู่ระบบก่อน จึงจะเห็นรายละเอียดและสมัครได้

## ถ้ากิจกรรมถูกยกเลิก

- ระบบปิดรับสมัครทันที
- คนที่ลงทะเบียนไว้จะได้รับการแจ้งเตือน
- กิจกรรมยังเปิดดูได้ ไม่ได้ถูกลบ
- คนในคิวสำรองจะไม่ถูกเลื่อนขึ้น เพราะไม่มีที่นั่งให้แล้ว

## ข้อจำกัดและข้อควรระวัง

- ไม่มีแท็บกิจกรรมของฉัน แยกดูได้จากหน้ารายละเอียดกิจกรรมที่ลงทะเบียนไว้
- จัดลำดับคิวเองไม่ได้ และคิวไม่หมดอายุอัตโนมัติ
- ไม่มีปฏิทินรายเดือน
- เฉพาะเจ้าหน้าที่ที่มีสิทธิ์จัดการกิจกรรมเท่านั้นที่สแกนเช็คอินได้
- ระบบจองที่นั่งให้ทันทีตอนกดลงทะเบียน เพื่อไม่ให้สองคนแย่งที่นั่งสุดท้ายพร้อมกัน
- เช็คอินซ้ำจะไม่ถูกนับสองครั้ง

## ติดปัญหาตรงไหน? ดูวิธีแก้ตรงนี้เลย

**Q: กดลงทะเบียนแล้วขึ้นว่ากิจกรรมยังไม่เปิดให้ลงทะเบียน?**

👉 **วิธีแก้:** กิจกรรมอาจยังเป็นฉบับร่างหรือยังไม่ประกาศ ให้รอสภานักเรียนเผยแพร่ก่อน

**Q: ที่นั่งเต็มแต่ยังอยากไป?**

👉 **วิธีแก้:** กด **เข้าคิวสำรอง** แล้วรอ พอมีคนถอนจะเลื่อนให้เอง

**Q: อยู่ในคิวแล้วจะรู้ได้ยังไงว่าได้ที่นั่ง?**

👉 **วิธีแก้:** จะมีแจ้งเตือน **คุณได้ที่นั่งแล้ว** และสถานะในหน้ากิจกรรมจะเปลี่ยนเป็น **ลงทะเบียนแล้ว**

**Q: คิวอาร์ใช้ได้ตลอดไหม?**

👉 **วิธีแก้:** ใช้ได้เมื่อยังลงทะเบียนอยู่ ถ้าถอนหรือกิจกรรมถูกยกเลิกจะใช้ไม่ได้

**Q: เช็คอินแล้วแต่สถานะยังไม่เปลี่ยน?**

👉 **วิธีแก้:** กดรีเฟรชหน้ารายละเอียดกิจกรรม ถ้ายังไม่เปลี่ยนให้บอกเจ้าหน้าที่ให้ตรวจรายชื่อ

**Q: ถอนแล้วอยากลงใหม่ได้ไหม?**

👉 **วิธีแก้:** ได้ ถ้ายังอยู่ในช่วงรับสมัครและมีที่นั่งหรือคิวว่าง
แต่ลำดับคิวใหม่จะต่อท้าย ไม่ได้ลำดับเดิม
