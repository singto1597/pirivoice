# กิจกรรม การลงทะเบียน และคิวอาร์เช็คอิน

กิจกรรมของโรงเรียนจะประกาศในแท็บ **กิจกรรม** ทั้งหมด ไม่ว่าจะเป็นค่าย การแข่งขัน
หรือกิจกรรมวันสำคัญ บทนี้อธิบายวิธีสมัคร วิธีรอคิวสำรอง และวิธีใช้บัตรคิวอาร์
ตอนเช็คอินที่หน้างาน

## ดูรายการกิจกรรม

1. กดแท็บ **กิจกรรม** ที่แถบล่าง
2. เลือก **กำลังจะมาถึง** **ผ่านไปแล้ว** หรือ **ทั้งหมด**
3. ถ้าอยากดูเฉพาะหมวด ให้เลือกหมวดจากตัวกรองด้านขวา
4. กดการ์ดกิจกรรมเพื่อเปิดรายละเอียด

![ภาพที่ 1 — หน้าแรกของแท็บกิจกรรม](../assets/screenshots/user/events.webp)

การ์ดแต่ละใบบอกวัน เวลา และจำนวนคนที่ลงทะเบียนแล้ว

![ภาพที่ 2 — การ์ดกิจกรรมและป้ายสถานะ](../assets/screenshots/user/events-list.webp)

| ป้าย | ความหมาย |
|---|---|
| **เปิดรับสมัคร** | ยังสมัครได้ |
| **ปิดรับสมัครแล้ว** | เลยกำหนดหรือกิจกรรมเริ่มแล้ว |
| **ยกเลิกแล้ว** | กิจกรรมถูกยกเลิก |
| **ไม่จำกัดจำนวน** | ไม่มีเพดานคน |
| **N คน** | จำนวนคนที่ลงทะเบียนแล้ว |

## เปิดรายละเอียดกิจกรรม

กดการ์ดกิจกรรม จะเห็นวันเวลา สถานที่ และรายละเอียดว่ากิจกรรมทำอะไร

![ภาพที่ 3 — หน้ารายละเอียดกิจกรรม](../assets/screenshots/user/event-detail.webp)

ตรงหัวจอมีป้ายสถานะ เช่น **เปิดรับสมัคร** และบอกว่าเหลือเวลาอีกกี่วันก่อนปิดรับ
ถ้าปิดรับแล้ว ป้ายจะเปลี่ยนเป็น **ปิดรับสมัครแล้ว** และปุ่มสมัครจะหายไป

## ลงทะเบียน

1. เปิดรายละเอียดกิจกรรม
2. อ่านวันเวลาและสถานที่ให้ดี
3. กด **ลงทะเบียนเข้าร่วม**

![ภาพที่ 4 — ปุ่มลงทะเบียนในหน้ารายละเอียดกิจกรรม](../assets/screenshots/user/event-register.webp)

ถ้ามีที่นั่ง ระบบจะขึ้นว่าลงทะเบียนสำเร็จทันที และสถานะในหน้ากิจกรรมจะเปลี่ยนเป็น
**ลงทะเบียนแล้ว**

::: info ปิดรับเมื่อไร
การลงทะเบียนปิดเมื่อถึงกำหนดปิดรับ หรือเมื่อถึงเวลาจัดกิจกรรม แล้วแต่เวลาไหนถึงก่อน
:::

## ที่นั่งเต็ม ทำอย่างไร

ถ้ากิจกรรมจำกัดจำนวนคนและเต็มแล้ว ระบบจะพาเข้าคิวสำรองให้อัตโนมัติ

![ภาพที่ 5 — สถานะคิวสำรองและลำดับคิว](../assets/screenshots/user/event-waitlist.webp)

1. กด **เข้าคิวสำรอง**
2. ระบบจะบอกว่าเข้าคิวแล้วและอยู่ลำดับที่เท่าไร
3. รอต่อไป ถ้ามีคนถอน ระบบจะเลื่อนคนแรกในคิวขึ้นมาอัตโนมัติ
4. เมื่อได้ที่นั่ง ระบบจะแจ้งเตือน **คุณได้ที่นั่งแล้ว**

::: tip ลำดับคิว
เรียงตามเวลาที่ลงทะเบียน คนที่มาก่อนได้ก่อน จัดลำดับเองไม่ได้
คิวไม่หมดอายุเอง ถ้าอยากถอนก็กดถอนได้ตลอด
:::

## ถอนการลงทะเบียน

1. เปิดรายละเอียดกิจกรรม
2. กด **ถอนการลงทะเบียน**
3. ยืนยันอีกครั้ง

::: warning ถอนแล้วอาจกลับมาลงใหม่ไม่ได้
ถ้ามีคนอยู่ในคิวสำรอง ระบบจะเลื่อนคนแรกขึ้นมาทันที
ถ้าภายหลังอยากลงใหม่ ต้องรอให้มีที่นั่งว่างจริง ๆ และลำดับคิวใหม่จะต่อท้าย
:::

## เช็คอินที่หน้างาน

เมื่อไปถึงงาน เปิดรายละเอียดกิจกรรมแล้วดูการ์ด **บัตรเช็คอินของคุณ**

![ภาพที่ 6 — บัตรเช็คอินที่มีคิวอาร์](../assets/screenshots/user/checkin-card.webp)

1. เปิดการ์ดบัตรเช็คอินขึ้นมา
2. ยื่นหน้าจอให้เจ้าหน้าที่สแกน
3. เมื่อสแกนสำเร็จ สถานะจะเปลี่ยนเป็น **เช็คอินแล้ว** พร้อมเวลา

::: warning เจ้าหน้าที่เป็นคนสแกน ไม่ใช่เรา
ผู้เข้าร่วมกดเช็คอินเองไม่ได้ เพราะระบบต้องกันการเช็คอินแทนกัน
ถ้าใครบอกให้กดเช็คอินให้ ก็ไม่ต้องทำ
:::

ถ้ามือถือแบตหมด ลืมเอามา หรือกล้องของเจ้าหน้าที่อ่านไม่ขึ้น
ให้บอกเจ้าหน้าที่ว่าเป็นใคร เจ้าหน้าที่เปิดรายชื่อผู้สมัครแล้วกดเช็คอินให้ได้
หรืออ่านรหัสใต้คิวอาร์ให้เจ้าหน้าที่พิมพ์ก็ได้

## แชร์กิจกรรมให้เพื่อน

1. เปิดรายละเอียดกิจกรรม
2. เลื่อนไปที่ **ชวนเพื่อนมาร่วมกิจกรรม**
3. กด **คัดลอก** แล้วส่งลิงก์ในกลุ่มแชท

คนที่เปิดลิงก์ต้องเข้าสู่ระบบก่อน จึงจะเห็นรายละเอียดและสมัครได้

## ถ้ากิจกรรมถูกยกเลิก

- ระบบปิดรับสมัครทันที
- คนที่ลงทะเบียนไว้จะได้รับการแจ้งเตือน
- กิจกรรมยังเปิดดูได้ ไม่ได้ถูกลบ
- คนในคิวสำรองจะไม่ถูกเลื่อนขึ้น เพราะไม่มีที่นั่งให้แล้ว

## ระบบทำอะไรเบื้องหลัง

ระบบจองที่นั่งให้ทันทีตอนกดลงทะเบียน เพื่อไม่ให้คนสองคนแย่งที่นั่งสุดท้ายพร้อมกัน
ถ้ากิจกรรมไม่ได้กำหนดจำนวนคน จะลงทะเบียนได้ไม่จำกัด

เมื่อมีคนถอน ระบบจะเลื่อนคนแรกในคิวขึ้นมาเป็นตัวจริงและแจ้งเตือนให้อัตโนมัติ
ส่วนการเช็คอินซ้ำจะไม่ถูกนับสองครั้ง

## ข้อจำกัดและข้อควรระวัง

- ไม่มีแท็บกิจกรรมของฉัน แยกดูได้จากหน้ารายละเอียดกิจกรรมที่ลงทะเบียนไว้
- จัดลำดับคิวเองไม่ได้ และคิวไม่หมดอายุอัตโนมัติ
- ไม่มีปฏิทินรายเดือน
- เฉพาะเจ้าหน้าที่ที่มีสิทธิ์จัดการกิจกรรมเท่านั้นที่สแกนเช็คอินได้

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: กดลงทะเบียนแล้วขึ้นว่ากิจกรรมยังไม่เปิดให้ลงทะเบียน**
ตอบ: กิจกรรมอาจยังเป็นฉบับร่างหรือยังไม่ประกาศ ให้รอสภานักเรียนเผยแพร่ก่อน

**ถาม: ที่นั่งเต็มแต่ยังอยากไป**
ตอบ: กด **เข้าคิวสำรอง** แล้วรอ ระบบจะเลื่อนให้เมื่อมีคนถอน

**ถาม: อยู่ในคิวแล้วจะรู้ได้อย่างไรว่าได้ที่นั่ง**
ตอบ: ระบบส่งแจ้งเตือน **คุณได้ที่นั่งแล้ว** และสถานะในหน้ากิจกรรมจะเปลี่ยนเป็น
**ลงทะเบียนแล้ว**

**ถาม: คิวอาร์ใช้ได้ตลอดไหม**
ตอบ: ใช้ได้เมื่อยังลงทะเบียนอยู่ ถ้าถอนหรือกิจกรรมถูกยกเลิกจะใช้ไม่ได้

**ถาม: เช็คอินแล้วแต่สถานะยังไม่เปลี่ยน**
ตอบ: กดรีเฟรชหน้ารายละเอียดกิจกรรม ถ้ายังไม่เปลี่ยนให้บอกเจ้าหน้าที่ให้ตรวจรายชื่อ

**ถาม: ถอนแล้วอยากลงใหม่ได้ไหม**
ตอบ: ได้ ถ้ายังอยู่ในช่วงรับสมัครและมีที่นั่งหรือคิวว่าง
แต่ลำดับคิวใหม่จะต่อท้าย ไม่ได้ลำดับเดิม
