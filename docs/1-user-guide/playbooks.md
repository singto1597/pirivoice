# คู่มือการทำงานสภานักเรียน 6 เล่ม

คู่มือชุดนี้คือคู่มือฉบับจริงของสภานักเรียนโรงเรียนพิริยาลัย แบ่งเป็นหกเล่มตามฝ่ายงาน
นักเรียนทุกคนเปิดอ่านได้ ไม่ต้องเป็นสมาชิกสภาก่อน

## เปิดคู่มือ

1. เปิด **เพิ่มเติม** ที่แถบล่าง
2. เลือก **คู่มือการทำงาน**
3. กดการ์ดเล่มที่ต้องการ หรือกด **อ่านเล่มนี้**

![ภาพที่ 1 — หน้ารวมคู่มือทั้งหกเล่ม](../assets/screenshots/user/playbooks.webp)

## รู้จักทั้งหกเล่ม

| เล่ม | เนื้อหา |
|---|---|
| **เล่มที่ 1 วิชาการ** | แนวทางด้านการเรียน การสอบ ทุนการศึกษา และแหล่งเรียนรู้ในโรงเรียน |
| **เล่มที่ 2 ปฏิคม** | การดูแลห้องเรียน สภาพแวดล้อม และการแจ้งของชำรุด |
| **เล่มที่ 3 กิจกรรม** | กิจกรรมนักเรียน ชมรม และเทศกาลต่าง ๆ |
| **เล่มที่ 4 วินัย** | ระเบียบวินัยและกติกาของโรงเรียน |
| **เล่มที่ 5 สุขภาวะ** | สุขภาพกายและใจ การดูแลความเครียด |
| **เล่มที่ 6 ประชาธิปไตย** | บทบาทสภานักเรียน สิทธิและหน้าที่ของนักเรียน |

ถ้าไม่แน่ใจว่าเรื่องที่อยากรู้อยู่ในเล่มไหน ให้เริ่มจากเล่มที่ใกล้ที่สุด
เนื้อหาของแต่ละเล่มเขียนให้อ่านต่อเนื่องกันได้

## อ่านในแอป

เมื่อเปิดเล่มแล้ว หน้าหนังสือจะเรียงต่อกันเป็นแนวตั้ง เลื่อนลงไปเรื่อย ๆ
ไม่ต้องกดเปลี่ยนหน้า

แถบที่หัวจอจะบอกว่าอ่านไปถึงไหนแล้วของเล่มนั้น
ถ้าปิดแอปไปกลางคัน กลับมาต้องเลื่อนหาเอง ระบบไม่จำหน้าล่าสุดให้

![ภาพที่ 2 — หน้าอ่านคู่มือและปุ่มดาวน์โหลด](../assets/screenshots/user/playbook-reader.webp)

## ดาวน์โหลด PDF ต้นฉบับ

ถ้าต้องอ่านหลายรอบ หรืออยากเก็บไว้เปิดตอนไม่มีอินเทอร์เน็ต แนะนำให้ดาวน์โหลด

1. เปิดเล่มที่ต้องการ
2. กด **ดาวน์โหลด** ที่มุมขวาบน
3. ไฟล์จะถูกบันทึกหรือเปิดในแอปอ่าน PDF ของเครื่อง

::: tip ทำไมควรใช้ PDF เมื่ออ่านต่อเนื่อง
แอปไม่จำตำแหน่งอ่านล่าสุด ถ้าอ่านหนังสือทั้งเล่มหลายวันติดกัน
การเปิด PDF แล้วเลื่อนต่อจากเดิมจะสะดวกกว่า

บนจอเล็ก ปุ่มอาจแสดงแค่คำว่า **ดาวน์โหลด**
:::

## ระบบทำอะไรเบื้องหลัง

คู่มือถูกเก็บเป็นรูปหน้าหนังสือในระบบ ไม่ได้ดึงจากฐานข้อมูล
หน้าด้านล่างจะโหลดเมื่อเลื่อนใกล้ถึง เพื่อไม่ให้เปลืองอินเทอร์เน็ตตอนเปิดเล่มครั้งแรก

ถ้าไฟล์หน้าไหนยังไม่ถูกวางไว้ ระบบจะซ่อนหน้านั้นและบอกว่าขาดกี่หน้า
ส่วนหน้าที่มีอยู่ยังอ่านได้ตามปกติ

## ข้อจำกัดและข้อควรระวัง

- ไม่มีช่องค้นหาคำในคู่มือ
- ไม่มีสารบัญให้กดข้ามบท
- ระบบจำตำแหน่งอ่านล่าสุดไม่ได้
- อัปโหลดหรือแก้ไขคู่มือจากหน้าเว็บไม่ได้ ผู้ดูแลเป็นคนวางไฟล์

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: เปิดเล่มแล้วขึ้นว่าหน้ายังมาไม่ครบ**
ตอบ: รูปบางหน้ายังไม่ถูกวางในระบบ หน้าที่มีอยู่ยังอ่านได้
ให้แจ้งผู้ดูแลระบบให้ตรวจไฟล์ของเล่มนั้น

**ถาม: ปกขึ้นว่า "ยังไม่พร้อมใช้งาน"**
ตอบ: ไฟล์ปกของเล่มนั้นหายหรือชื่อไฟล์ไม่ตรง ลองกดเข้าไปอ่านเนื้อหาดู
ถ้าหน้ายังมีอยู่จะอ่านได้ปกติ และควรแจ้งผู้ดูแลให้แก้ปก

**ถาม: กดดาวน์โหลดแล้วไม่มีอะไรเกิดขึ้น**
ตอบ: ปุ่มจะทำงานเมื่อไฟล์ PDF ถูกวางไว้แล้ว ถ้ากดแล้วเงียบให้ลองเปิดบนคอมพิวเตอร์
หรือแจ้งผู้ดูแลว่าปุ่มดาวน์โหลดของเล่มนั้นใช้ไม่ได้

**ถาม: อ่านถึงกลางเล่มแล้วปิดแอป กลับมาต้องเริ่มใหม่ไหม**
ตอบ: ต้องเลื่อนกลับมาเอง จดเลขหน้าไว้หรือใช้ PDF แทนจะสะดวกกว่า

**ถาม: คู่มือมีเรื่องการเลื่อนชั้นไหม**
ตอบ: เล่ม **วิชาการ** และ **วินัย** มีแนวปฏิบัติเกี่ยวกับการเรียนและระเบียบ
แต่ขั้นตอนเลื่อนชั้นในระบบเป็นงานของเจ้าหน้าที่ ดูได้ที่
[การเลื่อนชั้นนักเรียน](../2-staff-operations/student-promotion.md)
