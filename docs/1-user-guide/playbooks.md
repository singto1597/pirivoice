# คู่มือการทำงาน 6 เล่ม

บทนี้อธิบายวิธีเปิดอ่านคู่มือนักเรียนในแอป วิธีติดตามความคืบหน้า และวิธีดาวน์โหลดฉบับ PDF

## ใครใช้บทนี้

ผู้ใช้ทุกคนที่เข้าสู่ระบบแล้ว

## ก่อนเริ่ม

- คู่มือมี 6 เล่ม แยกตามหมวดงานของสภานักเรียน
- เนื้อหาเป็นรูปหน้าหนังสือที่วางไว้ในระบบ ไม่ได้ดึงจากฐานข้อมูล
- ระบบไม่มีการค้นหาข้อความภายในคู่มือ

## ถ้าต้องการเปิดอ่านคู่มือ

1. เปิด **เพิ่มเติม**
2. ในกลุ่ม **ทั่วไป** เลือก **คู่มือการทำงาน**
3. กดการ์ดเล่มที่ต้องการ
4. เลื่อนลงเพื่ออ่านหน้าถัดไป

::: info อ่านแบบเลื่อนต่อเนื่อง
ระบบแสดงหน้าติดกันเป็นแนวตั้ง ไม่ต้องกดเปลี่ยนหน้า แถบสีที่หัวจอแสดงความคืบหน้าของการอ่าน
:::

![ภาพที่ 11 — หน้าคู่มือการทำงาน](../assets/screenshots/user/playbooks.webp)

## เลือกเล่มให้ตรงกับเรื่องที่ต้องการ

| เล่ม | เนื้อหา |
|---|---|
| **เล่มที่ 1 วิชาการ** | การเรียน การสอบ ทุนการศึกษา และแหล่งเรียนรู้ |
| **เล่มที่ 2 ปฏิคม** | การดูแลห้องเรียน สภาพแวดล้อม และของชำรุด |
| **เล่มที่ 3 กิจกรรม** | กิจกรรมนักเรียน ชมรม และเทศกาล |
| **เล่มที่ 4 วินัย** | ระเบียบวินัยและกติกาของโรงเรียน |
| **เล่มที่ 5 สุขภาวะ** | สุขภาพกายและใจ การจัดการความเครียด |
| **เล่มที่ 6 ประชาธิปไตย** | บทบาทสภานักเรียน สิทธิและหน้าที่ของนักเรียน |

## ถ้าต้องการดาวน์โหลดฉบับ PDF

1. เปิดเล่มที่ต้องการ
2. กด **ดาวน์โหลด PDF ต้นฉบับ** ที่มุมขวาบน
3. ไฟล์จะถูกบันทึกหรือเปิดในแอปอ่าน PDF ของเครื่อง

::: tip อ่านต่อหลายรอบ แนะนำใช้ PDF
ระบบไม่จำตำแหน่งอ่านล่าสุด หากต้องอ่านต่อจากเดิมหลายครั้ง ให้ดาวน์โหลด PDF เก็บไว้

บนจอเล็ก ปุ่มจะแสดงเพียง **ดาวน์โหลด**
:::

## ถ้าต้องการไปเล่มถัดไป

1. เลื่อนจนถึงท้ายเล่ม จะเห็นข้อความ **จบเล่ม**
2. กดการ์ด **อ่านเล่มถัดไป**
3. หากเป็นเล่มสุดท้าย จะไม่มีปุ่มนี้

## ถ้าต้องการกลับขึ้นด้านบน

กด **กลับขึ้นบน** ที่ท้ายเล่ม ระบบจะเลื่อนกลับไปจุดเริ่มต้นของเล่ม

## ถ้าต้องการกลับไปหน้ารวมคู่มือ

กดลูกศรย้อนกลับที่หัวจอ ระบบจะพากลับไปหน้ารวมคู่มือ

## ระบบทำอะไรเบื้องหลัง

- จำนวนหน้าแต่ละเล่มกำหนดไว้ในโค้ด ไม่ได้อ่านจากไฟล์โดยอัตโนมัติ
- ชื่อไฟล์หน้าต้องเป็น `page-01.webp` ขึ้นไป และมีเลขศูนย์นำหน้า
- รูปโหลดแบบ lazy หน้าล่างจะโหลดเมื่อเลื่อนใกล้ถึง
- หากไฟล์ปกหาย ระบบแสดงกล่อง **ยังไม่พร้อมใช้งาน** แทนรูปที่เสีย
- หากไฟล์หน้าหาย ระบบซ่อนรูปหน้านั้นและแจ้งจำนวนหน้าที่ขาด

## ข้อจำกัดและข้อควรระวัง

- ไม่มีช่องค้นหาคำในคู่มือ
- ไม่มีสารบัญกระโดดไปบท
- ไม่มีบุ๊กมาร์กหน้าล่าสุด ระบบจำตำแหน่งอ่านไม่ได้
- ระบบไม่รับอัปโหลดคู่มือจากหน้าเว็บ ผู้ดูแลต้องวางไฟล์ในเซิร์ฟเวอร์

::: warning จำนวนหน้าต้องตรงกับไฟล์จริง
ถ้าจำนวนหน้าที่ประกาศไว้ไม่ตรงกับไฟล์ จะเห็นคำเตือน **หน้ายังมาไม่ครบตามที่ระบุ**
:::

## แก้ไขปัญหาและคำถามที่พบบ่อย

**ถาม: เปิดเล่มแล้วเห็นข้อความ "หน้ายังมาไม่ครบตามที่ระบุ"**
ตอบ: ไฟล์รูปบางหน้ายังไม่ถูกวางในระบบ แจ้งผู้ดูแลให้อัปเดตไฟล์
หน้าที่มีอยู่ยังอ่านได้ตามปกติ

**ถาม: ปกขึ้นว่า "ยังไม่พร้อมใช้งาน"**
ตอบ: ไฟล์ปกของเล่มนั้นหายหรือชื่อไฟล์ไม่ตรง ให้แจ้งผู้ดูแล
ยังกดเข้าไปอ่านเนื้อหาได้หากไฟล์หน้ามีอยู่

**ถาม: ดาวน์โหลด PDF แล้วเปิดไม่ได้**
ตอบ: ไฟล์ PDF อาจยังไม่ถูกวาง หรือเครื่องไม่มีแอปอ่าน PDF
ให้ลองเปิดบนคอมพิวเตอร์หรือติดตั้งแอปอ่าน PDF

**ถาม: อ่านถึงกลางเล่มแล้วปิดแอป กลับมาต้องเริ่มใหม่ไหม**
ตอบ: ต้องเลื่อนกลับมาเอง ระบบไม่จำตำแหน่งอ่านล่าสุด
แนะนำให้จดเลขหน้าหรือใช้ PDF แทนเมื่อต้องอ่านต่อหลายครั้ง

**ถาม: คู่มือมีเนื้อหาเรื่องเลื่อนชั้นหรือไม่**
ตอบ: เล่ม **วิชาการ** และ **วินัย** มีแนวปฏิบัติเกี่ยวกับการเรียนและระเบียบ
แต่ขั้นตอนเลื่อนชั้นในระบบให้ดูที่ [การเลื่อนชั้นนักเรียน](../2-staff-operations/student-promotion.md)

**ถาม: ทำไมบางเล่มมีหน้าต่างจากเล่มอื่น**
ตอบ: แต่ละเล่มมีจำนวนหน้าตามที่กำหนดไว้ ระบบไม่ได้ปรับตามขนาดจอ
หน้าที่ยาวจะเลื่อนต่อเนื่อง ไม่มีการแบ่งหน้าจอ
