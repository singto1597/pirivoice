# คลังภาพประกอบคู่มือ

โฟลเดอร์นี้เก็บภาพหน้าจอที่ใช้ในคู่มือทั้ง 3 เล่ม
ทุกภาพแคปจาก **staging** (`https://prsc-test.pirivoice.com`) ด้วยบัญชีทดสอบ ไม่ใช่ภาพวาดหรือภาพจำลอง

## ภาพชุดล่าสุดมาจากไหน

- **แคปเมื่อ:** 28 ตุลาคม 2026
- **บัญชีที่ใช้:** บัญชี e2e 3 ตัว คือ `e2estu` (นักเรียน) `e2ecou` (สภานักเรียน) และ `e2eadm` (ประธานสภา/ผู้ดูแลระบบ)
  รหัสผ่านอ่านจากไฟล์นอก repo ไม่เคยอยู่ในเอกสารหรือ commit
- **ขนาดจอ:** มือถือ 390×844 (สเกล 2x) สำหรับเล่ม 1–2 และ 760×844 (สเกล 2x) สำหรับเล่ม 3 ที่มีตารางกว้าง
- **ภาษาและเขตเวลา:** th-TH · Asia/Bangkok · จำลอง UA มือถือ Android
- **เครื่องมือ:** Playwright (Chromium headless) แปลง PNG ➔ WebP คุณภาพ 80

## วิธีทำให้ภาพปลอดภัย

ภาพทุกใบผ่านการปิดข้อมูลส่วนบุคคลก่อนแคป ใช้วิธีแทนข้อความในหน้าเว็บ (ไม่ใช่การวาดทับ) เพื่อให้อ่านป้ายอื่นได้ครบ

- ชื่อนักเรียนและชื่อบัญชีจริง ➔ **นักเรียน (ปิดชื่อ)** หรือ **สมาชิก (ปิดชื่อ)**
- เลขรหัสนักเรียน ➔ `•••••`
- เลข IP ในหน้าบันทึกการใช้งาน ➔ `••••••••`
- คอมเมนต์และหัวข้อที่เป็นข้อความทดสอบ ➔ ข้อความตัวอย่างที่อ่านรู้เรื่อง

หน้าไหนที่แสดงรายชื่อนักเรียนจริงทั้งโรงเรียนจะไม่ถูกแคปไว้ในคู่มือ

## สิ่งที่ไม่อยู่ในภาพ

- ไม่ได้สร้าง แก้ หรือลบข้อมูลใด ๆ บน staging เพื่อทำภาพ
- ฟอร์มที่เห็นกรอกไว้แล้ว คือกรอกค้างไว้**ก่อนกดส่ง** ไม่มีการยืนยัน
- ภาพที่แสดง "ยังทำไม่ได้" (เช่น หน้าเลื่อนชั้นที่ยังมีปีการศึกษาไม่ถึง 2 ปี) สะท้อนสถานะจริงของข้อมูล staging ไม่ใช่การจำลอง

## ภาพถูกทำเครื่องหมายอย่างไร

ทุกภาพวาดวงกลมสีแดง (`#e11d48`) ล้อมจุดที่ต้องดู และมีป้ายตัวเลขกำกับ
เลขในภาพตรงกับเลขในรายการขั้นตอนของบทนั้น

## ถ้าต้องแคปใหม่

1. เตรียมบัญชีทดสอบบน staging ตามปกติ อย่าใช้บัญชีจริงของนักเรียน
2. เปิดหน้าจอที่ต้องการด้วยขนาดจอเดียวกับด้านบน
3. ปิดชื่อและรหัสก่อนแคปทุกครั้ง
4. บันทึกเป็น `.webp` คุณภาพ 80 ชื่อไฟล์เป็น kebab-case ตรงกับชื่อเดิมถ้าเป็นภาพแทนที่
5. อัปเดตวันที่ในไฟล์นี้
