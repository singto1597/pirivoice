## วิธีแคปซ้ำ

### สภาพแวดล้อม

| ส่วน | ค่า |
|---|---|
| เว็บ staging | `https://prsc-test.pirivoice.com` |
| API staging | `https://prsc-api-test.pirivoice.com` |
| บัญชี | `e2estu` นักเรียน · `e2ecou` สภาณักเรียน · `e2eadm` ผู้ดูแล |
| รหัสผ่าน | เก็บนอก repository และห้ามพิมพ์ลงเอกสาร บันทึก หรือ commit |
| ขนาดจอมือถือ | 390×844 ที่ความละเอียด 2 เท่า (ไฟล์ 780×1688) |
| ขนาดจอผู้ดูแล | 1280×800 |
| ภาษาและเขตเวลา | `th-TH` · `Asia/Bangkok` |

ใช้ Playwright ร่วมกับ Chromium และเรียก API เข้าสู่ระบบก่อน แล้วใส่ `access_token` กับ
`user_id_str` ลง `localStorage` ผ่าน `addInitScript`
วิธีนี้ทำให้ไม่ต้องพิมพ์รหัสผ่านในหน้าเว็บและแคปได้ทุกหน้าโดยไม่ต้องโต้ตอบ

### ขั้นตอน

1. เข้าสู่ระบบผ่าน `POST /api/auth/login` ด้วยบัญชี e2e แล้วเก็บ token ไว้ในไฟล์ชั่วคราวที่สิทธิ์ 600
2. เปิดเบราว์เซอร์ด้วย viewport ตามตาราง เลือก `isMobile` และ `hasTouch` เมื่อแคปจอมือถือ
3. ใช้ `waitUntil: 'domcontentloaded'` แล้วรอด้วยเวลา **ห้ามใช้ `networkidle`** เพราะช่อง SSE เปิดค้างไว้ตลอดและจะรอไม่จบ
4. เลื่อนเฉพาะ container ภายใน ไม่ใช้การแคปเต็มหน้า เพราะแถบนำทางล่างจะหลุดตำแหน่ง
5. ใส่สไตล์บังคับฟอนต์ไทยสำหรับ `code` และ `.font-mono` ก่อนแคป กันกล่องสี่เหลี่ยมในตาราง
6. เบลอข้อมูลส่วนบุคคลด้วย `filter: blur(6px)` บน selector ที่เจาะจง แล้วรอให้ภาพนิ่งก่อนกดแคป
7. บันทึกเป็น PNG แล้วแปลงเป็น WebP คุณภาพ 80 ด้วย Pillow
8. ตรวจภาพด้วยตาอีกครั้งก่อนวางในโฟลเดอร์ ห้ามมีชื่อ รหัส หรือเลขโทรศัพท์ที่อ่านออก

### ตัวอย่าง selector ที่ใช้เบลอ

| หน้า | selector |
|---|---|
| บอร์ด | `span:has(i.bi-person)` |
| เรื่องที่รับผิดชอบ | `span:has(i.bi-person)` |
| รายชื่อนักเรียน | `td:nth-child(1)` ถึง `td:nth-child(3)` |
| ย้ายห้อง | ชื่อและรหัสใน `ul` ของรายการที่เลือก |
| บันทึกการใช้งาน | `td:nth-child(2)` และ `td:nth-child(7)` |
| หน้าต่างเปลี่ยนตำแหน่ง | `.swal2-title` |

selector เหล่านี้ผูกกับโครงสร้างปัจจุบัน ถ้ามีการแก้เทมเพลตต้องตรวจว่าเบลอถูกจุดจริง
ก่อนนำภาพใหม่ไปแทน

## ข้อควรระวัง

- ห้ามแคปตารางนักเรียนจริงทั้งโรงเรียน หน้าบันทึกการใช้งานที่มีชื่อจริง หรือไฟล์นำเข้าที่มีข้อมูลจริง
  หากจำเป็นให้ใช้บัญชี e2e และเบลอทุกคอลัมน์ที่ระบุตัวบุคคล
- ห้ามสร้าง แก้ หรือลบข้อมูลบน staging เพื่อให้ได้ภาพ ใช้เฉพาะสถานะที่มีอยู่
  ฟอร์มที่ต้องกรอกให้พิมพ์ข้อความตัวอย่างแล้วแคปก่อนกดส่ง
- ภาพที่ 15 ได้ภาพจากกล้องจำลองของ Chromium ซึ่งเป็นลายทดสอบสีเขียว ไม่ใช่กล้องจริง
  ใช้เพื่อแสดงโครงหน้าจอและสถานะ **พร้อมสแกน** เท่านั้น
- ภาพความละเอียด 2 เท่าใช้เพื่อให้คมบนจอ Retina ไม่ได้หมายความว่าหน้าจอจริงกว้าง 780 พิกเซล
- เมื่อหน้าจอเปลี่ยน ให้แคปใหม่เฉพาะภาพที่ได้รับผลกระทบและอัปเดตตารางในไฟล์นี้
- ห้ามฝังภาพที่มีข้อมูลส่วนบุคคลแม้จะเบลอไม่สนิท ให้แคปใหม่แทนการเดา
